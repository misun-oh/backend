# Day 3~5. 함수(FUNCTION) - 실습

> 아래 문제는 `01_실습데이터.md`의 `EMP` 테이블만으로 풀 수 있습니다.
> (교안에서 다룬 문자/숫자/날짜/형변환/NULL 처리 함수, CASE, 그룹 함수, GROUP BY/HAVING만 사용
> / MySQL 문법 기준)

## 기본

### 문제 1. 날짜 형식 변환
총무부(`'D9'`) 사원의 이름과 입사일을 `"2013년 03월 02일"`과 같은 형식의 문자열로 변환해서,
입사일이 빠른 순으로 조회하세요. (`DATE_FORMAT` 활용)

**Output**
```
곽상혁 2013년 03월 02일
권진우 2013년 09월 15일
김민혜 2014년 02월 10일
```

---

### 문제 2. 문자 길이 함수
회계관리부(`'D2'`) 사원의 이름, 이름의 글자 수(`CHAR_LENGTH`), 이름의 바이트 수(`LENGTH`)를
조회하세요.

**Output**
```
박홍주 3 9
심재호 3 9
엄용민 3 9
```

---

## 응용

### 문제 3. IFNULL + 산술 연산
해외영업1부(`'D5'`) 사원의 이름, 급여, 보너스 포함 연봉(`(급여 + 급여*IFNULL(보너스,0)) * 12`)을
연봉이 높은 사람부터 정렬해서 조회하세요.

**확인할 것**: 5행이 조회되고, 1위는 박지민(연봉 48,300,000), 꼴찌는 최주호(연봉 21,600,000)
입니다.

---

### 문제 4. CASE + GROUP BY
전 사원을 아래 기준으로 등급을 나누고, 등급별 인원수를 조회하세요.
- 급여 500만원 이상 → `'고액'`
- 급여 250만원 이상 500만원 미만 → `'중액'`
- 나머지 → `'소액'`

**Output**
```
고액 2
중액 11
소액 8
```

---

### 문제 5. GROUP BY + HAVING
부서별 평균 급여(1의 자리에서 반올림)를 구하되, 평균 급여가 300만원 이상인 부서만 부서코드와
평균 급여를 조회하세요.

**Output**
```
D6 3650000
D9 5900000
```
(순서는 무관합니다)

## 도전

### 문제 6. 종합 - CASE로 성별 구분 후 집계
`EMP_NO`의 8번째 글자(`'1'`/`'3'`이면 `'남'`, `'2'`/`'4'`이면 `'여'`)로 성별을 구분해서,
성별별 인원수와 평균 급여(1의 자리에서 반올림)를 조회하세요.

**Output**
```
남 14 3106429
여 7  3160891
```

### 문제 7. 종합 - TIMESTAMPDIFF + WHERE
재직 중인(`ENT_YN = 'N'`) 사원 중, **2026-08-19**를 기준으로 재직 개월수가 120개월(10년)
이상인 사원의 이름, 입사일, 재직 개월수를 재직 개월수가 큰 순으로 조회하세요.
(`TIMESTAMPDIFF(MONTH, HIRE_DATE, '2026-08-19')` 활용, 현재 날짜 대신 고정된 날짜를 기준으로
계산해야 답이 항상 같게 나옵니다)

**확인할 것**: 7행이 조회되고, 1위는 곽상혁(161개월)입니다.
