# Day 6~7. JOIN - 실습

> 아래 문제는 `01_실습데이터.md`의 `EMP`, `DEPT`, `JOB`, `LOCATION`, `NATIONAL`,
> `SAL_GRADE` 테이블로 풀 수 있습니다. (ANSI `JOIN ... ON` / `USING` 문법만 사용,
> MySQL 문법 기준)

---

## 기본

### 문제 1. INNER JOIN
기술지원부(`'D8'`) 사원의 이름, 부서명, 직급명을 조회하세요. (`EMP`-`DEPT`-`JOB` 조인)

**Output**
```
이광렬 기술지원부 대리
이금빈 기술지원부 대리
오미자 기술지원부 사원
```

---

### 문제 2. USING
`USING`을 사용해서 `EMP`와 `DEPT`를 연결하고, 회계관리부(`'D2'`) 사원의 이름과 부서명을
조회하세요.

**Output**
```
박홍주 회계관리부
심재호 회계관리부
엄용민 회계관리부
```

---

## 응용

### 문제 3. LEFT JOIN + IFNULL
전 사원의 이름과 부서명을 조회하되, 부서가 배정되지 않은 사원도 결과에 포함시키고
부서명 자리는 `'부서없음'`으로 표시하세요.

**확인할 것**: 21행이 조회되고, 그중 조정원·한규원 두 사람만 부서명이 `'부서없음'`으로
나옵니다.

---

### 문제 4. 다중 JOIN
인사관리부(`'D1'`) 사원의 이름, 부서명, 근무 도시(`LOCAL_NAME`), 국가명(`NATIONAL_NAME`)을
조회하세요. (`EMP`-`DEPT`-`LOCATION`-`NATIONAL` 조인)

**Output**
```
이다현 인사관리부 ASIA1 한국
전태성 인사관리부 ASIA1 한국
한재헌 인사관리부 ASIA1 한국
```

---

### 문제 5. SELF JOIN
관리자가 `'이광렬'`인 사원의 이름과 급여를 조회하세요.

**Output**
```
이금빈 2550000
오미자 2436240
```

---

## 도전

### 문제 6. RIGHT JOIN + GROUP BY
부서별 평균 급여(1의 자리에서 반올림)를 구하되, 사원이 한 명도 없는 부서까지 포함해서
부서코드, 부서명, 평균 급여를 부서코드 순으로 조회하세요. (사원이 없는 부서는 평균 급여가
`NULL`로 나옵니다)

**확인할 것**: 9행이 조회되고, 그중 마케팅부(D3), 국내영업부(D4), 해외영업3부(D7) 세
부서는 평균 급여가 `NULL`입니다.

---

### 문제 7. 비동등 조인 + 정렬
급여 등급(`SAL_LEVEL`)이 `'S1'` 또는 `'S6'`인 사원의 이름, 급여, 급여 등급을 급여 등급
오름차순, 같은 등급 안에서는 급여 내림차순으로 조회하세요. (`EMP`-`SAL_GRADE` 비동등 조인)

**Output**
```
곽상혁 8000000 S1
권진우 6000000 S1
최주호 1800000 S6
심재호 1550000 S6
한재헌 1380000 S6
```
