## 기본

### 문제 1. 단일행 서브쿼리
김민혜보다 급여가 높은 사원의 이름과 급여를 급여 내림차순으로 조회하세요.

**Output**
```
곽상혁 8000000
권진우 6000000
김태일 3900000
윤정주 3760000
```

---

### 문제 2. 다중행 서브쿼리 (IN)
부장(`'J3'`) 직급인 사원이 한 명이라도 속한 부서에 소속된 사원 전체의 부서코드, 이름을
사번 오름차순으로 조회하세요.

```
203 김은민 D6
204 김태일 D6

206 염성원 D5

## 응용

### 문제 3. ALL
회계관리부(`'D2'`) 사원 전원보다 급여가 낮은 사원의 이름과 급여를 조회하세요.
(`< ALL` 사용)

**Output**
```
한재헌 1380000
```

---

### 문제 4. ANY
해외영업2부(`'D6'`) 사원 중 어느 한 명보다도 급여가 높은 사원의 이름과 급여를 급여
내림차순으로 조회하세요. (`> ANY` 사용)

**Output**
```
곽상혁 8000000
권진우 6000000
김태일 3900000
윤정주 3760000
김민혜 3700000
전태성 3660000
박지민 3500000
```

### 문제 7. 종합 - 인라인 뷰 + LIMIT
부서별 평균 급여(반올림)를 구한 뒤, 평균 급여가 가장 높은 부서 **딱 1곳**의 부서명과
평균 급여를 조회하세요. (인라인 뷰로 부서별 평균을 먼저 구하고, `ORDER BY` + `LIMIT`으로
1위만 추출)

```
