## 기본

### 문제 1. RANK 기본
총무부(`'D9'`) 사원의 이름, 급여, 급여 내림차순 순위(`RANK`)를 조회하세요.

**Output**
```
곽상혁 8000000 1
권진우 6000000 2
김민혜 3700000 3
```

---

### 문제 2. AVG() OVER
해외영업1부(`'D5'`) 사원의 이름, 급여, 부서 평균 급여(`AVG() OVER`)를 사번 오름차순으로
조회하세요.

**Output**
```
박지민 3500000 2752000
염성원 2200000 2752000
유제영 2500000 2752000
윤정주 3760000 2752000
최주호 1800000 2752000
```

## 응용

### 문제 3. PARTITION BY
기술지원부(`'D8'`)와 회계관리부(`'D2'`) 사원의 이름, 부서코드, 급여, 부서 내 급여
순위(`RANK`, 내림차순)를 부서코드·순위 순으로 조회하세요.

**Output**
```
이금빈 D8 2550000 1
오미자 D8 2436240 2
이광렬 D8 2000000 3
박홍주 D2 2800000 1
엄용민 D2 2490000 2
심재호 D2 1550000 3
```

### 문제 4. LAG / LEAD
인사관리부(`'D1'`) 사원의 이름과 급여를 급여 내림차순으로 정렬하고, 바로 위 순위
사원과 아래 순위 사원의 급여(`LAG`/`LEAD`)를 함께 조회하세요.

**Output**
```
전태성 3660000 (null)    2780000
이다현 2780000 3660000   1380000
한재헌 1380000 2780000   (null)
```

---

### 문제 5. 누적 합계
총무부(`'D9'`) 사원의 이름, 급여를 급여 내림차순으로 정렬하고, 누적 급여
합계(`SUM() OVER`)를 함께 조회하세요.

**Output**
```
곽상혁 8000000 8000000
권진우 6000000 14000000
김민혜 3700000 17700000
```

## 도전

### 문제 6. RANK vs DENSE_RANK
총무부(`'D9'`) 사원의 이름, 입사 연도(`EXTRACT(YEAR FROM HIRE_DATE)`), `ROW_NUMBER`,
`RANK`, `DENSE_RANK`를 입사 연도 오름차순으로 조회하세요.

**Output**
```
곽상혁 2013 1 1 1
권진우 2013 2 1 1
김민혜 2014 3 3 2
```
