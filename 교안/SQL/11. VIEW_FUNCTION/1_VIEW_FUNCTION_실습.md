> 각 문제를 풀기 전, `1_VIEW_FUNCTION.md` 0절의 사본 생성 스크립트를 먼저
> 실행해 원본과 동일한 상태에서 시작하세요. (MySQL 8.0 문법 기준)

## 기본

회계관리부(`'D2'`) 사원의 이름, 급여만 보여주는 뷰 `V_D2_EMP`를 만들고, 급여
내림차순으로 조회하세요.

```

엄용민 2490000

```

### 문제 2. 사용자정의 함수 - 급여 등급
급여를 입력받아 500만원 이상이면 `'고액'`, 250만원 이상이면 `'중액'`, 그 외에는
`'소액'`을 반환하는 함수 `GET_GRADE(급여)`를 만드세요. 이 함수를 이용해 해외영업2부
(`'D6'`) 사원의 이름, 급여, 등급을 조회하세요.

**Output**
```
김은민 3400000 중액
김태일 3900000 중액
```

### 문제 7. 종합 - 함수 + 뷰 + LIMIT
문제 5의 방식대로, 급여와 보너스를 입력받아 보너스 포함 연봉
(`(급여 + 급여 * IFNULL(보너스, 0)) * 12`)을 반환하는 함수 `GET_ANNUAL_SALARY(급여, 보너스)`를
만드세요. 이 함수를 이용해 부서별 평균 연봉(반올림)을 구하는 뷰
`V_DEPT_ANNUAL_AVG`를 만들고, 평균 연봉이 가장 높은 부서 **딱 1곳**의 부서명과
평균 연봉을 조회하세요.

**Output**
```
총무부 80400000
```
