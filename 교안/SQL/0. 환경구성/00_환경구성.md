# 0. 환경 구성 (MySQL 설치 ~ 실습 데이터 생성)

| 항목 | 내용 |

## 학습목표
- MySQL Server와 MySQL Workbench를 다운로드해서 설치할 수 있다.
- 설치 시 만든 관리자(root) 계정으로 Workbench에 접속할 수 있다.
- root 계정으로 실습용 계정을 새로 만들고, 데이터베이스를 생성할 수 있는 권한을 부여할 수 있다.
- 새로 만든 계정으로 접속을 전환하고, `0. 환경구성/01_실습데이터.md`의 스크립트로 실습
  데이터를 생성/확인할 수 있다.

## 1. MySQL Installer 다운로드

MySQL은 공식 사이트에서 **MySQL Installer** 하나로 서버(Server)와 Workbench를 한 번에
설치할 수 있습니다.

1. 브라우저에서 `https://www.mysql.com/downloads/` 접속하면 여러 다운로드 항목이
   보입니다(HeatWave, Enterprise Edition, Community Edition, Early Access,
   AI, NDB Cluster 등).
   - **MySQL Early Access Release**: 정식 출시 전 테스트용 빌드입니다. 버그가 있을
     수 있고 기술지원도 없으니 넘어갑니다.
   - **MySQL Community Edition** ← **이걸 선택합니다.** 무료 오픈소스 버전이며,
     우리가 쓸 Installer/Server/Workbench가 모두 여기 포함되어 있습니다.
     `MySQL Community (GPL) Downloads »` 링크를 클릭합니다.
   - **MySQL Enterprise Edition, HeatWave, AI, NDB Cluster** 등: 모두 상용/클라우드
     제품이거나 실습과 무관한 별도 기능입니다. 무시합니다.
2. 이어지는 목록에서 **MySQL Installer for Windows**를 선택합니다.
   (바로 `https://dev.mysql.com/downloads/installer/`로 이동해도 같은 페이지입니다.)
3. 다운로드 페이지 상단에는 버전을 고르는 드롭다운이 있고, 버전 옆에 **"GA"**라는
   표시가 붙어 있습니다.

   > **GA가 뭔가요?** **General Availability**(정식 배포)의 줄임말로, 충분히
   > 검증되어 **실서비스에 써도 되는 정식 안정 버전**이라는 뜻입니다. (반대로
   > "Innovation" 트랙이나 앞서 언급한 "Early Access"는 새 기능을 먼저 써볼 수 있는
   > 대신 안정성이 떨어지는 버전입니다.) 특별한 이유가 없다면 **항상 GA로 표시된
   > 최신 버전**을 선택하면 됩니다.

   버전을 고른 뒤에는 두 가지 설치 파일 중 하나를 선택합니다.
   - **mysql-installer-web-community** (용량이 작음, 설치 중 필요한 구성요소를 그때그때
     인터넷에서 받음) — 일반적으로 이 버전을 권장합니다.
   - **mysql-installer-community** (모든 구성요소가 포함된 큰 파일, 오프라인 설치 가능)

   > **"(x86, 32-bit)"라고 적혀 있는데 32비트 컴퓨터만 쓸 수 있나요?** 아닙니다. 이
   > 라벨은 **설치 프로그램(installer) 실행 파일 자체**가 32비트로 빌드되었다는
   > 뜻일 뿐입니다. 이 설치 프로그램은 실행되는 순간 내 컴퓨터가 64비트인지 감지해서,
   > 64비트 Windows에는 **64비트 MySQL Server/Workbench**를 알아서 내려받아
   > 설치해줍니다. 대부분의 현재 Windows PC는 64비트이므로 이 항목 하나만 받으면
   > 됩니다. (Oracle이 호환성을 위해 설치 프로그램만 32비트로 배포하는 것이며,
   > 공식적으로 안내된 정상적인 동작입니다.)
4. 다운로드 버튼을 누르면 오라클 계정 로그인/회원가입 화면이 뜨는데, 화면 하단의
   **"No thanks, just start my download."** 링크를 누르면 로그인 없이 바로 받을 수
   있습니다. (이 링크를 못 찾아서 헤매는 경우가 많으니 꼭 기억해두세요.)

## 2. MySQL Installer 실행 — Server + Workbench 함께 설치

1. 다운로드한 설치 파일을 실행합니다.
2. **Choosing a Setup Type** 화면에서 **Developer Default**를 선택합니다.
   - 이 옵션 하나로 **MySQL Server, MySQL Workbench, MySQL Shell** 등 학습에 필요한
     구성요소가 한 번에 설치됩니다.
3. **Check Requirements** 화면에서 부족한 구성요소가 있다고 뜨면 안내에 따라 함께
   설치합니다 (보통 자동으로 해결됩니다).
4. **Installation** 화면에서 **Execute**를 눌러 다운로드 및 설치를 진행합니다.
5. 설치가 끝나면 **Product Configuration** 단계로 넘어갑니다. 여기서부터가 중요합니다.
   - **Type and Networking**: `Config Type`은 `Development Computer`, `Port`는 기본값
     `3306`을 그대로 사용합니다.
   - **Authentication Method**: 기본값(`Use Strong Password Encryption`)을 그대로
     둡니다.
   - **Accounts and Roles**: **root 계정의 비밀번호**를 설정하는 화면입니다.
     > **이 비밀번호를 반드시 기록해두세요.** 이후 모든 관리자 작업(계정 생성, 권한
     > 부여 등)에 계속 필요하며, 분실하면 복구 절차가 번거롭습니다.
   - **Windows Service**: 기본값(`Start the MySQL Server at System Startup`)을 그대로
     두면 컴퓨터를 켤 때마다 MySQL이 자동으로 실행됩니다.
6. **Apply Configuration** → **Execute** → **Finish**로 설치를 마칩니다.

## 3. 설치 확인

- **Windows 서비스 확인**: 작업 표시줄 검색에서 `services.msc` 실행 → 목록에서
  `MySQL80`(버전에 따라 이름이 다를 수 있음) 서비스가 **실행 중** 상태인지 확인합니다.
- **MySQL Workbench 실행**: 시작 메뉴에서 `MySQL Workbench` 실행 → 첫 화면의
  `MySQL Connections` 아래에 `Local instance MySQL80` 접속 정보가 이미 자동으로
  만들어져 있는지 확인합니다.

## 4. root 계정으로 최초 접속

1. Workbench에서 `Local instance MySQL80`을 클릭합니다.
2. 위 **2. MySQL Installer 실행** 단계의 `Accounts and Roles` 화면에서 설정한
   **root 비밀번호**를 입력하고 접속합니다.
3. 접속에 성공하면 왼쪽 **Navigator** 패널의 **SCHEMAS** 탭에 데이터베이스 목록이
   보입니다. (아직 우리가 만든 데이터베이스는 없으니 `information_schema`,
   `mysql`, `sys` 같은 MySQL 내부용 데이터베이스만 보일 것입니다.)

## 5. 실습용 계정 생성 및 권한 부여 (root로 실행)

관리자(root) 계정을 실습 때마다 계속 쓰는 것은 위험합니다(모든 권한을 갖고 있어 실수로
다른 데이터베이스까지 건드릴 수 있음). **실습 전용 계정**을 새로 만들어서 사용합니다.

Workbench 상단 쿼리 탭에 아래 SQL을 입력하고 실행합니다 (root로 접속된 상태여야 합니다).

```sql
-- 1) 계정 생성 (계정명, 비밀번호는 원하는 값으로 바꿔서 사용)
CREATE USER 'student'@'localhost' IDENTIFIED BY '비밀번호를입력하세요';

-- 2) 데이터베이스 생성 권한 + 실습에 필요한 모든 권한 부여
GRANT ALL PRIVILEGES ON *.* TO 'student'@'localhost';

-- 3) 권한 변경 사항을 즉시 반영
FLUSH PRIVILEGES;
```

**설명**
- `CREATE USER '계정명'@'localhost' IDENTIFIED BY '비밀번호'`: `localhost`(이 컴퓨터)에서만
  접속 가능한 새 계정을 만듭니다.
- `GRANT ALL PRIVILEGES ON *.* TO '계정명'@'localhost'`: `*.*`는 "모든 데이터베이스의
  모든 테이블"을 뜻합니다. 여기에는 `CREATE DATABASE`(데이터베이스 생성) 권한도
  포함되어 있으므로, 이 계정으로 앞으로 실습에 쓸 데이터베이스를 직접 만들 수 있습니다.
- `FLUSH PRIVILEGES`: 방금 바뀐 권한 정보를 서버에 즉시 반영합니다. (최신 MySQL은
  `GRANT` 실행 시 자동으로 반영되지만, 습관적으로 함께 실행하는 것을 권장합니다.)

> **참고**: 데이터베이스 생성 권한만 필요하다면 `GRANT ALL PRIVILEGES` 대신
> `GRANT CREATE, DROP, SELECT, INSERT, UPDATE, DELETE ON *.* TO 'student'@'localhost';`
> 처럼 필요한 권한만 최소로 부여할 수도 있습니다. 실무에서는 이렇게 **꼭 필요한 권한만
> 부여**하는 것이 원칙이지만, 학습 환경에서는 편의를 위해 `ALL PRIVILEGES`를 사용합니다.

## 6. 새로 만든 계정으로 접속 전환

1. Workbench 홈 화면(탭에서 `Home` 클릭)으로 이동합니다.
2. `MySQL Connections` 옆의 **`+`** 아이콘을 눌러 새 접속 정보를 추가합니다.
   - `Connection Name`: 원하는 이름 (예: `student_local`)
   - `Hostname`: `127.0.0.1`
   - `Port`: `3306`
   - `Username`: `student` (5단계에서 만든 계정명)
3. `Test Connection`을 눌러 비밀번호를 입력하고 접속이 되는지 확인한 뒤 `OK`로
   저장합니다.
4. 새로 만든 접속 아이콘을 클릭해서 접속합니다. 이제부터는 이 계정으로 실습을
   진행합니다.

## 7. 실습 데이터 생성

이제 `student` 계정으로 접속된 상태에서 `0. 환경구성/01_실습데이터.md`의 스크립트를
그대로 실행합니다.

1. `01_실습데이터.md`의 **1. 실습 스키마 준비** ~ **4. 데이터 입력**에 있는 SQL을
   순서대로 Workbench 쿼리 탭에 붙여넣습니다. (`CREATE DATABASE` → `USE` →
   `CREATE TABLE` 6개 → `INSERT INTO` 전체)
2. 전체 실행(⚡ 번개 모양 아이콘, 또는 `Ctrl + Shift + Enter`)으로 한 번에 실행합니다.
3. 아래 SQL로 정상 생성 여부를 확인합니다.

```sql
SHOW DATABASES;               -- 방금 만든 데이터베이스가 목록에 보이는지 확인
SELECT * FROM EMP;            -- 21행이 조회되는지 확인
SELECT COUNT(*) FROM EMP;     -- 결과가 21인지 확인
```

**확인할 것**: `SELECT * FROM EMP;`를 실행했을 때 21행이 나오고, 이름/이메일 등 한글과
영문이 깨지지 않고 정상적으로 보여야 합니다.

## 8. 한글이 깨져 보인다면 (문자셋 확인)

`EMP_NAME`, `DEPT_TITLE` 같은 한글 데이터가 `?????`처럼 깨져 보인다면 문자셋 설정
문제일 수 있습니다.

```sql
SHOW VARIABLES LIKE 'character_set%';
```

MySQL 8.0은 기본 문자셋이 `utf8mb4`라 보통 문제가 없지만, 만약 깨진다면 데이터베이스를
아래처럼 문자셋을 명시해서 다시 만들어봅니다.

```sql
CREATE DATABASE 데이터베이스명 CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
```

## 자주 하는 실수

- **root 비밀번호를 기록해두지 않음** → 설치 중 설정한 비밀번호를 잊어버리면 복구
  절차가 복잡합니다. 설치 화면에서 반드시 메모해두세요.
- **`GRANT` 후 `FLUSH PRIVILEGES`를 빠뜨림** → 최신 MySQL에서는 대부분 자동
  반영되지만, 권한이 바로 적용되지 않는 것처럼 보이면 `FLUSH PRIVILEGES;`를 실행해
  보세요.
- **새 계정으로 접속했는데 `Access denied for user` 에러** → 계정명/비밀번호 오타,
  또는 `CREATE USER`에서 지정한 호스트(`'student'@'localhost'`)와 실제 접속 시
  `Hostname`이 다른 경우 발생합니다. Workbench에서는 `127.0.0.1`로 접속해도
  `localhost`로 인식되니 안심해도 됩니다.
- **`USE 데이터베이스명;` 없이 바로 `CREATE TABLE`/`INSERT` 실행** → `No database
  selected` 에러가 납니다. `CREATE DATABASE` 다음에 반드시 `USE 데이터베이스명;`을
  실행해야 그 이후 명령이 해당 데이터베이스 안에서 실행됩니다.
- **포트 3306이 이미 사용 중이라는 에러** → 이전에 설치했던 MySQL이 남아있는 경우
  발생할 수 있습니다. 기존 MySQL 서비스가 있는지 `services.msc`에서 먼저 확인하세요.
