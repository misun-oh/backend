# Day 17. PROCEDURE & TRIGGER - 실습

> 아래 문제는 `EMP_COPY`(원본 `EMP`의 사본)와 `SALARY_LOG` 테이블로 풀 수 있습니다.
> 각 문제를 풀기 전, `1_PROCEDURE_TRIGGER.md` 0절의 사본/로그 테이블 생성 스크립트를
> 먼저 실행해 원본과 동일한 상태에서 시작하세요. (MySQL 8.0 문법 기준)

---

## 기본

### 문제 1. OUT 파라미터
부서코드를 입력받아 그 부서의 인원수를 반환하는 프로시저 `GET_DEPT_COUNT(IN 부서코드,
OUT 인원수)`를 만들고, 해외영업1부(`'D5'`)로 호출한 결과를 조회하세요.

**Output**
```
5
```

---

### 문제 2. IN 파라미터로 급여 인상
부서코드와 인상률을 입력받아 그 부서 전체 급여를 인상하는 프로시저
`RAISE_SALARY(IN 부서코드, IN 인상률)`을 만들고, 인사관리부(`'D1'`)에 5%(`0.05`)
인상을 적용한 뒤 `EMP_COPY`에서 결과를 조회하세요.

**Output**
```
이다현 2919000
전태성 3843000
한재헌 1449000
```

---

## 응용

### 문제 3. IF 제어문
사번을 입력받아 급여 등급(`'고액'`/`'중액'`/`'소액'`, 기준은 함수 챕터와 동일:
500만/250만)을 반환하는 프로시저 `CLASSIFY_SALARY(IN 사번, OUT 등급)`를 만들고,
윤정주(`EMP_ID = '208'`)로 호출한 결과를 확인하세요.

**Output**
```
중액
```

---

### 문제 4. AFTER UPDATE 트리거
`EMP_COPY`에 `AFTER UPDATE` 트리거 `TRG_SALARY_LOG`를 만들어, 급여가 바뀔 때마다
`SALARY_LOG(EMP_ID, OLD_SALARY, NEW_SALARY)`에 자동으로 기록되게 하세요. 그 다음
최주호(`EMP_ID = '209'`)의 급여를 300,000원 인상하고 `SALARY_LOG`를 조회하세요.

**Output**
```
209 1800000 2100000
```

---

### 문제 5. 커서로 조건에 맞는 행 세기
`EMP_COPY`를 커서로 순회하며 급여가 300만원 이상인 사원 각각의 사번과 급여를
`SALARY_LOG`(`OLD_SALARY`, `NEW_SALARY`에 같은 값 기록)에 남기는 프로시저
`SNAPSHOT_HIGH_SALARY()`를 작성하고 실행하세요. 실행 후 `SALARY_LOG`에 몇 건이
쌓였는지 조회하세요.

**Output**
```
8
```

---

## 도전

### 문제 6. EXIT HANDLER로 예외 처리
사번을 입력받아 급여를 반환하되, 존재하지 않는 사번이면 `-1`을 반환하는 프로시저
`GET_SALARY_SAFE(IN 사번, OUT 급여)`를 `EXIT HANDLER`로 작성하세요. 사번
`'999'`(존재하지 않음)와 `'200'`(곽상혁)으로 각각 호출한 결과를 비교하세요.

**Output**
```
'999' 호출 결과: -1
'200' 호출 결과: 8000000
```

---

### 문제 7. 종합 - BEFORE INSERT 트리거
`EMP_COPY`에 `BEFORE INSERT` 트리거 `TRG_DEFAULT_ENTYN`을 만들어, 새로 추가되는
사원의 `ENT_YN`이 `NULL`이면 자동으로 `'N'`으로 채워지게 하세요. `ENT_YN`을 비워둔
채 신입 사원(`EMP_ID = '222'`, 이름/부서/직급/급여/입사일은 자유, `DEPT_ID = 'D9'`)을
`INSERT`한 뒤 `ENT_YN` 값을 확인하세요.

**Output**
```
N
```
