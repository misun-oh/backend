# Day 5. String과 배열 기초 - 실습

> 아래 문제는 교안에서 다룬 String 메서드와 1차원 배열, 향상된 for문만으로 풀 수 있습니다.

---

## 기본

### 문제 1. 문자열 정보 출력
문자열 `"Hello Java"`를 변수에 저장하고, 길이(length)와 첫 글자(charAt)를 출력하세요.

**Output**
```
길이: 10
첫 글자: H
```

---

### 문제 2. 배열 선언과 순회 (향상된 for문)
정수 배열 `{10, 20, 30, 40, 50}`을 선언하고, 향상된 for문으로 모든 값을 한 줄씩 출력하세요.

**Output**
```
10
20
30
40
50
```

---

## 응용

### 문제 3. 이메일에서 아이디 추출
이메일 주소(`"student@example.com"`)를 입력받아, `indexOf`와 `substring`을 이용해 `@` 앞부분(아이디)만 잘라 출력하세요.

**Input**
```
student@example.com
```

**Output**
```
아이디: student
```

---

### 문제 4. 대소문자 무시 비교
Scanner로 문자열 두 개를 입력받아, `equalsIgnoreCase()`로 대소문자를 무시하고 같은지 비교해 결과를 출력하세요.

**Input**
```
JAVA
java
```

**Output**
```
같은 단어입니다
```

---

### 문제 5. 배열 합계와 평균
정수 배열 `{85, 90, 78, 92, 88}`의 합계와 평균(소수점 둘째 자리까지)을 구해 출력하세요. (기존 for문 사용)

**Output**
```
합계: 433
평균: 86.60
```

---

## 도전

### 문제 6. 콤마로 구분된 문자열 분리 (split)
`"사과,바나나,포도,딸기"`를 `split(",")`으로 나눠 배열에 담고, 향상된 for문으로 각 과일 앞에 번호를 붙여 출력하세요.

**Output**
```
1. 사과
2. 바나나
3. 포도
4. 딸기
```
(힌트: 번호가 필요하므로 향상된 for문과 별도의 카운터 변수를 함께 사용하세요.)

---

### 문제 7. 종합 - 최댓값 찾기와 문자열 가공
정수 배열 `{72, 95, 63, 88, 91}`에서 최댓값을 찾아 출력하고, "최고점: 95점입니다"처럼 문자열과 결합해서 출력하세요. (기존 for문으로 최댓값 비교 로직 작성)

**Output**
```
최고점: 95점입니다
```
