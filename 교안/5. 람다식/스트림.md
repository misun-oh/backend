# 부록 5. 스트림 (Stream)

| 항목 | 내용 |
|---|---|
| 선수 학습 | 람다식 (부록4), 컬렉션 (Day 16) |
| 이번 챕터 | 스트림의 필요성, 중간 연산과 종단 연산, `Collectors`를 활용한 집계 |

## 학습목표
- 반복문으로 컬렉션을 처리하는 방식의 한계를 통해 스트림이 왜 필요한지 설명할 수 있다
- 스트림의 생성 → 중간 연산 → 종단 연산이라는 3단계 흐름을 이해할 수 있다
- `filter`, `map`, `sorted` 같은 중간 연산을 람다식으로 작성할 수 있다
- `forEach`, `count`, `collect` 같은 종단 연산으로 결과를 얻어낼 수 있다
- `Collectors.toList()`, `Collectors.joining()`, `Collectors.groupingBy()`를 활용할 수 있다

---

## 1. 문제 상황: 반복문으로 컬렉션 가공하기

Day16에서 배운 `List`를 다루다 보면, "조건에 맞는 것만 골라서 → 원하는 형태로 바꾸고 → 개수를 세거나 새 리스트로 모은다"는 작업을 자주 반복하게 됩니다. 지금까지는 이런 작업을 for문과 임시 리스트로 직접 구현해야 했습니다.

```java
List<Student> students = new ArrayList<>();
students.add(new Student("홍길동", 92));
students.add(new Student("김철수", 78));
students.add(new Student("이영희", 85));

// 90점 이상인 학생의 이름만 모아서 새 리스트를 만들기
List<String> highScoreNames = new ArrayList<>();
for (Student student : students) {
    if (student.getScore() >= 90) {
        highScoreNames.add(student.getName());
    }
}

System.out.println(highScoreNames); // [홍길동]
```

**설명**: "필터링"과 "변환"이라는 두 가지 목적이 하나의 for문 안에 섞여 있고, 결과를 담을 임시 리스트(`highScoreNames`)도 직접 만들어야 합니다. 조건이 하나만 더 늘어도 for문 내부가 점점 복잡해집니다. 스트림(Stream)은 이런 "컬렉션을 걸러내고 바꾸고 모으는" 작업을 파이프라인 형태로 간결하게 표현하는 문법입니다.

---

## 2. 스트림의 3단계 흐름

스트림은 항상 다음 3단계로 이루어집니다.

| 단계 | 역할 | 예시 |
|---|---|---|
| ① 생성 | 컬렉션 등에서 스트림을 만든다 | `students.stream()` |
| ② 중간 연산 | 필터링/변환을 하고 다시 스트림을 반환한다 (0번 이상 연결 가능) | `.filter(...)`, `.map(...)` |
| ③ 종단 연산 | 스트림을 소비해서 최종 결과를 만든다 (딱 1번, 마지막에) | `.collect(...)`, `.forEach(...)` |

```java
List<String> highScoreNames = students.stream()               // ① 생성
        .filter(student -> student.getScore() >= 90)           // ② 중간 연산: 필터링
        .map(student -> student.getName())                     // ② 중간 연산: 변환
        .collect(Collectors.toList());                         // ③ 종단 연산: 리스트로 모으기

System.out.println(highScoreNames); // [홍길동]
```

**설명**: 1번의 for문 코드와 완전히 같은 결과를 만들지만, "무엇을 할지"만 순서대로 나열하면 됩니다. 임시 리스트를 직접 만들고 `add()`할 필요가 없습니다. 중요한 규칙 하나: **중간 연산은 스트림을 반환**하므로 계속 이어붙일(체이닝) 수 있지만, **종단 연산은 스트림이 아닌 최종 결과(List, 개수, 문자열 등)를 반환**하므로 그 뒤에는 더 이상 스트림 메서드를 이어붙일 수 없고, 스트림은 딱 한 번만 사용할 수 있습니다(재사용 불가).

## 3. 중간 연산 (Intermediate Operations)

| 연산 | 역할 | 예시 |
|---|---|---|
| `filter(조건)` | 조건(`Predicate`)에 맞는 요소만 통과시킴 | `filter(s -> s.getScore() >= 90)` |
| `map(변환)` | 각 요소를 다른 값/타입으로 변환함 | `map(s -> s.getName())` |
| `sorted()` / `sorted(비교자)` | 자연 순서 또는 `Comparator` 기준으로 정렬함 | `sorted((a, b) -> b.getScore() - a.getScore())` |
| `distinct()` | 중복된 요소를 제거함 | `distinct()` |

```java
public class StreamIntermediateExample {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>();
        students.add(new Student("홍길동", 92));
        students.add(new Student("김철수", 78));
        students.add(new Student("이영희", 85));

        // filter + map + sorted를 연결: 80점 이상 학생을 이름만 뽑아 점수 내림차순으로
        List<String> result = students.stream()
                .filter(student -> student.getScore() >= 80)                 // 80점 이상만
                .sorted((a, b) -> b.getScore() - a.getScore())               // 점수 내림차순 정렬
                .map(student -> student.getName())                          // 이름만 추출
                .collect(Collectors.toList());

        System.out.println(result); // [홍길동, 이영희]
    }
}
```

**설명**: 중간 연산은 순서대로 실행됩니다. `filter`로 먼저 80점 이상만 남기고, `sorted`로 점수 내림차순 정렬한 뒤, `map`으로 `Student` 객체를 이름 문자열로 바꿉니다. 각 단계는 "이전 단계가 넘겨준 스트림"을 받아 "가공된 새 스트림"을 돌려주기 때문에 `.filter(...).sorted(...).map(...)`처럼 자유롭게 이어붙일 수 있습니다.

## 4. 종단 연산 (Terminal Operations)

| 연산 | 역할 | 예시 |
|---|---|---|
| `forEach(동작)` | 각 요소에 대해 동작을 수행함 (반환값 없음) | `forEach(s -> System.out.println(s.getName()))` |
| `count()` | 요소 개수를 센다 | `count()` → `long` |
| `collect(Collectors.toList())` | 요소들을 `List`로 모은다 | 아래 5번 참고 |

```java
public class StreamTerminalExample {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>();
        students.add(new Student("홍길동", 92));
        students.add(new Student("김철수", 78));
        students.add(new Student("이영희", 85));

        // forEach: 화면 출력
        students.stream()
                .filter(student -> student.getScore() >= 80)
                .forEach(student -> System.out.println(student.getName() + ": " + student.getScore()));

        // count: 개수 세기
        long count = students.stream()
                .filter(student -> student.getScore() >= 80)
                .count();
        System.out.println("80점 이상 인원: " + count + "명"); // 2명
    }
}
```

**설명**: `forEach`와 `count`는 둘 다 스트림을 "끝내는" 종단 연산입니다. 한 번 종단 연산이 실행되면 그 스트림은 소비되어 다시 사용할 수 없으므로, `students.stream()`을 각 파이프라인마다 새로 호출해야 합니다.

## 5. `Collectors`로 결과 모으기

`collect()`는 스트림의 요소들을 원하는 자료구조로 모아주는 종단 연산입니다. `java.util.stream.Collectors`가 제공하는 대표적인 수집기를 사용합니다.

| 수집기 | 역할 | 예시 |
|---|---|---|
| `Collectors.toList()` | 요소들을 `List`로 모음 | `collect(Collectors.toList())` |
| `Collectors.joining(구분자)` | 문자열들을 하나의 문자열로 이어 붙임 | `collect(Collectors.joining(", "))` |
| `Collectors.groupingBy(분류기준)` | 분류 기준별로 묶어서 `Map`으로 모음 | 아래 예시 참고 |

```java
public class StreamCollectorsExample {
    public static void main(String[] args) {
        List<Student> students = new ArrayList<>();
        students.add(new Student("홍길동", 92));
        students.add(new Student("김철수", 78));
        students.add(new Student("이영희", 85));

        // joining: 이름들을 ", "로 이어붙인 하나의 문자열로 만들기
        String names = students.stream()
                .map(student -> student.getName())
                .collect(Collectors.joining(", "));
        System.out.println(names); // 홍길동, 김철수, 이영희

        // groupingBy: 합격(90점 이상)/불합격으로 묶어서 Map으로 모으기
        Map<Boolean, List<Student>> grouped = students.stream()
                .collect(Collectors.groupingBy(student -> student.getScore() >= 90));

        System.out.println("합격: " + grouped.get(true).size() + "명");   // 1명
        System.out.println("불합격: " + grouped.get(false).size() + "명"); // 2명
    }
}
```

**설명**: `groupingBy`에 전달하는 람다식은 "각 요소를 어떤 기준(key)으로 분류할지"를 정합니다. 여기서는 `student.getScore() >= 90`이 `true`/`false` 중 하나로 평가되므로, 결과는 `Map<Boolean, List<Student>>` 형태가 됩니다. 기준을 `student.getName().charAt(0)`처럼 바꾸면 성씨별 그룹핑도 가능합니다.

## 자주 하는 실수

1. **종단 연산 없이 파이프라인만 만들고 끝내기**
   ```java
   students.stream().filter(student -> student.getScore() >= 90); // 아무 일도 일어나지 않음!
   ```
   중간 연산은 "게으르게(lazy)" 동작하므로, `forEach`나 `collect` 같은 종단 연산이 없으면 실제로는 아무 요소도 처리되지 않습니다.

2. **이미 사용한 스트림을 재사용하려는 시도**
   ```java
   Stream<Student> stream = students.stream();
   stream.forEach(student -> System.out.println(student));
   stream.count(); // 예외 발생! IllegalStateException: stream has already been operated upon or closed
   ```
   스트림은 1회용입니다. 다시 쓰려면 `students.stream()`을 새로 호출해야 합니다.

3. **`map`과 `filter`의 역할을 헷갈림**
   ```java
   // filter는 "걸러내기"(boolean 조건), map은 "바꾸기"(값 변환) — 서로 대체 불가
   students.stream().map(student -> student.getScore() >= 90); // 컴파일은 되지만 의미가 다름(Boolean 스트림이 됨)
   ```

4. **`collect(Collectors.toList())`를 잊고 대입하려는 시도**
   ```java
   List<String> names = students.stream().map(student -> student.getName()); // 컴파일 에러! Stream<String>은 List가 아님
   ```
   반드시 `.collect(Collectors.toList())`로 스트림을 리스트로 변환해야 합니다.

## 핵심 요약

| 항목 | 핵심 내용 |
|---|---|
| 스트림의 3단계 | 생성(`stream()`) → 중간 연산(`filter`, `map`, `sorted`, ...) → 종단 연산(`forEach`, `count`, `collect`, ...) |
| 중간 연산 | 스트림을 반환하므로 체이닝 가능, 종단 연산이 있어야 실제로 실행됨(lazy) |
| 종단 연산 | 스트림을 소비하여 최종 결과를 반환, 한 스트림당 1회만 사용 가능 |
| `filter` | 조건에 맞는 요소만 남김 (걸러내기) |
| `map` | 요소를 다른 값/타입으로 변환함 (바꾸기) |
| `Collectors.toList()` | 스트림 결과를 `List`로 모음 |
| `Collectors.groupingBy()` | 분류 기준별로 묶어서 `Map`으로 모음 |
