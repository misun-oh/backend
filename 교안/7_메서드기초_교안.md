# Day 7. 메서드(함수) 기초

## 학습목표
- 메서드를 정의하고 호출하는 문법을 이해할 수 있다

- void 메서드와 값을 반환하는 메서드의 차이를 구분할 수 있다

---

## 1. 메서드란?

메서드(method)는 특정 기능을 수행하는 코드 묶음입니다. 지금까지 사용해온 `main` 메서드도 메서드의 한 종류입니다. 같은 코드를 여러 번 반복 작성하는 대신, 메서드로 만들어두면 필요할 때마다 이름으로 불러서(호출) 재사용할 수 있습니다.

---

## 2. 메서드 정의 문법

```java
public class 메서드예제 {
    // 메서드 정의: 반환형 메서드이름(매개변수) { 실행할 코드 }
    public static void 인사하기() {
        System.out.println("안녕하세요!");
    }

    public static void main(String[] args) {
        인사하기(); // 메서드 호출
        인사하기(); // 여러 번 재사용 가능
    }
}
```

**구조**: `반환형 메서드이름(매개변수) { 코드 }`
- `public static` : 접근 방식(지금은 고정된 형식으로 사용, 자세한 의미는 Day 9~10에서)
- `void` : 반환값이 없다는 뜻 (아래 3번에서 자세히)
- `인사하기()` : 메서드 이름과 괄호(매개변수가 없으면 빈 괄호)

**주의**: 메서드는 반드시 클래스 안에, `main` 메서드와 같은 레벨(형제 관계)로 정의해야 합니다. 메서드 안에 또 다른 메서드를 정의할 수는 없습니다.

---

## 3. void 메서드 vs 값을 반환하는 메서드

| 구분 | 설명 | 예시 |
|---|---|---|
| `void` 메서드 | 결과값을 돌려주지 않고, 그냥 실행만 함 | `public static void 인사하기()` |
| 반환형이 있는 메서드 | 계산 결과를 `return`으로 돌려줌 | `public static int 더하기(...)` |

```java
public class 반환예제 {
    // void: 반환값 없음, 그냥 출력만 함
    public static void 결과출력(int 값) {
        System.out.println("결과: " + 값);
    }

    // int: 계산 결과를 반환함
    public static int 더하기(int a, int b) {
        int 결과 = a + b;
        return 결과; // 이 메서드를 호출한 곳으로 결과값을 돌려줌
    }

    public static void main(String[] args) {
        결과출력(10); // 그냥 실행만 하고 끝, 돌려받는 값 없음

        int 합 = 더하기(3, 5); // 반환값(8)을 합 변수에 저장
        System.out.println(합); // 8
    }
}
```

**설명**: `return`은 메서드의 실행을 즉시 종료하고, 지정한 값을 호출한 곳으로 돌려줍니다. `void` 메서드는 `return;`(값 없이)으로 중간에 종료할 수는 있지만, 값을 돌려줄 수는 없습니다. 반환형이 있는 메서드는 반드시 모든 실행 경로에서 해당 자료형의 값을 `return`해야 합니다.

## 4. 매개변수 (Parameter)

메서드를 호출할 때 값을 전달하려면 매개변수를 사용합니다.

```java
public class 매개변수예제 {
    // 매개변수 1개
    public static void 이름출력(String 이름) {
        System.out.println("이름: " + 이름);
    }

    // 매개변수 여러 개
    public static double 평균계산(int 국어, int 영어, int 수학) {
        return (국어 + 영어 + 수학) / 3.0;
    }

    public static void main(String[] args) {
        이름출력("홍길동"); // "홍길동"이 매개변수 이름에 전달됨

        double 평균 = 평균계산(90, 85, 78); // 세 값이 순서대로 전달됨
        System.out.printf("평균: %.2f%n", 평균);
    }
}
```

**설명**: 메서드를 호출할 때 괄호 안에 넘긴 값(인자, argument)은 메서드 정의부의 매개변수(parameter) 순서에 맞춰 전달됩니다. 매개변수 개수와 자료형이 정확히 일치해야 호출할 수 있습니다.

---

## 자주 하는 실수

1. **반환형이 있는데 return을 빠뜨림**
   ```java
   public static int 더하기(int a, int b) {
       int 결과 = a + b;
       // return 결과; 를 빠뜨리면 컴파일 에러: "missing return statement"
   }
   ```

2. **void 메서드인데 값을 반환하려고 시도**
   ```java
   public static void 계산(int a, int b) {
       return a + b; // 컴파일 에러: void는 값을 반환할 수 없음
   }
   ```

3. **매개변수 개수/순서 불일치**
   ```java
   public static double 평균계산(int 국어, int 영어, int 수학) { ... }
   평균계산(90, 85); // 컴파일 에러: 매개변수 3개가 필요한데 2개만 전달함
   ```

4. **메서드 호출 시 반환값을 받지 않고 버림**
   ```java
   더하기(3, 5); // 계산은 되지만 결과를 어디에도 저장하지 않아 사용할 수 없음
   int 합 = 더하기(3, 5); // 올바른 사용: 반환값을 변수에 저장
   ```

## 핵심 요약

| 항목 | 핵심 내용 |
|---|---|
| 메서드 정의 | `반환형 메서드이름(매개변수) { 코드 }` |
| void | 반환값이 없는 메서드 |
| return | 값을 계산해서 호출한 곳으로 돌려줌, 반환형이 있으면 필수 |
| 매개변수 | 메서드 호출 시 전달하는 값, 개수·순서·자료형이 일치해야 함 |
| 메서드 호출 | `메서드이름(인자1, 인자2, ...)` |
