## 기본

### 문제 1. 파일에 문자열 쓰기

```java
// SubjectWriteAnswer.java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.util.List;

public class SubjectWriteAnswer {
    public static void main(String[] args) throws IOException {
        List<String> subjects = List.of("국어", "영어", "수학");

        try (BufferedWriter writer = new BufferedWriter(new FileWriter("subjects.txt", StandardCharsets.UTF_8))) {
            for (String subject : subjects) {
                writer.write(subject);
                writer.newLine();
            }
        }
    }
}
```

**설명**: `List.of(...)`로 만든 과목 목록을 순회하면서, `write()`로 과목명을 쓰고 `newLine()`으로 줄을 바꿉니다. `BufferedWriter`/`FileWriter` 모두 try-with-resources 괄호 안에서 선언했으므로, 블록이 끝나면 자동으로 `close()`가 호출되어 버퍼에 남은 내용까지 안전하게 파일에 반영됩니다.

### 문제 2. 파일에서 문자열 읽기

```java
// SubjectReadAnswer.java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
import java.nio.charset.StandardCharsets;

public class SubjectReadAnswer {
    public static void main(String[] args) throws IOException {
        try (BufferedReader reader = new BufferedReader(new FileReader("subjects.txt", StandardCharsets.UTF_8))) {
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
        }
    }
}
```

**출력 결과**
```
국어
영어
수학
```

**설명**: `readLine()`은 파일의 끝에 도달하면 `null`을 반환합니다. `while ((line = reader.readLine()) != null)`은 "한 줄 읽기"와 "끝인지 확인"을 동시에 하는 관용구입니다.

### 문제 3. 사원 정보를 CSV로 저장하고 다시 불러오기

```java
// Emp.java
public class Emp {
    private String empId;
    private String empName;
    private int salary;

    public Emp(String empId, String empName, int salary) {
        this.empId = empId;
        this.empName = empName;
        this.salary = salary;
    }

    public String getEmpId() { return empId; }
    public String getEmpName() { return empName; }
    public int getSalary() { return salary; }
}
```

```java
// EmpCsvAnswer.java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;

public class EmpCsvAnswer {
    public static void save(List<Emp> employees, String fileName) throws IOException {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter(fileName, StandardCharsets.UTF_8))) {
            for (Emp emp : employees) {
                writer.write(emp.getEmpId() + "," + emp.getEmpName() + "," + emp.getSalary());
                writer.newLine();
            }
        }
    }

    public static List<Emp> load(String fileName) throws IOException {
        List<Emp> result = new ArrayList<>();
        try (BufferedReader reader = new BufferedReader(new FileReader(fileName, StandardCharsets.UTF_8))) {
            String line;
            while ((line = reader.readLine()) != null) {
                String[] fields = line.split(",");
                result.add(new Emp(fields[0], fields[1], Integer.parseInt(fields[2])));
            }
        }
        return result;
    }

    public static void main(String[] args) throws IOException {
        List<Emp> employees = List.of(
                new Emp("101", "박민수", 2500000),
                new Emp("102", "최지은", 3200000),
                new Emp("103", "정다은", 2900000)
        );

        save(employees, "emp.csv");

        List<Emp> loaded = load("emp.csv");
        for (Emp emp : loaded) {
            System.out.println("사번:" + emp.getEmpId() + " 이름:" + emp.getEmpName() + " 급여:" + emp.getSalary());
        }
    }
}
```

**출력 결과**
```
사번:101 이름:박민수 급여:2500000
사번:102 이름:최지은 급여:3200000
사번:103 이름:정다은 급여:2900000
```

**설명**: `save()`는 `Emp`의 세 필드를 콤마로 이어붙여 한 줄씩 씁니다. `load()`는 그 반대로 `split(",")`한 결과를 다시 `Emp` 생성자에 넘겨 객체로 복원합니다. `salary`는 문자열로 저장되므로 다시 읽을 때 `Integer.parseInt(fields[2])`로 정수로 변환해야 한다는 점에 주의해야 합니다.

### 문제 4. 람다식/스트림으로 파일 내용 필터링

```java
// EmpFilterAnswer.java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.util.List;
import java.util.stream.Collectors;

public class EmpFilterAnswer {
    public static void main(String[] args) throws IOException {
        try (BufferedReader reader = new BufferedReader(new FileReader("emp.csv", StandardCharsets.UTF_8))) {
            List<String> names = reader.lines()
                    .map(line -> line.split(","))
                    .filter(fields -> Integer.parseInt(fields[2]) >= 2800000)
                    .map(fields -> fields[1])
                    .collect(Collectors.toList());

            System.out.println(names);
        }
    }
}
```

**출력 결과**
```
[최지은, 정다은]
```

**설명**: 박민수(250만원)는 조건(280만원 이상)에 못 미쳐 제외되고, 최지은(320만원)과 정다은(290만원)만 남습니다. `map(line -> line.split(","))`으로 필드 배열을 만들고, `filter(...)`로 급여 조건을 검사한 뒤, 다시 `map(fields -> fields[1])`로 이름만 뽑아냈습니다.

### 문제 5. Path/Files로 폴더 만들고 텍스트 저장/읽기

```java
// PathFilesAnswer.java
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;

public class PathFilesAnswer {
    public static void main(String[] args) throws IOException {
        Path dir = Path.of("report", "2026");
        Files.createDirectories(dir);

        Path file = dir.resolve("summary.txt");
        Files.writeString(file, "연간 보고서");

        String content = Files.readString(file);
        System.out.println(content);
    }
}
```

**출력 결과**
```
연간 보고서
```

**설명**: `Path.of("report", "2026")`는 `report/2026`이라는 경로를 표현하고, `Files.createDirectories()`는 `report` 폴더가 없어도 `report`와 `report/2026`을 한 번에 만듭니다. `Files.writeString()`/`Files.readString()`(Java 11+)을 쓰면 `BufferedWriter`/`BufferedReader`를 직접 감쌀 필요 없이 한 줄로 문자열을 저장·조회할 수 있습니다.

### 문제 6. 파일명 충돌 방지

```java
// FileUploadAnswer.java
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.UUID;

public class FileUploadAnswer {
    public static Path saveUploadedFile(String originalFileName, byte[] content) throws IOException {
        Path dir = Path.of("uploads");
        Files.createDirectories(dir);

        String ext = originalFileName.substring(originalFileName.lastIndexOf('.'));
        String savedName = UUID.randomUUID() + ext;

        Path savedPath = dir.resolve(savedName);
        Files.write(savedPath, content);

        return savedPath;
    }

    public static void main(String[] args) throws IOException {
        Path path1 = saveUploadedFile("프로필.png", "첫 번째 사진".getBytes());
        Path path2 = saveUploadedFile("프로필.png", "두 번째 사진".getBytes());

        System.out.println(path1);
        System.out.println(path2);
        System.out.println(path1.equals(path2)); // false -> 서로 다른 파일로 저장됨
    }
}
```

**출력 결과 (예시 — UUID 값은 실행할 때마다 달라짐)**
```
uploads\22c2db40-5e56-4877-aa49-f3a346e1739b.png
uploads\73f8f34a-434f-4dac-a183-9d58173c4e34.png
false
```

**설명**: 원본 파일명(`"프로필.png"`)이 완전히 같아도, `UUID.randomUUID()`가 매번 다른 문자열을 만들어주기 때문에 실제 저장 경로(`path1`, `path2`)는 서로 다릅니다. `path1.equals(path2)`가 `false`라는 것은 두 파일이 서로 덮어쓰지 않고 **둘 다 살아있다**는 뜻입니다. `uploads` 폴더를 직접 열어봐도 `.png` 파일이 2개 있는 것을 확인할 수 있습니다.

### 문제 7. 종합 - 버퍼 사용 유무 속도 비교

```java
// SpeedCompareAnswer.java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;
import java.nio.charset.StandardCharsets;

public class SpeedCompareAnswer {
    public static void main(String[] args) throws IOException {
        int count = 20_000;

        long start1 = System.currentTimeMillis();
        try (FileWriter writer = new FileWriter("no_buffer.txt", StandardCharsets.UTF_8)) {
            for (int i = 0; i < count; i++) {
                writer.write("데이터" + i + "\n");
            }
        }
        long noBufferMs = System.currentTimeMillis() - start1;

        long start2 = System.currentTimeMillis();
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("with_buffer.txt", StandardCharsets.UTF_8))) {
            for (int i = 0; i < count; i++) {
                writer.write("데이터" + i);
                writer.newLine();
            }
        }
        long bufferMs = System.currentTimeMillis() - start2;

        System.out.println("버퍼 없이: " + noBufferMs + "ms");
        System.out.println("버퍼 사용: " + bufferMs + "ms");
    }
}
```

**실제 측정 결과 (예시 — 환경에 따라 절대값은 달라짐)**
```
버퍼 없이: 46ms
버퍼 사용: 13ms
```

**설명**: 2만 번의 `write()` 호출이 각각 디스크 접근으로 이어지는 `FileWriter`만 쓴 경우가, 8192자씩 모아서 디스크에 접근하는 `BufferedWriter`를 쓴 경우보다 뚜렷하게 느립니다. 반복 횟수를 늘릴수록(예: 20만 번) 이 차이는 더 커집니다.
