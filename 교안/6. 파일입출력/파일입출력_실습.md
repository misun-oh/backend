# 부록 7. 파일 입출력 - 실습

> 아래 문제는 교안에서 다룬 `FileWriter`/`BufferedWriter`, `FileReader`/`BufferedReader`, try-with-resources, `Charset` 지정, CSV 저장/파싱, `BufferedReader.lines()`(람다/스트림), `Path`/`Files`, UUID를 이용한 파일명 충돌 방지만으로 풀 수 있습니다.

---

## 기본

### 문제 1. 파일에 문자열 쓰기
`BufferedWriter`(+`FileWriter`, `StandardCharsets.UTF_8`)를 이용해서 `"국어"`, `"영어"`, `"수학"`을 `subjects.txt`에 한 줄씩 쓰세요. try-with-resources를 사용하세요.

**확인할 것**: 실행 후 `subjects.txt` 파일이 실제로 생기고, 안에 세 과목명이 한 줄씩 들어있는지 확인합니다. (콘솔 출력 없음)

---

### 문제 2. 파일에서 문자열 읽기
문제 1에서 만든 `subjects.txt`를 `BufferedReader`(+`FileReader`)로 읽어서 한 줄씩 화면에 출력하세요. `while ((line = reader.readLine()) != null)` 패턴을 사용하세요.

**Output**
```
국어
영어
수학
```

---

## 응용

### 문제 3. 사원 정보를 CSV로 저장하고 다시 불러오기
`empId`(String), `empName`(String), `salary`(int) 세 필드를 가진 `Emp` 클래스를 만드세요. 아래 세 명의 사원을 `emp.csv`에 `"사번,이름,급여"` 형태로 저장(`save`)하고, 다시 읽어(`load`) 화면에 출력하세요.

- `("101", "박민수", 2500000)`
- `("102", "최지은", 3200000)`
- `("103", "정다은", 2900000)`

**Output**
```
사번:101 이름:박민수 급여:2500000
사번:102 이름:최지은 급여:3200000
사번:103 이름:정다은 급여:2900000
```

---

### 문제 4. 람다식/스트림으로 파일 내용 필터링
문제 3에서 만든 `emp.csv`를 `BufferedReader.lines()`로 읽어서, 급여가 280만원 이상인 사원의 이름만 `List<String>`으로 모아 출력하세요. (`map`/`filter`/`collect` 활용)

**Output**
```
[최지은, 정다은]
```

---

### 문제 5. Path/Files로 폴더 만들고 텍스트 저장/읽기
`java.nio.file.Path`/`Files`를 이용해서 `report/2026` 폴더를 만드세요(중간 폴더가 없어도 한 번에 생성). 그 안에 `summary.txt` 파일을 만들어 `"연간 보고서"`라는 문자열을 저장(`Files.writeString`)하고, 다시 읽어(`Files.readString`) 출력하세요.

**Output**
```
연간 보고서
```

## 도전

### 문제 6. 파일명 충돌 방지
`saveUploadedFile(String originalFileName, byte[] content)` 메서드를 만드세요. `UUID.randomUUID()`로 저장용 파일명을 새로 만들어서(원본 확장자는 유지) `uploads` 폴더 밑에 저장하고, 저장된 경로를 반환합니다. `"프로필.png"`라는 같은 이름으로 서로 다른 내용을 두 번 저장했을 때, 두 파일이 서로 덮어쓰지 않고 둘 다 남아있는지 확인하세요.

**확인할 것**: `uploads` 폴더 안에 `.png` 파일이 2개 생기고, 각 파일 내용이 서로 다른지 확인합니다.

### 문제 7. 종합 - 버퍼 사용 유무 속도 비교
정수 `20000`을 반복 횟수로 해서, ① `FileWriter`만 사용해서 `"데이터" + i`를 한 줄씩 쓰는 데 걸린 시간과, ② `BufferedWriter`로 감싸서 쓰는 데 걸린 시간을 각각 `System.currentTimeMillis()`로 측정해 밀리초 단위로 출력하세요.

**확인할 것**: 두 시간을 출력하고, 버퍼를 사용한 쪽이 더 빠른지 비교합니다. (정확한 ms 값은 실행 환경마다 다르므로 Output을 정해두지 않습니다)
