## 기본

### 문제 1. 나의 정보 출력하기

```java
public class Practice1 {
    public static void main(String[] args) {
        String 이름 = "홍길동";
        int 나이 = 20;
        double 키 = 175.5;
        boolean 재학여부 = true;

        System.out.println("이름: " + 이름);
        System.out.println("나이: " + 나이);
        System.out.println("키: " + 키);
        System.out.println("재학 여부: " + 재학여부);
    }
}
```

**설명**: `String`은 8가지 기본 자료형에는 속하지 않지만 문자열을 다룰 때 필수이므로 함께 사용했습니다. `+` 연산자는 문자열과 다른 자료형을 이어 붙일 때 자동으로 문자열로 변환해줍니다.

**틀리기 쉬운 포인트**: `이름`을 작은따옴표(`'`)로 감싸면 컴파일 에러가 납니다. 작은따옴표는 `char`(문자 1개) 전용이고, 문자열은 반드시 큰따옴표(`"`)를 사용해야 합니다.

### 문제 2. 한 줄로 출력하기

```java
public class Practice2 {
    public static void main(String[] args) {
        String 이름 = "홍길동";
        String 학번 = "20260001";

        System.out.print("이름: ");
        System.out.print(이름);
        System.out.print(", 학번: ");
        System.out.println(학번); // 마지막만 println으로 줄바꿈
    }
}
```

**설명**: `print`는 줄바꿈 없이 이어서 출력되므로, 중간까지는 `print`를 쓰고 마지막에만 `println`을 써서 한 줄을 완성한 뒤 줄바꿈합니다.

**틀리기 쉬운 포인트**: 모든 문장을 `print`로만 쓰면 다음 실행 결과가 이어서 같은 줄에 출력되어 화면이 지저분해집니다. 한 줄 출력이 끝나는 지점에는 반드시 `println`을 사용해야 합니다.

## 응용

### 문제 3. 형변환 연습

```java
public class Practice3 {
    public static void main(String[] args) {
        double 원래값 = 3.9;
        int 형변환값 = (int) 원래값; // 강제 형변환, 소수점 버림

        System.out.println("원래 값: " + 원래값);
        System.out.println("형변환 후 값: " + 형변환값);
    }
}
```

**설명**: `(int) 원래값`은 `double`을 `int`로 강제 형변환합니다. 이때 소수점 이하는 반올림되지 않고 그냥 버려집니다(`3.9` → `3`).

**틀리기 쉬운 포인트**: 형변환이 반올림이라고 착각하기 쉬운데, `int` 캐스팅은 항상 소수점을 버립니다(내림이 아니라 절삭). `3.9`뿐 아니라 `3.1`도 캐스팅하면 똑같이 `3`이 됩니다.

### 문제 4. 학생 성적 출력 (printf 활용)

```java
public class Practice4 {
    public static void main(String[] args) {
        double 평점 = 3.856;

        System.out.printf("평점: %.2f%n", 평점);
    }
}
```

**설명**: `%.2f`는 소수점 둘째 자리까지 출력하되, 셋째 자리에서 반올림합니다. 그래서 `3.856`은 `3.86`으로 출력됩니다. `%n`은 줄바꿈을 의미합니다.

**틀리기 쉬운 포인트**: 형변환 `(int)`는 버림이지만, `printf`의 `%.2f`는 반올림이라는 차이를 헷갈리지 않아야 합니다.

### 문제 5. 자료형별 변수 선언

```java
public class Practice5 {
    public static void main(String[] args) {
        byte b = 10;
        short s = 100;
        int i = 1000;
        long l = 10000000000L;   // long은 값 뒤에 L 필수
        float f = 3.14f;          // float은 값 뒤에 f 필수
        double d = 3.141592;
        char c = 'A';
        boolean bool = true;

        System.out.println("byte: " + b);
        System.out.println("short: " + s);
        System.out.println("int: " + i);
        System.out.println("long: " + l);
        System.out.println("float: " + f);
        System.out.println("double: " + d);
        System.out.println("char: " + c);
        System.out.println("boolean: " + bool);
    }
}
```

**설명**: `long`에 `L`을 붙이는 이유는 기본적으로 정수 리터럴이 `int`로 처리되기 때문입니다. `10000000000`은 `int` 범위(약 21억)를 넘어서므로 `L`이 없으면 컴파일 에러가 납니다. 마찬가지로 `float`도 기본 실수 리터럴이 `double`로 처리되므로 `f`를 붙여야 합니다.

**틀리기 쉬운 포인트**: `int` 범위를 넘지 않는 작은 `long` 값(예: `long l = 100;`)은 `L`을 안 붙여도 자동 형변환되어 컴파일되지만, 습관적으로 항상 붙이는 것이 안전합니다.

## 도전

### 문제 6. 정수 나눗셈 결과를 실수로 출력

```java
public class Practice6 {
    public static void main(String[] args) {
        int a = 7;
        int b = 2;

        double 결과 = (double) a / b; // a를 먼저 double로 캐스팅 후 나눗셈

        System.out.println(a + " / " + b + " = " + 결과);
    }
}
```

**설명**: `a / b`를 캐스팅 없이 그대로 계산하면 `int / int`라서 소수점이 버려집니다(`3`). `(double) a`로 `a`를 먼저 실수로 바꾼 뒤 나눗셈하면, 나눗셈 전체가 실수 연산으로 처리되어 `3.5`가 정확히 나옵니다.

**틀리기 쉬운 포인트**: `(double) (a / b)`처럼 나눗셈 **결과**를 캐스팅하면 이미 정수 나눗셈이 끝난 뒤(`3`)라 `3.0`이 되어버립니다. 캐스팅은 나눗셈 **전에** 피연산자에 적용해야 합니다.

### 문제 7. 학과 정보를 한글 변수로 출력하기

```java
public class Practice7 {
    public static void main(String[] args) {
        String 학과번호 = "CS001";
        String 학과명 = "컴퓨터공학과";
        int 정원 = 40;
        boolean 개설여부 = true;

        System.out.printf("[%s] 정원 %d명, 개설여부 %b%n", 학과명, 정원, 개설여부);
    }
}
```

**설명**: `printf`의 형식 지정자는 순서대로 뒤에 나열된 값에 매칭됩니다. `%s`는 문자열(`학과명`), `%d`는 정수(`정원`), `%b`는 boolean(`개설여부`)에 대응합니다. `%b`는 `true`/`false` 값을 그대로 문자열처럼 출력해주는 지정자입니다.

**틀리기 쉬운 포인트**: `printf`에 넘기는 값의 **순서와 개수**가 형식 지정자와 정확히 일치해야 합니다. 순서가 바뀌면(예: `정원`과 `개설여부` 위치를 바꾸면) `%d` 자리에 boolean 값이 들어가 예외(`IllegalFormatConversionException`)가 발생합니다.
