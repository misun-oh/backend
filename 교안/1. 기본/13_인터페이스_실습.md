# Day 13. 인터페이스 - 실습

> 아래 문제는 교안에서 다룬 interface, implements, 인터페이스 참조 변수 다형성, 다중 구현만으로 풀 수 있습니다.

---

## 기본

### 문제 1. 인터페이스 정의와 구현
`Soundable` 인터페이스(추상 메서드 `makeSound(): void`)를 정의하고, `Dog` 클래스가 이를 구현하도록 만드세요. `Dog`의 `makeSound()`는 "멍멍!"을 출력합니다.

**Output**
```
멍멍!
```

---

### 문제 2. 서로 관계없는 두 클래스가 같은 인터페이스 구현
문제 1의 `Soundable`을 `Cat` 클래스도 구현하도록 만드세요(`makeSound()`는 "야옹"). `Dog`와 `Cat`는 서로 상속 관계가 없습니다.

**Output**
```
멍멍!
야옹
```

---

## 응용

### 문제 3. 인터페이스 배열로 다형성 활용
문제 1~2의 `Dog`, `Cat` 객체를 `Soundable[]` 배열에 담고, 반복문으로 모두의 `makeSound()`를 호출하세요.

**Output**
```
멍멍!
야옹
```

---

### 문제 4. 상속 + 인터페이스 함께 사용
`Printable` 인터페이스(`printInfo(): void`)를 정의하세요. `Professor` 클래스가 (교안에서 정의한) `Person`을 상속받으면서 동시에 `Printable`도 구현하도록 만드세요. `printInfo()`은 "[교수] 이름: OOO, 교수번호: OOO"을 출력합니다.

**Output**
```
[교수] 이름: 김교수, 교수번호: P001
```

---

## 도전

### 문제 5. 상속 관계가 다른 여러 클래스를 인터페이스로 묶기
문제 4의 `Printable`을 `Student`(`Person`을 상속)과 `Course`(아무것도 상속받지 않음)도 함께 구현하도록 만드세요. `Printable[]` 배열에 학생, 교수, 강좌 객체를 모두 담고 반복문으로 정보를 출력하세요.

**Output**
```
[학생] 이름: 홍길동, 학번: S001
[교수] 이름: 김교수, 교수번호: P001
[강좌] 강좌명: 자바프로그래밍, 정원: 30
```

---

### 문제 6. 종합 - 인터페이스 2개 동시 구현
`Printable`과 `Savable`(`save(): void`) 두 인터페이스를 `Student` 클래스가 동시에 구현하도록 만드세요. `save()`은 "OOO 학생 정보를 저장했습니다."를 출력합니다. `Student` 객체를 만들어 `printInfo()`과 `save()`을 순서대로 호출하세요.

**Output**
```
[학생] 이름: 홍길동, 학번: S001
홍길동 학생 정보를 저장했습니다.
```
