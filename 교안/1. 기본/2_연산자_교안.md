## 1. 산술 연산자

두 값을 더하고 빼고 곱하고 나누는 데 사용합니다.

| 연산자 | 설명 | 예시 |
|---|---|---|
| `+` | 더하기 | `5 + 2` → `7` |
| `-` | 빼기 | `5 - 2` → `3` |
| `*` | 곱하기 | `5 * 2` → `10` |
| `/` | 나누기 | `5 / 2` → `2` (int끼리는 소수점 버림) |
| `%` | 나머지 | `5 % 2` → `1` |

```java
public class 산술연산예제 {
    public static void main(String[] args) {
        int a = 7, b = 2;
        System.out.println(a + b); // 9
        System.out.println(a - b); // 5
        System.out.println(a * b); // 14
        System.out.println(a / b); // 3
        System.out.println(a % b); // 1
    }
}
```

**주의**: `int / int`는 결과도 `int`이므로 소수점이 버려집니다(Day 1의 형변환 참고).

## 2. 비교 연산자

두 값을 비교해서 `boolean`(true/false) 결과를 반환합니다.

| 연산자 | 설명 | 예시 |
|---|---|---|
| `>` | 크다 | `5 > 2` → `true` |
| `<` | 작다 | `5 < 2` → `false` |
| `>=` | 크거나 같다 | `5 >= 5` → `true` |
| `<=` | 작거나 같다 | `5 <= 4` → `false` |
| `==` | 같다 | `5 == 5` → `true` |
| `!=` | 다르다 | `5 != 5` → `false` |

```java
public class 비교연산예제 {
    public static void main(String[] args) {
        int 국어 = 80, 영어 = 90;
        System.out.println(국어 > 영어);   // false
        System.out.println(국어 != 영어);  // true
        System.out.println(국어 == 80);    // true
    }
}
```

**주의**: `==`은 대입 연산자 `=`와 다릅니다. `==`은 "같은지 비교", `=`는 "값을 저장"하는 연산자입니다.

## 3. 논리 연산자

여러 조건을 결합할 때 사용합니다.

| 연산자 | 설명 | 예시 |
|---|---|---|
| `&&` | 그리고(AND), 둘 다 참이어야 true | `(5>2) && (3>1)` → `true` |
| `\|\|` | 또는(OR), 하나만 참이어도 true | `(5>2) \|\| (1>3)` → `true` |
| `!` | 부정(NOT), true/false를 반대로 | `!(5>2)` → `false` |

```java
public class 논리연산예제 {
    public static void main(String[] args) {
        int 나이 = 20;
        boolean 성인여부 = 나이 >= 20;
        boolean 학생여부 = true;

        System.out.println(성인여부 && 학생여부);  // true && true → true
        System.out.println(성인여부 || false);     // true || false → true
        System.out.println(!성인여부);              // !true → false
    }
}
```

**설명**: `&&`는 왼쪽 조건이 `false`이면 오른쪽은 확인하지 않고 바로 `false`를 반환합니다(단락 평가). `||`도 왼쪽이 `true`이면 오른쪽을 확인하지 않고 바로 `true`를 반환합니다.

## 4. 대입 연산자 (복합 대입)

기본 대입(`=`) 외에, 연산과 대입을 한 번에 처리하는 복합 대입 연산자가 있습니다.

| 연산자 | 의미 | 예시 |
|---|---|---|
| `=` | 오른쪽 값을 왼쪽에 저장 | `x = 10;` |
| `+=` | `x = x + 값` | `x += 5;` |
| `-=` | `x = x - 값` | `x -= 5;` |
| `*=` | `x = x * 값` | `x *= 5;` |
| `/=` | `x = x / 값` | `x /= 5;` |
| `%=` | `x = x % 값` | `x %= 5;` |

```java
public class 대입연산예제 {
    public static void main(String[] args) {
        int x = 10;
        x += 5;   // x = x + 5 → 15
        System.out.println(x);
        x *= 2;   // x = x * 2 → 30
        System.out.println(x);
    }
}
```

## 5. 증감 연산자 (전위/후위)

값을 1 증가시키거나 감소시킵니다. 변수 앞에 붙이는지(전위), 뒤에 붙이는지(후위)에 따라 **다른 식 안에서 사용할 때** 동작 차이가 있습니다.

| 연산자 | 설명 | 예시 |
|---|---|---|
| `++변수` | 전위 증가: 먼저 증가시킨 후 그 값을 사용 | `int b = ++a;` |
| `변수++` | 후위 증가: 먼저 그 값을 사용한 후 증가 | `int b = a++;` |
| `--변수` | 전위 감소 | `--a;` |
| `변수--` | 후위 감소 | `a--;` |

```java
public class 증감연산예제 {
    public static void main(String[] args) {
        int a = 5;
        int b = ++a; // a를 먼저 6으로 만들고, 그 값을 b에 저장
        System.out.println("a=" + a + ", b=" + b); // a=6, b=6

        int c = 5;
        int d = c++; // c의 현재값(5)을 먼저 d에 저장한 후, c를 6으로 만듦
        System.out.println("c=" + c + ", d=" + d); // c=6, d=5
    }
}
```

**설명**: 단독으로 `a++;`처럼 한 줄에 쓸 때는 전위든 후위든 결과가 같습니다. 차이는 **다른 대입식과 함께** 쓸 때만 나타납니다.

## 6. 삼항 연산자

`조건 ? 참일때값 : 거짓일때값` 형태로, 간단한 if-else를 한 줄로 표현할 때 사용합니다.

| 연산자 | 설명 | 예시 |
|---|---|---|
| `조건 ? A : B` | 조건이 true면 A, false면 B | `(5>2) ? "크다" : "작다"` → `"크다"` |

```java
public class 삼항연산예제 {
    public static void main(String[] args) {
        int 점수 = 85;
        String 결과 = (점수 >= 60) ? "합격" : "불합격";
        System.out.println(결과); // 합격
    }
}
```

**설명**: `점수 >= 60`이 `true`이면 `"합격"`이, `false`이면 `"불합격"`이 `결과` 변수에 저장됩니다. 조건문(if-else)은 Day 3에서 본격적으로 다루며, 삼항 연산자는 그중 아주 간단한 경우를 한 줄로 줄인 표현입니다.

## 7. 연산자 우선순위

여러 연산자가 한 식에 섞여 있을 때 계산 순서가 정해져 있습니다. 대표적인 순서(높은 순→낮은 순)는 다음과 같습니다.

```
1순위: 증감(++, --), 부정(!)
2순위: 곱셈/나눗셈/나머지(*, /, %)
3순위: 덧셈/뺄셈(+, -)
4순위: 비교(<, >, <=, >=)
5순위: 동등 비교(==, !=)
6순위: 논리곱(&&)
7순위: 논리합(||)
8순위: 삼항(? :)
9순위: 대입(=, +=, ...)
```

```java
public class 우선순위예제 {
    public static void main(String[] args) {
        int result = 2 + 3 * 4;      // 곱셈이 먼저: 2 + 12 = 14
        System.out.println(result);

        boolean check = 5 > 2 && 3 > 1; // 비교가 먼저: true && true = true
        System.out.println(check);
    }
}
```

**팁**: 순서가 헷갈릴 때는 괄호 `()`를 사용해 명확하게 묶어주는 것이 안전하고 가독성도 좋습니다.

## 8. Scanner로 입력받기

지금까지는 변수에 값을 직접 대입했지만, 실제 프로그램은 사용자로부터 입력을 받아 연산하는 경우가 많습니다. `Scanner` 클래스를 사용합니다.

| 메서드 | 설명 | 예시 |
|---|---|---|
| `new Scanner(System.in)` | Scanner 객체 생성(입력 받을 준비) | `Scanner sc = new Scanner(System.in);` |
| `nextInt()` | 정수 하나를 입력받음 | `int n = sc.nextInt();` |
| `nextDouble()` | 실수 하나를 입력받음 | `double d = sc.nextDouble();` |
| `next()` | 공백 전까지 문자열 하나를 입력받음 | `String s = sc.next();` |
| `nextLine()` | 한 줄 전체(공백 포함)를 입력받음 | `String line = sc.nextLine();` |

`Scanner`는 `java.util` 패키지에 있으므로 파일 맨 위에 `import java.util.Scanner;`를 반드시 작성해야 합니다.

```java
import java.util.Scanner;

public class Scanner예제 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("첫 번째 정수: ");
        int a = sc.nextInt();
        System.out.print("두 번째 정수: ");
        int b = sc.nextInt();

        System.out.println("합: " + (a + b));
        System.out.println("두 수가 같은가요? " + (a == b));
    }
}
```

## 자주 하는 실수

1. **`=`(대입)과 `==`(비교) 혼동**
   ```java
   if (a = 5) { ... }   // 컴파일 에러: 대입 연산자를 조건문에 사용
   if (a == 5) { ... }  // 올바른 표현
   ```

2. **정수 나눗셈 소수점 버림**
   ```java
   System.out.println(5 / 2); // 2 (2.5가 아님, Day1 형변환 복습)
   ```

3. **전위/후위 증감 혼동**
   ```java
   int a = 5;
   int b = a++ + ++a; // a++: 5(사용 후 6), ++a: 7(먼저 증가) → b = 5 + 7 = 12
   ```
   전위/후위가 한 식에 섞이면 헷갈리기 쉬우므로, 실무에서는 가급적 증감을 별도 줄로 분리해서 작성합니다.

4. **nextInt() 다음 nextLine() 호출 시 개행문자 남는 문제**
   ```java
   int age = sc.nextInt();      // 숫자만 읽고 개행문자(\n)는 버퍼에 남음
   String name = sc.nextLine(); // 남아있던 개행문자를 즉시 읽어버려 빈 문자열이 됨
   ```
   해결: `nextInt()` 뒤에 `sc.nextLine();`을 한 번 더 호출해 개행문자를 비워줍니다.

| 항목 | 핵심 내용 |

| 비교 연산자 | `> < >= <= == !=`, 결과는 boolean |
| 논리 연산자 | `&& \|\| !`, 조건을 결합 |
| 대입 연산자 | `= += -= *= /= %=` |
| 증감 연산자 | 전위(`++a`)는 먼저 증가 후 사용, 후위(`a++`)는 먼저 사용 후 증가 |
| 삼항 연산자 | `조건 ? 참값 : 거짓값` |
| 우선순위 | 산술 > 비교 > 논리 > 삼항 > 대입, 헷갈리면 괄호 사용 |
| Scanner | `nextInt()`, `nextDouble()`, `next()`, `nextLine()`으로 입력 처리 |
