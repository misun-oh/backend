# Day 4. 참조 타입 개념 - 실습

> 아래 문제는 교안에서 다룬 기본형/참조형, ==와 equals, null과 NullPointerException 개념만으로 풀 수 있습니다.

---

## 기본

### 문제 1. == 결과 예측하고 확인하기
`new String("java")`로 문자열 두 개를 각각 만든 뒤, `==`과 `.equals()` 결과를 각각 출력하세요.

**Output**
```
== 결과: false
equals 결과: true
```

---

### 문제 2. null 확인하기
String 변수를 `null`로 선언하고 출력한 뒤, `if`문으로 `null`인지 확인해서 "값이 없습니다"를 출력하세요.

**Output**
```
null
값이 없습니다
```

---

## 응용

### 문제 3. 안전한 문자열 비교
Scanner로 문자열을 입력받아, 입력값이 `null`이 아니고 "hello"와 같으면(`.equals()`) "인사 감지"를 출력하고, 아니면 "다른 입력"을 출력하세요.

**Input**
```
hello
```

**Output**
```
인사 감지
```

---

### 문제 4. NullPointerException 재현하고 방어하기
String 변수를 `null`로 선언한 후, `.length()`를 직접 호출하면 어떤 일이 일어나는지 주석으로 설명을 남기고, 실제로는 `null` 체크 후 안전하게 처리하는 코드로 완성하세요.

**Output (null일 때)**
```
문자열이 null이라 길이를 확인할 수 없습니다.
```

---

## 도전

### 문제 5. 리터럴을 앞에 두는 안전한 equals 패턴
Scanner로 입력받은 문자열이 `null`일 수도 있다고 가정하고, `"관리자".equals(입력값)` 형태로 비교해서 NullPointerException 없이 "관리자입니다" 또는 "일반 사용자입니다"를 출력하세요. (입력값이 null이어도 에러 없이 동작해야 합니다)

**Input**
```
관리자
```

**Output**
```
관리자입니다
```

---

### 문제 6. 종합 - 회원 등급 확인 프로그램
회원 이름(String)을 입력받되, 빈 문자열("")을 입력하면 이름이 없는 것으로 간주해 "이름을 입력해주세요"를 출력하고, 이름이 있으면 "환영합니다, [이름]님"을 출력하세요. (`.equals("")`와 삼항 또는 if-else 활용)

**Input**
```
홍길동
```

**Output**
```
환영합니다, 홍길동님
```
