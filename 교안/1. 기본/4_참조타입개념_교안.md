## 1. 데이터 타입 분류: 기본형 vs 참조형

자바의 자료형은 크게 두 가지로 나뉩니다.

| 구분 | 설명 | 예시 |
|---|---|---|
| 기본형(primitive type) | 실제 **값**을 변수에 직접 저장 | `int`, `double`, `char`, `boolean` 등 8가지 (Day1 참고) |
| 참조형(reference type) | 객체가 저장된 **메모리 주소(참조값)** 를 저장 | `String`, 배열, 나중에 배울 `Student` 같은 클래스 |

```java
public class 기본형참조형예제 {
    public static void main(String[] args) {
        int 숫자 = 10;               // 기본형: 값 10이 변수에 직접 저장됨
        String 이름 = "홍길동";      // 참조형: "홍길동" 객체의 주소가 변수에 저장됨
    }
}
```

---

## 2. 메모리 사용 영역 (개념 이해용)

자바 프로그램이 실행될 때 크게 두 가지 메모리 영역을 사용합니다.

| 영역 | 저장되는 것 |
|---|---|
| 스택(Stack) | 지역 변수(기본형의 값, 참조형의 주소값) |
| 힙(Heap) | `new`로 생성된 객체의 실제 내용(String 객체, 배열, 나중에 배울 클래스 객체 등) |

```
int 숫자 = 10;              →  [스택] 숫자 = 10 (값 직접 저장)

String 이름 = "홍길동";      →  [스택] 이름 = 0x1234(주소)  →  [힙] 0x1234번지에 "홍길동" 저장
```

**개념적으로 이해할 점**: 기본형 변수는 "값 그 자체"를 담는 상자이고, 참조형 변수는 "객체가 어디 있는지 알려주는 주소"를 담는 상자입니다. 이 차이가 다음 항목(`==` vs `.equals()`)의 핵심 이유입니다.

---

## 3. 참조 변수의 == 연산

`==`은 기본형에서는 "값이 같은지"를 비교하지만, 참조형에서는 **"같은 주소를 가리키는지"** 를 비교합니다.

```java
public class 참조비교예제 {
    public static void main(String[] args) {
        int a = 10;
        int b = 10;
        System.out.println(a == b); // true (값 10과 10이 같음)

        String s1 = new String("hello");
        String s2 = new String("hello");
        System.out.println(s1 == s2); // false! 내용은 같지만 서로 다른 객체(다른 주소)

        String s3 = "hello";
        String s4 = "hello";
        System.out.println(s3 == s4); // true! 문자열 리터럴은 자바가 같은 객체를 재사용함
    }
}
```

**설명**: `new String("hello")`로 만든 두 객체는 내용은 같아도 힙 메모리 상에서 서로 다른 위치에 존재하므로 `==` 비교 결과는 `false`입니다. 반면 `"hello"`처럼 큰따옴표로 바로 쓴 문자열 리터럴은 자바가 내부적으로 같은 객체를 재사용하기 때문에 `==`이 `true`가 될 수 있습니다. 하지만 이 동작에 의존하는 것은 위험하므로, **문자열 내용 비교는 항상 `.equals()`를 사용**해야 합니다.

---

## 4. equals() 로 내용 비교하기

| 메서드 | 설명 | 예시 |
|---|---|---|
| `.equals(대상)` | 두 객체의 **내용**이 같은지 비교 (참조형 전용) | `s1.equals(s2)` |

```java
public class Equals예제 {
    public static void main(String[] args) {
        String s1 = new String("hello");
        String s2 = new String("hello");

        System.out.println(s1 == s2);        // false (주소 다름)
        System.out.println(s1.equals(s2));   // true (내용 같음)
    }
}
```

**정리하면**: 참조형 변수를 비교할 때 "내용이 같은지" 확인하려면 반드시 `.equals()`를 사용해야 하고, `==`은 "완전히 같은 객체인지(같은 주소인지)"를 확인할 때만 사용합니다. 기본형(`int`, `double` 등)은 값 자체를 비교하므로 그냥 `==`을 사용하면 됩니다.

## 5. null과 NullPointerException

참조형 변수는 "가리키는 객체가 없음"을 뜻하는 `null` 값을 가질 수 있습니다.

| 개념 | 설명 |
|---|---|
| `null` | 참조형 변수가 아무 객체도 가리키지 않는 상태 |
| `NullPointerException` (줄여서 NPE) | `null`인 참조 변수의 메서드를 호출하거나 필드를 사용하려 할 때 발생하는 실행 오류 |

```java
public class NullExample {
    public static void main(String[] args) {
        String 이름 = null; // 아직 아무 객체도 가리키지 않음
        System.out.println(이름); // null (출력은 가능, 문자열 "null"로 표시됨)

        System.out.println(이름.length()); // 실행 에러! NullPointerException 발생
    }
}
```

**설명**: `null`은 기본형에는 사용할 수 없고(`int a = null;`은 컴파일 에러), 참조형에만 사용할 수 있습니다. `null`인 변수에 `.length()`, `.equals()` 같은 메서드를 호출하면 프로그램이 즉시 중단되며 `NullPointerException`이 발생합니다. 참조형 변수를 사용하기 전에는 `null`이 아닌지 확인하는 습관이 중요합니다.

```java
public class NullCheck예제 {
    public static void main(String[] args) {
        String 이름 = null;

        if (이름 != null) {
            System.out.println(이름.length());
        } else {
            System.out.println("이름이 설정되지 않았습니다.");
        }
    }
}
```

## 자주 하는 실수

1. **문자열 비교에 `==` 사용**
   ```java
   String 입력값 = sc.nextLine();
   if (입력값 == "yes") { ... }  // 위험! 항상 예상대로 동작하지 않을 수 있음
   if (입력값.equals("yes")) { ... }  // 올바른 방법
   ```

2. **null 체크 없이 참조형 변수 사용**
   ```java
   String 이름 = null;
   System.out.println(이름.length()); // NullPointerException 발생
   ```

3. **기본형에 null 대입 시도**
   ```java
   int 나이 = null; // 컴파일 에러: 기본형에는 null 불가
   ```

4. **`.equals()`를 null 객체에 직접 호출**
   ```java
   String 값 = null;
   if (값.equals("test")) { ... }  // NullPointerException! 값이 null이라 equals 자체를 호출 불가
   if ("test".equals(값)) { ... }  // 안전한 방법: 리터럴을 앞에 두면 NPE 없이 false 반환
   ```

## 핵심 요약

| 항목 | 핵심 내용 |
|---|---|
| 기본형 | 값 자체를 저장 (int, double, char, boolean 등) |
| 참조형 | 객체의 주소를 저장 (String, 배열, 클래스 등) |
| 메모리 영역 | 스택(변수), 힙(객체 실제 내용) |
| `==` | 기본형: 값 비교 / 참조형: 주소(같은 객체인지) 비교 |
| `.equals()` | 참조형의 내용(값)을 비교할 때 사용 |
| `null` | 참조형 변수가 아무 객체도 가리키지 않는 상태 |
| NullPointerException | null인 참조 변수를 사용하려 할 때 발생하는 실행 오류 |
| 안전한 비교 습관 | 리터럴을 앞에 두고 `.equals()` 호출 (`"test".equals(값)`) |
