# Day 2. 연산자 - 실습

> 아래 문제는 교안에서 다룬 산술/비교/논리/대입/증감/삼항 연산자와 Scanner만으로 풀 수 있습니다.

---

## 기본

### 문제 1. 두 정수 사칙연산
정수 두 개를 입력받아 합, 차, 곱, 몫, 나머지를 출력하세요.

**Input**
```
10 3
```

**Output**
```
합: 13
차: 7
곱: 30
몫: 3
나머지: 1
```

---

### 문제 2. 짝수/홀수 판별 (삼항 연산자)
정수 하나를 입력받아 삼항 연산자로 짝수인지 홀수인지 문자열로 출력하세요.

**Input**
```
7
```

**Output**
```
홀수
```

---

## 응용

### 문제 3. 두 수 비교
정수 두 개를 입력받아 비교 연산자로 "크다/작다/같다" 중 하나를 출력하세요. (삼항 연산자 또는 println 여러 개 사용)

**Input**
```
5 8
```

**Output**
```
첫 번째 수가 더 작습니다.
```

---

### 문제 4. 논리 연산자로 합격 여부 판별
국어, 영어 점수(정수)를 입력받아, **두 과목 모두 60점 이상**이면 "합격", 아니면 "불합격"을 출력하세요. (`&&`와 삼항 연산자 활용)

**Input**
```
70 55
```

**Output**
```
불합격
```

---

### 문제 5. 전위/후위 증감 결과 확인
정수 변수 `a = 5`를 선언한 뒤, `a++ + ++a`의 결과와 최종 `a` 값을 출력하세요.

**Output**
```
계산 결과: 12
최종 a 값: 7
```

---

## 도전

### 문제 6. 복합 대입 연산자로 누적 계산
정수 변수 `total = 0`에서 시작해서, `+=`을 이용해 10, 20, 30을 차례로 더한 뒤 최종 값을 출력하세요.

**Output**
```
최종 합계: 60
```

---

### 문제 7. 종합 - 평균 및 등급 판정
국어, 영어, 수학 점수(정수)를 입력받아 평균을 계산하고(소수점 둘째 자리까지), 평균이 90 이상이면 "A", 아니면 "B"를 삼항 연산자로 판정해 출력하세요.

**Input**
```
95 92 90
```

**Output**
```
평균: 92.33
등급: A
```
