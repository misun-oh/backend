## 1. if / else if / else

조건(boolean 식)이 참인지 거짓인지에 따라 실행할 코드를 분기합니다.

```java
public class If예제 {
    public static void main(String[] args) {
        int 점수 = 75;

        if (점수 >= 90) {
            System.out.println("A등급");
        } else if (점수 >= 80) {
            System.out.println("B등급");
        } else if (점수 >= 70) {
            System.out.println("C등급");
        } else {
            System.out.println("D등급");
        }
    }
}
```

**설명**: 조건은 위에서부터 순서대로 검사되며, 처음으로 `true`인 조건의 블록만 실행되고 나머지는 건너뜁니다. `else`는 앞의 모든 조건이 거짓일 때 실행됩니다.

**자바와 JS의 차이**: 자바는 `if (조건)`의 조건식이 반드시 `boolean` 타입이어야 합니다. JS처럼 숫자(`0`, `1`)나 문자열을 조건에 바로 넣을 수 없습니다.
```java
if (1) { ... }  // 컴파일 에러! 자바는 boolean만 허용
```

## 2. switch문

하나의 변수 값에 따라 여러 경우로 분기할 때 `if-else`보다 간결하게 표현할 수 있습니다.

```java
public class Switch예제 {
    public static void main(String[] args) {
        int 학년 = 2;

        switch (학년) {
            case 1:
                System.out.println("신입생");
                break;
            case 2:
                System.out.println("2학년");
                break;
            case 3:
                System.out.println("3학년");
                break;
            default:
                System.out.println("해당 없음");
        }
    }
}
```

**설명**: `switch(학년)`의 값과 일치하는 `case`로 이동해 실행하고, `break`를 만나면 switch문을 빠져나갑니다. `break`가 없으면 다음 `case`까지 계속 실행됩니다(fall-through). `default`는 일치하는 `case`가 없을 때 실행됩니다.

**주의**: `break`를 빠뜨리면 의도치 않게 여러 case가 연달아 실행되므로, 각 case 끝에 `break`를 꼭 확인해야 합니다.

## 3. for문

반복 횟수가 정해져 있을 때 주로 사용합니다.

```java
public class For예제 {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println(i + "번째 반복");
        }
    }
}
```

**구조**: `for (초기식; 조건식; 증감식) { 반복할 코드 }`
- 초기식: 처음 한 번만 실행 (`int i = 1`)
- 조건식: 매 반복 전에 검사, `true`면 계속 (`i <= 5`)
- 증감식: 매 반복 후 실행 (`i++`)

---

## 4. while문 / do-while문

반복 횟수가 정해지지 않고, 조건이 만족하는 동안 계속 반복할 때 사용합니다.

```java
public class While예제 {
    public static void main(String[] args) {
        int i = 1;
        while (i <= 5) {
            System.out.println(i + "번째 반복");
            i++; // 증감식을 직접 작성해야 함 (for문과 차이)
        }
    }
}
```

`do-while`은 조건 검사를 맨 뒤에서 하므로, **조건이 거짓이어도 최소 1번은 실행**됩니다.

```java
public class DoWhile예제 {
    public static void main(String[] args) {
        int i = 10;
        do {
            System.out.println("실행됨: " + i);
            i++;
        } while (i <= 5); // 조건이 거짓이지만 이미 1번 실행됨
    }
}
```

## 5. break, continue

| 키워드 | 설명 |
|---|---|
| `break` | 반복문을 즉시 종료하고 빠져나감 |
| `continue` | 이번 반복만 건너뛰고 다음 반복으로 넘어감 |

```java
public class BreakContinue예제 {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i == 5) {
                break; // i가 5가 되면 반복문 전체 종료
            }
            System.out.println("break 예제: " + i);
        }

        for (int i = 1; i <= 5; i++) {
            if (i % 2 == 0) {
                continue; // 짝수면 아래 출력을 건너뛰고 다음 반복으로
            }
            System.out.println("continue 예제(홀수만): " + i);
        }
    }
}
```

## 6. 중첩 반복문

반복문 안에 또 다른 반복문을 넣어 2차원적인 반복(표, 별찍기, 구구단 등)을 처리합니다.

```java
public class 중첩반복예제 {
    public static void main(String[] args) {
        // 구구단 2단~4단
        for (int 단 = 2; 단 <= 4; 단++) {
            for (int i = 1; i <= 9; i++) {
                System.out.println(단 + " x " + i + " = " + (단 * i));
            }
            System.out.println("-----");
        }
    }
}
```

**설명**: 바깥쪽 반복문(`단`)이 한 번 돌 때마다, 안쪽 반복문(`i`)이 처음부터 끝까지 전부 실행됩니다. 안쪽 반복문이 다 끝나야 바깥쪽 반복문이 다음 단계로 넘어갑니다.

## 자주 하는 실수

1. **switch문에서 break 누락**
   ```java
   switch (학년) {
       case 1:
           System.out.println("신입생"); // break 없음
       case 2:
           System.out.println("2학년");  // case 1에서 이어서 실행되어 버림
   }
   ```

2. **while문에서 증감식 작성을 잊어 무한루프**
   ```java
   int i = 1;
   while (i <= 5) {
       System.out.println(i);
       // i++; 를 빠뜨리면 조건이 영원히 참 → 무한루프
   }
   ```

3. **for문 조건식 실수로 인한 범위 오류**
   ```java
   for (int i = 0; i < 5; i++) { ... }  // 0~4, 총 5번
   for (int i = 0; i <= 5; i++) { ... } // 0~5, 총 6번 (의도와 다를 수 있음)
   ```

4. **if 조건식에 boolean이 아닌 값 사용 (JS 습관)**
   ```java
   int flag = 1;
   if (flag) { ... }        // 컴파일 에러
   if (flag == 1) { ... }   // 올바른 표현
   ```

## 핵심 요약

| 항목 | 핵심 내용 |
|---|---|
| if/else if/else | 조건은 반드시 boolean, 위에서부터 순서대로 검사 |
| switch | 값 일치 시 해당 case로 이동, break 없으면 다음 case까지 실행됨 |
| for | 반복 횟수가 정해진 경우, `(초기식; 조건식; 증감식)` |
| while | 조건 만족하는 동안 반복, 조건이 처음부터 거짓이면 0번 실행 |
| do-while | 조건과 무관하게 최소 1번 실행 후 조건 검사 |
| break | 반복문 즉시 종료 |
| continue | 이번 반복만 건너뛰고 다음 반복 진행 |
| 중첩 반복문 | 바깥 반복 1회당 안쪽 반복이 전부 실행됨 |
