# Day 7. 메서드(함수) 기초 - 실습

> 아래 문제는 교안에서 다룬 메서드 정의/호출, 매개변수, 반환값(void 포함)만으로 풀 수 있습니다.

---

## 기본

### 문제 1. 인사 메서드 만들기
매개변수 없이 "안녕하세요, 자바 세계!"를 출력하는 `void` 메서드 `인사()`를 만들고 `main`에서 2번 호출하세요.

**Output**
```
안녕하세요, 자바 세계!
안녕하세요, 자바 세계!
```

---

### 문제 2. 두 수를 더하는 메서드
정수 두 개를 매개변수로 받아 합을 반환하는 `더하기` 메서드를 만들고, `main`에서 `더하기(3, 7)`을 호출해 결과를 출력하세요.

**Output**
```
결과: 10
```

---

## 응용

### 문제 3. 이름을 매개변수로 받아 인사하기
문자열 이름을 매개변수로 받아 "OO님 환영합니다!"를 출력하는 `void` 메서드를 만들고, "홍길동"으로 호출하세요.

**Output**
```
홍길동님 환영합니다!
```

---

### 문제 4. 최댓값을 반환하는 메서드
정수 두 개를 매개변수로 받아 더 큰 값을 반환하는 `최댓값` 메서드를 만들고, `main`에서 `최댓값(7, 3)`을 호출해 출력하세요.

**Output**
```
최댓값: 7
```

---

### 문제 5. 짝수 판별 메서드 (boolean 반환)
정수를 매개변수로 받아 짝수이면 `true`, 홀수이면 `false`를 반환하는 `짝수인가` 메서드를 만들고, 4와 7 각각에 대해 호출한 결과를 출력하세요.

**Output**
```
4는 짝수인가? true
7는 짝수인가? false
```

---

## 도전

### 문제 6. 배열의 합계를 반환하는 메서드
정수 배열을 매개변수로 받아 모든 요소의 합계를 반환하는 `합계구하기` 메서드를 만들고, `{10, 20, 30}` 배열로 호출해 결과를 출력하세요.

**Output**
```
합계: 60
```

---

### 문제 7. 종합 - 성적 처리 메서드 묶음
정수 배열을 매개변수로 받아 평균(double)을 반환하는 `평균구하기` 메서드와, 평균 점수를 매개변수로 받아 90 이상이면 "A", 80 이상이면 "B", 그 외 "C"를 반환하는 `등급판정` 메서드를 각각 만들어서, `{88, 92, 79, 95}` 배열의 평균과 등급을 함께 출력하세요.

**Output**
```
평균: 88.50
등급: B
```
