## 1. 2차원 배열

배열 안에 배열이 들어있는 구조로, 표(행과 열) 형태의 데이터를 다룰 때 사용합니다.

```java
public class 이차원배열예제 {
    public static void main(String[] args) {
        // 3행 2열짜리 성적표: 학생 3명, 과목 2개(국어, 영어)
        int[][] 성적표 = {
            {90, 85},  // 1번 학생: 국어 90, 영어 85
            {78, 92},  // 2번 학생
            {88, 76}   // 3번 학생
        };

        System.out.println(성적표[0][0]); // 90 (1번 학생의 국어 점수)
        System.out.println(성적표[1][1]); // 92 (2번 학생의 영어 점수)
        System.out.println(성적표.length);    // 3 (행의 개수 = 학생 수)
        System.out.println(성적표[0].length); // 2 (열의 개수 = 과목 수)
    }
}
```

**설명**: `성적표[행][열]`처럼 인덱스를 두 개 사용해 특정 위치의 값에 접근합니다. `성적표.length`는 행(바깥 배열)의 개수를, `성적표[0].length`는 그 행 안에 들어있는 열(안쪽 배열)의 개수를 의미합니다.

2차원 배열을 순회할 때는 중첩 반복문(Day 3)을 사용합니다.

```java
public class 이차원배열순회예제 {
    public static void main(String[] args) {
        int[][] 성적표 = {
            {90, 85},
            {78, 92},
            {88, 76}
        };

        for (int i = 0; i < 성적표.length; i++) {           // 행(학생) 순회
            for (int j = 0; j < 성적표[i].length; j++) {    // 열(과목) 순회
                System.out.print(성적표[i][j] + " ");
            }
            System.out.println(); // 한 학생의 점수를 다 출력하면 줄바꿈
        }
    }
}
```

## 2. 배열 값 교환 (swap)

배열의 두 요소 위치를 서로 바꾸려면, **임시 변수**를 하나 사용해야 합니다.

```java
public class 값교환예제 {
    public static void main(String[] args) {
        int[] 숫자들 = {10, 20, 30};

        // 숫자들[0]과 숫자들[1]을 교환
        int temp = 숫자들[0];  // 1. 0번 값을 임시로 저장
        숫자들[0] = 숫자들[1]; // 2. 1번 값을 0번에 대입
        숫자들[1] = temp;      // 3. 임시로 저장했던 값을 1번에 대입

        System.out.println(숫자들[0] + ", " + 숫자들[1]); // 20, 10
    }
}
```

**설명**: `숫자들[0] = 숫자들[1];`을 먼저 실행하면 원래 `숫자들[0]`의 값(10)을 잃어버리게 됩니다. 그래서 바꾸기 전에 `temp`라는 임시 변수에 원래 값을 미리 저장해두는 것이 핵심입니다.

## 3. 배열 값 교환을 활용한 정렬 기초 (버블 정렬)

값 교환을 반복적으로 적용하면, 배열을 오름차순으로 정렬할 수 있습니다. 가장 기본적인 정렬 방식인 **버블 정렬**을 살펴봅니다.

```java
public class 버블정렬예제 {
    public static void main(String[] args) {
        int[] 숫자들 = {5, 2, 4, 1, 3};

        // 인접한 두 값을 비교하며, 앞이 뒤보다 크면 교환하는 과정을 반복
        for (int i = 0; i < 숫자들.length - 1; i++) {
            for (int j = 0; j < 숫자들.length - 1 - i; j++) {
                if (숫자들[j] > 숫자들[j + 1]) {
                    int temp = 숫자들[j];
                    숫자들[j] = 숫자들[j + 1];
                    숫자들[j + 1] = temp;
                }
            }
        }

        for (int 값 : 숫자들) {
            System.out.print(값 + " ");
        }
        // 결과: 1 2 3 4 5
    }
}
```

**설명**: 안쪽 반복문이 이웃한 두 값을 비교해서, 앞의 값이 뒤의 값보다 크면 교환합니다. 이 과정을 배열 전체에 대해 여러 번 반복하면 큰 값들이 뒤로 점점 "밀려나면서" 정렬이 완성됩니다. 바깥 반복문의 `i`가 늘어날수록 안쪽 반복 범위(`length - 1 - i`)가 줄어드는데, 이는 이미 정렬이 끝난 뒤쪽 요소들을 다시 비교할 필요가 없기 때문입니다.

## 자주 하는 실수

1. **swap 시 임시 변수 없이 바로 교환 시도**
   ```java
   숫자들[0] = 숫자들[1];
   숫자들[1] = 숫자들[0]; // 이미 숫자들[0]이 바뀐 뒤라 원래 값을 잃어버림 (결과: 둘 다 같은 값)
   ```

2. **2차원 배열 인덱스 순서 착각**
   ```java
   성적표[열][행] // 잘못된 접근: 항상 [행][열] 순서로 접근해야 함
   ```

3. **버블 정렬 안쪽 반복 범위 실수**
   ```java
   for (int j = 0; j < 숫자들.length; j++) { // length까지 그대로 두면
       if (숫자들[j] > 숫자들[j+1]) { ... }   // 마지막 j일 때 j+1이 범위를 벗어나 에러 발생
   }
   ```
