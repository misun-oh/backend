# Day 15. 제네릭 - 실습

> 아래 문제는 교안에서 다룬 제네릭 클래스 정의(`<T>`), 제네릭 객체 생성, 래퍼 클래스만으로 풀 수 있습니다.

---

## 기본

### 문제 1. 제네릭 클래스 만들기
`Box<T>` 클래스를 만드세요. `content`(T 타입) 필드와 `setContent(T)`, `getContent()`을 가집니다. `Box<String>` 객체를 만들어 문자열을 담고 꺼내 출력하세요.

**Output**
```
자바
```

---

### 문제 2. 다른 타입으로 같은 제네릭 클래스 재사용
문제 1의 `Box<T>`를 이번엔 `Box<Integer>`로 만들어 정수(래퍼 클래스 Integer)를 담고 꺼내 출력하세요.

**Output**
```
100
```

---

## 응용

### 문제 3. 제네릭 없이 만들었을 때의 문제 재현
`Object`로 만든 `Box`(제네릭이 아닌 버전) 클래스를 만들어서, 문자열을 저장했다가 캐스팅해서 꺼내보세요. 그리고 실수로 다른 타입(정수)을 넣었을 때 캐스팅 과정에서 어떤 문제가 생기는지 주석으로 설명을 남기세요.

**정답 예시(주석 형태)**
```java
// box1.setContent(123);
// String value = (String) box1.getContent();
// 실행 시 ClassCastException 발생: Integer를 String으로 캐스팅할 수 없음
// (컴파일은 되지만 실행하면 에러가 나는 것이 문제 — 제네릭을 쓰면 컴파일 시점에 막을 수 있음)
```

---

### 문제 4. 제네릭 클래스에 학사관리 도메인 적용
`Pair<T>` 클래스를 만드세요. 필드로 `first`(T), `second`(T)를 가지고, 생성자로 초기화하며, `printInfo()` 메서드로 "첫번째: X, 두번째: Y"를 출력합니다. `Pair<String>` 객체를 만들어 학과명 두 개("컴퓨터공학과", "경영학과")를 담아 출력하세요.

**Output**
```
첫번째: 컴퓨터공학과, 두번째: 경영학과
```

---

## 도전

### 문제 5. 제네릭 메서드로 배열 출력하기
제네릭을 활용한 메서드 `printAll(T[] array)`을 만드세요(클래스 전체가 아니라 메서드 하나에만 제네릭을 적용, 형식: `public static <T> void printAll(T[] array)`). `String[]`과 `Integer[]` 배열 각각에 대해 호출해서 모든 요소를 출력하세요.

**Output**
```
홍길동
김철수
이영희
90
85
78
```

### 문제 6. 종합 - 제네릭 상자와 인터페이스 함께 사용
Day13에서 배운 `Printable` 인터페이스를 구현하는 제네릭 클래스 `Box<T>`를 만드세요. `printInfo()` 메서드는 "상자 안에는 X가 들어있습니다"를 출력합니다. `Box<String>`과 `Box<Integer>` 객체를 각각 만들어 `Printable[]` 배열에 담고, 반복문으로 모두 출력하세요.

**Output**
```
상자 안에는 자바가 들어있습니다
상자 안에는 100이 들어있습니다
```
