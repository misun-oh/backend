# VSCode 마크다운(.md) 기본 미리보기 설정 방법

VSCode에서 마크다운 파일을 열 때 편집기 대신 **미리보기 화면이 기본으로 바로 열리도록** 설정하는 방법입니다.
기본설정을 미리보기로 변경 할 수 있습니다.
만약, 미리보기와 편집기를 동시에 열고 싶다면 확장프로그램을 설치 합니다. 

---

## 0. editorAssociations
파일 확장자와 프로그램을 연결하는 설정

## 1. 마크다운 기본 보기 설정 변경 (settings.json)
VSCode 설정을 변경하여 마크다운 파일을 열 때 항상 미리보기가 기본값(Default)으로 지정되도록 만들 수 있습니다.

1. **설정창 열기**: `Ctrl + ,` (맥은 `Cmd + ,`)를 누릅니다.
2. **항목 검색**: 상단 검색창에 `workbench.editorAssociations`를 입력합니다.
3. 항목추가 선택후 아래와 같이 입력

    | 항목 | 값 |
    | --- | --- |
    | *.md | vscode.markdown.preview.editor(선택) |


---

## 2. 파일에서 마우스 우클릭으로 설정 
설정 파일을 직접 수정하기 어렵다면 탐색기 창에서 바로 변경할 수 있습니다.

1. **우클릭 메뉴 열기**: VSCode 왼쪽 탐색기에서 마크다운 파일에 마우스를 대고 우클릭합니다.
2. **연결 프로그램 선택**: 메뉴에서 **'다음으로 열기...(Open With...)'**를 클릭합니다.
3. **기본값 구성**: 팝업 창 맨 아래에 있는 **'기본 편집기 구성...(Configure default editor for...)'**을 선택합니다.
4. **미리보기 선택**: 목록에서 **'마크다운 미리보기(Markdown Preview)'**를 클릭합니다.

---

## 💡 참고 팁
* 이제부터 마크다운 파일을 더블 클릭하면 편집기가 아닌 미리보기 창이 곧바로 열립니다.
* 다시 코드를 수정하고 싶을 때는 파일 우클릭 후 **'다음으로 열기...' -> '텍스트 편집기(Text Editor)'**를 선택하시면 됩니다.
