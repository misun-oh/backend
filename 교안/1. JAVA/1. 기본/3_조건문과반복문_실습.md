# Day 3. 조건문과 반복문 - 실습

> 아래 문제는 교안에서 다룬 if/switch, for/while/do-while, break/continue, 중첩 반복문만으로 풀 수 있습니다.

---

## 기본

### 문제 1. 성적 등급 판정 (if-else)
점수(정수)를 입력받아 90이상 A, 80이상 B, 70이상 C, 그 외 D를 출력하세요.

**Input**
```
85
```

**Output**
```
B등급
```

---

### 문제 2. 1부터 10까지 출력 (for문)
`for`문을 이용해 1부터 10까지 한 줄에 하나씩 출력하세요.

**Output**
```
1
2
...
10
```

---

## 응용

### 문제 3. 요일 출력 (switch문)
숫자(1~7)를 입력받아 switch문으로 요일을 출력하세요. (1=월요일 ~ 7=일요일)

**Input**
```
3
```

**Output**
```
수요일
```

---

### 문제 4. 1부터 100까지 합계 (while문)
`while`문을 이용해 1부터 100까지의 합을 구해 출력하세요.

**Output**
```
합계: 5050
```

---

### 문제 5. 3의 배수만 출력하고 50 넘으면 중단 (break, continue)
1부터 100까지 반복하면서, 3의 배수가 아니면 건너뛰고(continue), 3의 배수를 출력하되 값이 50을 넘으면 반복을 종료(break)하세요.

**Output**
```
3
6
9
...
48
```

---

## 도전

### 문제 6. 별 찍기 (중첩 반복문)
정수 n(예: 5)을 입력받아, 아래처럼 직각삼각형 모양으로 별을 출력하세요.

**Input**
```
5
```

**Output**
```
*
**
***
****
*****
```

---

### 문제 7. 종합 - 구구단 중 원하는 단만 출력
정수(2~9)를 입력받아 해당 단의 구구단을 출력하세요. 만약 2~9 범위 밖의 숫자가 입력되면 "잘못된 입력입니다"를 출력하세요. (if-else와 for문 결합)

**Input**
```
7
```

**Output**
```
7 x 1 = 7
7 x 2 = 14
...
7 x 9 = 63
```

**Input**
```
15
```

**Output**
```
잘못된 입력입니다
```
