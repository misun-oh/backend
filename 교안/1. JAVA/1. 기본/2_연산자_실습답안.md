## 기본

### 문제 1. 두 정수 사칙연산

```java
import java.util.Scanner;

public class Practice1 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int a = sc.nextInt();
        int b = sc.nextInt();

        System.out.println("합: " + (a + b));
        System.out.println("차: " + (a - b));
        System.out.println("곱: " + (a * b));
        System.out.println("몫: " + (a / b));
        System.out.println("나머지: " + (a % b));
    }
}
```

**설명**: `(a + b)`처럼 괄호로 묶은 이유는 `+`가 문자열 연결에도 쓰이므로, 숫자 연산이 먼저 계산되도록 명확히 하기 위함입니다.

**틀리기 쉬운 포인트**: `"합: " + a + b`처럼 괄호 없이 쓰면 왼쪽부터 순서대로 처리되어 숫자 덧셈이 아니라 문자열 이어붙이기가 됩니다.

### 문제 2. 짝수/홀수 판별

```java
import java.util.Scanner;

public class Practice2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        String 결과 = (n % 2 == 0) ? "짝수" : "홀수";
        System.out.println(결과);
    }
}
```

**설명**: `n % 2 == 0`은 `n`을 2로 나눈 나머지가 0인지 비교합니다. 나머지가 0이면 짝수이므로 삼항 연산자로 바로 문자열을 결정합니다.

**틀리기 쉬운 포인트**: `n % 2 = 0`처럼 `==` 대신 `=`을 쓰면 컴파일 에러가 납니다.

### 문제 3. 두 수 비교

```java
import java.util.Scanner;

public class Practice3 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int a = sc.nextInt();
        int b = sc.nextInt();

        String 결과 = (a > b) ? "첫 번째 수가 더 큽니다."
                    : (a < b) ? "첫 번째 수가 더 작습니다."
                    : "두 수가 같습니다.";
        System.out.println(결과);
    }
}
```

**설명**: 삼항 연산자를 중첩해서 세 가지 경우(크다/작다/같다)를 처리했습니다. 첫 번째 조건이 거짓이면 두 번째 삼항식으로 넘어가 다시 판별합니다.

**틀리기 쉬운 포인트**: 삼항 연산자를 중첩할 때 괄호 없이 여러 줄로 이어 쓰면 어디까지가 하나의 식인지 헷갈리기 쉬우므로, 들여쓰기로 구조를 명확히 하는 것이 좋습니다. (조건문 if-else는 Day3에서 배우며, 조건이 3개 이상이면 조건문이 더 읽기 좋습니다.)

### 문제 4. 논리 연산자로 합격 여부 판별

```java
import java.util.Scanner;

public class Practice4 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int 국어 = sc.nextInt();
        int 영어 = sc.nextInt();

        String 결과 = (국어 >= 60 && 영어 >= 60) ? "합격" : "불합격";
        System.out.println(결과);
    }
}
```

**설명**: `국어 >= 60 && 영어 >= 60`은 두 조건이 모두 참이어야 `true`가 됩니다. `&&`의 단락 평가 특성상 국어가 60 미만이면 영어는 확인하지 않고 바로 `false`가 됩니다.

**틀리기 쉬운 포인트**: `||`(또는)를 쓰면 한 과목만 60점이 넘어도 합격 처리되어 문제 요구사항("두 과목 모두")과 달라집니다. `&&`와 `||`를 혼동하지 않도록 주의합니다.

### 문제 5. 전위/후위 증감 결과 확인

```java
public class Practice5 {
    public static void main(String[] args) {
        int a = 5;
        int 결과 = a++ + ++a;
        // a++ : 현재 값 5를 먼저 사용, 이후 a는 6이 됨
        // ++a : a(6)를 먼저 7로 증가시킨 후 그 값(7) 사용
        // 결과 = 5 + 7 = 12

        System.out.println("계산 결과: " + 결과);
        System.out.println("최종 a 값: " + a);
    }
}
```

**설명**: `a++`는 계산에는 원래 값(5)을 사용하고, 계산이 끝난 뒤 `a`가 6으로 증가합니다. 이어지는 `++a`는 이미 6이 된 `a`를 먼저 7로 증가시킨 뒤 그 값을 계산에 사용합니다. 따라서 `5 + 7 = 12`, 최종 `a`는 `7`입니다.

**틀리기 쉬운 포인트**: 전위/후위를 한 식에 섞어 쓰면 계산 순서를 착각하기 쉽습니다. 실무에서는 가독성을 위해 이런 식은 되도록 피하고 증감을 별도 줄로 나눠 작성하는 것이 좋습니다.

### 문제 6. 복합 대입 연산자로 누적 계산

```java
public class Practice6 {
    public static void main(String[] args) {
        int total = 0;
        total += 10; // total = total + 10 → 10
        total += 20; // total = total + 20 → 30
        total += 30; // total = total + 30 → 60

        System.out.println("최종 합계: " + total);
    }
}
```

**설명**: `+=`은 "기존 값에 더한 뒤 다시 저장"을 짧게 줄인 표현입니다. `total += 10`은 `total = total + 10`과 완전히 같습니다.

**틀리기 쉬운 포인트**: `total = 10 + 20 + 30`처럼 한 번에 계산해도 결과는 같지만, 이 문제는 "차례로 누적"하는 상황을 연습하기 위한 것이므로 `+=`을 세 번 나눠 쓰는 방식에 익숙해지는 것이 중요합니다. 이 패턴은 이후 반복문(Day3)에서 합계를 구할 때 그대로 사용됩니다.

### 문제 7. 종합 - 평균 및 등급 판정

```java
import java.util.Scanner;

public class Practice7 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int 국어 = sc.nextInt();
        int 영어 = sc.nextInt();
        int 수학 = sc.nextInt();

        double 평균 = (국어 + 영어 + 수학) / 3.0; // 3.0으로 나눠 자동으로 double 연산 유도
        String 등급 = (평균 >= 90) ? "A" : "B";

        System.out.printf("평균: %.2f%n", 평균);
        System.out.println("등급: " + 등급);
    }
}
```

**설명**: `(국어 + 영어 + 수학) / 3.0`에서 `3.0`을 실수로 써주면, 정수 합계가 자동 형변환되어 실수 나눗셈이 됩니다(Day1의 자동 형변환 복습). `(double) 3`으로 캐스팅하는 대신 `3.0`이라는 실수 리터럴을 바로 쓴 것도 같은 효과입니다.

**틀리기 쉬운 포인트**: `/ 3`으로 쓰면 정수 나눗셈이 되어 소수점이 버려집니다. 평균처럼 소수점이 필요한 계산에서는 나누는 값 자체를 실수로 쓰거나 형변환을 반드시 적용해야 합니다.
