# Day 9. 클래스 - 객체와 생성자 - 실습 답안

> 참고: 자바에서는 `public` 클래스는 하나의 파일에 하나만 존재해야 하므로, 아래 코드는 실제로는 클래스별로 `.java` 파일을 나눠 저장합니다. (예: `책.java`, `Practice1.java`)

---

## 기본

### 문제 1. 다이어그램 보고 클래스 구현하기

```java
// 책.java
public class 책 {
    String 제목;
    String 저자;
    int 가격;

    public 책(String 제목, String 저자, int 가격) {
        this.제목 = 제목;
        this.저자 = 저자;
        this.가격 = 가격;
    }
}
```

```java
// Practice1.java
public class Practice1 {
    public static void main(String[] args) {
        책 책1 = new 책("자바의 정석", "남궁성", 30000);

        System.out.println("제목: " + 책1.제목);
        System.out.println("저자: " + 책1.저자);
        System.out.println("가격: " + 책1.가격);
    }
}
```

**설명**: 다이어그램의 필드 3개(`제목`, `저자`, `가격`)를 클래스 필드로 선언하고, `+책(...)` 생성자를 그대로 구현했습니다. `new 책(...)`으로 객체를 생성하면서 값을 전달하면 생성자가 실행되어 필드가 즉시 초기화됩니다.

**틀리기 쉬운 포인트**: 생성자의 매개변수 이름(`제목`)과 필드 이름(`제목`)이 같아서, `this.제목 = 제목;`처럼 `this`로 구분해야 합니다. `this`는 Day10에서 자세히 다루지만, "현재 만들어지고 있는 객체 자신의 필드"를 가리킨다고 이해하면 됩니다.

### 문제 2. 여러 객체 만들기

```java
public class Practice2 {
    public static void main(String[] args) {
        책 책1 = new 책("이것이 자바다", "신용권", 28000);
        책 책2 = new 책("자바의 정석", "남궁성", 30000);

        System.out.println("책1 - 제목: " + 책1.제목 + ", 저자: " + 책1.저자);
        System.out.println("책2 - 제목: " + 책2.제목 + ", 저자: " + 책2.저자);
    }
}
```

**설명**: 같은 `책` 클래스로 `책1`, `책2` 두 개의 독립된 객체를 만들었습니다. 각 객체는 힙 메모리에 별도로 존재하며, 서로 다른 필드 값을 가집니다.

**틀리기 쉬운 포인트**: `책1`을 수정해도 `책2`에는 전혀 영향이 없습니다. 각 객체는 클래스라는 같은 "설계도"를 사용했을 뿐, 실제로는 완전히 독립적인 데이터 공간입니다.

## 응용

### 문제 3. 다이어그램 보고 get 메서드까지 구현하기

```java
// 교수.java
public class 교수 {
    private String 교수번호;
    private String 교수명;

    public 교수(String 교수번호, String 교수명) {
        this.교수번호 = 교수번호;
        this.교수명 = 교수명;
    }

    public String get교수번호() {
        return 교수번호;
    }

    public String get교수명() {
        return 교수명;
    }
}
```

```java
// Practice3.java
public class Practice3 {
    public static void main(String[] args) {
        교수 교수1 = new 교수("P001", "김교수");

        System.out.println("교수번호: " + 교수1.get교수번호());
        System.out.println("교수명: " + 교수1.get교수명());
    }
}
```

**설명**: 다이어그램에서 필드 앞에 `-`가 붙어있으므로 `private`로 선언했습니다. `private` 필드는 클래스 바깥에서 `교수1.교수번호`처럼 직접 접근할 수 없기 때문에(Day10에서 자세히), `get교수번호()`, `get교수명()` 같은 `public` 메서드를 통해서만 값을 꺼낼 수 있도록 다이어그램에 정의되어 있습니다.

**틀리기 쉬운 포인트**: 필드를 `private`로 선언했는데 get 메서드를 만들지 않으면, 클래스 바깥(`Practice3`)에서는 그 값을 확인할 방법이 전혀 없습니다. 다이어그램에 `+get교수번호() String`이 명시되어 있다면 반드시 구현해야 합니다.

### 문제 4. 기본 생성자와 사용자 정의 생성자 함께 만들기

```java
// 학과.java
public class 학과 {
    String 학과명;

    public 학과() {
        this.학과명 = "미정";
    }

    public 학과(String 학과명) {
        this.학과명 = 학과명;
    }
}
```

```java
// Practice4.java
public class Practice4 {
    public static void main(String[] args) {
        학과 학과1 = new 학과();              // 매개변수 없는 생성자 → 학과명 "미정"
        학과 학과2 = new 학과("컴퓨터공학과"); // 매개변수 있는 생성자

        System.out.println("학과1: " + 학과1.학과명);
        System.out.println("학과2: " + 학과2.학과명);
    }
}
```

**설명**: 교안에서 배운 대로, 사용자 정의 생성자(`학과(String 학과명)`)를 만들면 기본 생성자는 자동으로 사라집니다. 그래서 매개변수 없는 `new 학과()`를 계속 사용하고 싶다면, 매개변수 없는 생성자(`학과()`)도 직접 작성해야 합니다.

**틀리기 쉬운 포인트**: `학과()` 생성자를 빠뜨리고 `학과(String 학과명)`만 작성한 상태에서 `new 학과();`를 호출하면 "생성자를 찾을 수 없다"는 컴파일 에러가 발생합니다.

### 문제 5. 다이어그램 보고 클래스 구현 + 배열로 관리

```java
// 학생.java
public class 학생 {
    private String 학번;
    private String 이름;
    private int 나이;

    public 학생(String 학번, String 이름, int 나이) {
        this.학번 = 학번;
        this.이름 = 이름;
        this.나이 = 나이;
    }

    public String get학번() {
        return 학번;
    }

    public String get이름() {
        return 이름;
    }

    public int get나이() {
        return 나이;
    }
}
```

```java
// Practice5.java
public class Practice5 {
    public static void main(String[] args) {
        학생[] 학생들 = new 학생[3]; // 학생 객체 3개를 담을 배열
        학생들[0] = new 학생("S001", "홍길동", 20);
        학생들[1] = new 학생("S002", "김철수", 21);
        학생들[2] = new 학생("S003", "이영희", 22);

        for (학생 학생 : 학생들) {
            System.out.println("학번: " + 학생.get학번() + ", 이름: " + 학생.get이름() + ", 나이: " + 학생.get나이());
        }
    }
}
```

**설명**: `학생[] 학생들 = new 학생[3];`은 "학생 객체를 3개 담을 수 있는 배열"을 만드는 것입니다. Day5~6에서 배운 배열 문법이 기본형(`int[]`)뿐 아니라 클래스 타입(`학생[]`)에도 그대로 적용됩니다. 향상된 for문으로 배열 속 각 `학생` 객체를 꺼내 get 메서드로 정보를 출력합니다.

**틀리기 쉬운 포인트**: `new 학생[3]`은 배열 "상자"만 만들 뿐, 그 안의 각 칸(`학생들[0]`, `학생들[1]`, `학생들[2]`)은 아직 `null` 상태입니다. 각 칸에 실제로 `new 학생(...)`으로 객체를 만들어 넣어주지 않으면 NullPointerException이 발생합니다(Day4 복습).

### 문제 6. 종합 - 생성자 안에서 필드 간 계산

```java
// 사각형.java
public class 사각형 {
    private int 가로;
    private int 세로;
    private int 넓이;

    public 사각형(int 가로, int 세로) {
        this.가로 = 가로;
        this.세로 = 세로;
        this.넓이 = 가로 * 세로; // 생성자 안에서 다른 필드 값을 이용해 계산 후 저장
    }

    public int get넓이() {
        return 넓이;
    }
}
```

```java
// Practice6.java
public class Practice6 {
    public static void main(String[] args) {
        사각형 사각형1 = new 사각형(6, 4);
        System.out.println("넓이: " + 사각형1.get넓이());
    }
}
```

**설명**: 생성자는 단순히 값을 그대로 대입하는 것뿐 아니라, 전달받은 값들을 이용해 계산한 결과를 다른 필드에 저장하는 것도 가능합니다. 여기서는 `가로`와 `세로`를 전달받아 즉시 곱셈한 결과를 `넓이` 필드에 저장해두어, 나중에 다시 계산할 필요 없이 `get넓이()`로 바로 꺼내 쓸 수 있게 했습니다.

**틀리기 쉬운 포인트**: `this.가로 = 가로; this.세로 = 세로;`를 먼저 실행한 뒤에 `this.넓이 = 가로 * 세로;`를 계산해야 합니다. 순서를 지키지 않고 필드에 대입하기 전의 매개변수 값을 사용하는 것 자체는 이 예제에서는 문제 없지만(매개변수 `가로`, `세로`를 직접 곱했으므로), 만약 `this.가로 * this.세로`처럼 필드를 사용했다면 대입 순서가 중요해집니다.
