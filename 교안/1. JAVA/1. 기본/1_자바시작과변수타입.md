## 1. 프로그래밍 언어와 자바

프로그래밍 언어는 사람이 컴퓨터에게 "무엇을 어떻게 할지"를 명령하기 위한 약속된 문법 체계입니다. 자바는 그중에서도 다음 특징을 가진 언어입니다.

- **객체 지향 언어**: 데이터와 기능을 하나의 단위(객체)로 묶어서 다룸 (Day 9~12에서 본격적으로 다룰 내용)
- **플랫폼 독립적**: JVM 위에서 실행되므로 윈도우/맥/리눅스 어디서든 동일하게 동작
- **정적 타입 언어**: 변수를 선언할 때 자료형을 반드시 명시해야 함 (이번 챕터의 핵심)

## 2. JVM / JDK / 컴파일-실행 과정

자바로 작성한 코드(`.java`)는 컴퓨터가 바로 실행할 수 없습니다. 아래 3단계를 거칩니다.

1. **소스코드 작성**: `Hello.java` 같은 텍스트 파일 작성
2. **컴파일**: `javac`(자바 컴파일러)가 `.java` 파일을 `.class`(바이트코드) 파일로 변환
3. **실행**: `java` 명령이 **JVM(Java Virtual Machine)** 을 통해 `.class` 파일을 실행

**JDK(Java Development Kit)** 는 `javac`, `java` 등 개발에 필요한 도구를 모두 포함한 패키지입니다. 이 교안은 **JDK 17** 기준으로 작성합니다.

```
Hello.java  --(javac)-->  Hello.class  --(java, JVM)-->  실행 결과
```

JVM 덕분에 자바는 소스코드를 한 번만 작성하면 어떤 운영체제에서도 동일한 `.class` 파일이 그대로 실행됩니다. ("Write Once, Run Anywhere")

---

## 3. 개발환경과 실행 방법

이 과정은 별도의 통합개발환경(IDE) 없이 **콘솔(터미널)에서 javac/java 명령**으로 실습합니다.

| 명령어 | 설명 | 예시 |
|---|---|---|
| `javac` | `.java` 파일을 `.class`로 컴파일 | `javac Hello.java` |
| `java` | `.class` 파일을 JVM으로 실행 (확장자 제외) | `java Hello` |

```bash
javac Hello.java   # 컴파일 → Hello.class 생성
java Hello          # 실행
```

## 4. 자바 프로그램 기본 구조와 주석

모든 자바 프로그램은 클래스(`class`) 안에 작성하며, 프로그램은 `main` 메서드에서 시작합니다.

```java
public class Hello {
    public static void main(String[] args) {
        // 이것은 한 줄 주석입니다. 컴파일 시 무시됩니다.
        /*
         * 이것은 여러 줄 주석입니다.
         * 코드에 대한 설명을 남길 때 사용합니다.
         */
        System.out.println("Hello, Java!");
    }
}
```

- `public class Hello` : 파일명은 반드시 클래스명과 동일해야 합니다 → `Hello.java`
- `public static void main(String[] args)` : 프로그램의 시작점(진입점). 형식이 고정되어 있으므로 그대로 암기해서 사용합니다
- `//` : 한 줄 주석, `/* */` : 여러 줄 주석. 코드 실행에는 영향을 주지 않고, 코드를 설명하는 용도로 사용합니다

## 5. 변수 선언과 명명 규칙

변수는 데이터를 저장하는 상자입니다. 자바는 정적 타입 언어이므로 변수를 선언할 때 어떤 종류의 데이터를 담을지(자료형) 반드시 함께 지정해야 합니다.

```java
int 나이;       // 선언: 나이라는 이름의 int(정수) 변수를 만듦
나이 = 20;      // 대입: 나이에 20을 저장
int 점수 = 90;   // 선언과 동시에 초기화
```

**참고**: 자바는 한글을 변수명으로 사용할 수 있습니다. 이 교재에서는 이해를 돕기 위해 한글 변수명을 사용하지만, 실무에서는 영어 변수명(카멜케이스)을 사용하는 것이 일반적이라는 점을 알아두세요. (예: `age`, `studentName`)

**명명 규칙**
- 변수명은 소문자로 시작 (영어의 경우 카멜케이스: `studentName`), 한글은 단어를 그대로 붙여 사용 (`학생이름`)
- 클래스명은 대문자로 시작 (영어의 경우: `Student`), 한글 클래스명도 사용 가능 (`학생`)
- 숫자로 시작할 수 없고, 예약어(`class`, `int` 등)는 변수명으로 사용 불가

## 6. 데이터 타입 - 기본 자료형 8가지

자바의 기본 자료형(primitive type)은 8가지이며, 크게 정수/실수/문자/논리로 나뉩니다.

| 자료형 | 종류 | 크기 | 설명 | 예시 |
|---|---|---|---|---|
| byte | 정수 | 1byte | 아주 작은 범위의 정수 | `byte b = 10;` |
| short | 정수 | 2byte | 작은 범위의 정수 | `short s = 100;` |
| int | 정수 | 4byte | 가장 많이 쓰는 정수형 | `int 나이 = 20;` |
| long | 정수 | 8byte | 아주 큰 정수(끝에 L 붙임) | `long 큰수 = 10000000000L;` |
| float | 실수 | 4byte | 실수(끝에 f 붙임) | `float f = 3.14f;` |
| double | 실수 | 8byte | 가장 많이 쓰는 실수형 | `double 원주율 = 3.14159;` |
| char | 문자 | 2byte | 문자 1개(작은따옴표) | `char 학점 = 'A';` |
| boolean | 논리 | 1bit | true/false만 저장 | `boolean 통과여부 = true;` |

실무/학습에서는 정수는 `int`, 실수는 `double`을 기본으로 사용합니다.

```java
public class 변수예제 {
    public static void main(String[] args) {
        int 나이 = 20;
        double 키 = 175.5;
        char 학점 = 'A';
        boolean 재학여부 = true;

        System.out.println("나이: " + 나이);
        System.out.println("키: " + 키);
        System.out.println("학점: " + 학점);
        System.out.println("재학 여부: " + 재학여부);
    }
}
```

**설명**: `+` 연산자는 문자열과 다른 자료형을 이어 붙일 때, 뒤에 오는 값을 자동으로 문자열로 변환해서 이어줍니다. 이 성질을 이용해 변수 값을 문자열 사이에 끼워 출력할 수 있습니다.

## 7. 형변환 (자동 형변환 / 강제 형변환)

**자동 형변환**은 작은 범위의 자료형이 큰 범위의 자료형에 대입될 때 자바가 자동으로 변환해줍니다.

```java
int 정수값 = 10;
double 실수값 = 정수값;  // int -> double, 자동 변환 (10.0)
```

**강제 형변환(캐스팅)** 은 큰 범위를 작은 범위로 바꿀 때, 자료형 이름을 괄호로 감싸 앞에 붙여서 명시적으로 변환합니다. 이때 정보 손실(소수점 버림 등)이 발생할 수 있습니다.

```java
double 실수값 = 3.9;
int 정수값 = (int) 실수값;   // 강제 형변환, 결과: 3 (소수점 버림)

int a = 5, b = 2;
double 결과 = (double) a / b;  // a를 double로 캐스팅 후 나눗셈 → 2.5
```

`(double) a / b`처럼 나눗셈 **전에** 피연산자 하나를 `double`로 캐스팅해야 소수점 결과가 제대로 나옵니다. 나눗셈 연산자(`/`)는 다음 챕터(연산자)에서 자세히 다룹니다.

## 8. 출력 메서드

값을 화면에 확인하기 위해 아래 출력 메서드를 사용합니다.

| 메서드 | 설명 | 예시 |
|---|---|---|
| `System.out.println()` | 출력 후 줄바꿈 | `System.out.println("Hi");` |
| `System.out.print()` | 출력만 하고 줄바꿈 없음 | `System.out.print("Hi");` |
| `System.out.printf()` | 형식을 지정해 출력 | `System.out.printf("%.2f", 3.14159);` |

`printf`는 `%d`(정수), `%f`(실수), `%.2f`(소수점 둘째자리까지), `%s`(문자열), `%n`(줄바꿈) 같은 형식 지정자를 사용합니다.

```java
public class 출력예제 {
    public static void main(String[] args) {
        String 이름 = "홍길동";
        double 평점 = 3.856;

        System.out.print("이름: ");
        System.out.println(이름);                     // 줄바꿈 있음
        System.out.printf("평점: %.2f%n", 평점);        // 평점: 3.86 (반올림)
    }
}
```

**설명**: `print`는 줄바꿈이 없어서 다음 출력이 같은 줄에 이어집니다. 그래서 "이름: "을 `print`로 출력한 뒤 `println`으로 실제 이름을 이어붙이면 한 줄에 "이름: 홍길동"이 완성됩니다. `printf`의 `%.2f`는 소수점 둘째 자리까지 반올림해서 출력합니다.

## 자주 하는 실수

1. **변수 선언 없이 사용 / 초기화 안 하고 사용**
   ```java
   int 점수;
   System.out.println(점수); // 컴파일 에러: 초기화되지 않은 변수
   ```
   지역 변수는 반드시 값을 대입한 뒤 사용해야 합니다.

2. **캐스팅 위치 실수 (나눗셈 결과가 아니라 피연산자를 캐스팅)**
   ```java
   int a = 5, b = 2;
   double 잘못된결과 = (double) (a / b); // a/b가 먼저 정수 나눗셈(2)으로 계산된 후 캐스팅 → 2.0 (틀림)
   double 올바른결과 = (double) a / b;   // a만 먼저 double로 캐스팅 → 2.5 (맞음)
   ```

3. **char는 작은따옴표, String은 큰따옴표 혼동**
   ```java
   char 학점 = "A";  // 컴파일 에러: char는 작은따옴표(')만 가능
   char 학점 = 'A';  // 올바른 표현
   ```

4. **long, float 리터럴에 접미사(L, f) 누락**
   ```java
   long 큰수 = 10000000000;   // 컴파일 에러: int 범위를 초과하는 값에 L 필요
   long 큰수 = 10000000000L;  // 올바른 표현

   float f = 3.14;   // 컴파일 에러: 기본적으로 3.14는 double이므로 f 필요
   float f = 3.14f;  // 올바른 표현
   ```

## 핵심 요약

| 항목 | 핵심 내용 |
|---|---|
| JVM/JDK | JDK로 컴파일(javac) → JVM으로 실행(java) |
| 프로그램 구조 | `public class 파일명 { public static void main(String[] args) { } }` |
| 주석 | `//` 한 줄, `/* */` 여러 줄 |
| 변수 | 자료형 + 변수명으로 선언, 한글 변수명 사용 가능 |
| 기본 자료형 | 정수는 int, 실수는 double을 기본으로 사용 |
| 형변환 | 작은→큰: 자동, 큰→작은: `(자료형)` 강제 캐스팅 필요 |
| 출력 | `println`(줄바꿈), `print`(줄바꿈 없음), `printf`(형식 지정) |
