## 기본

### 문제 1. 인사 메서드 만들기

```java
public class Practice1 {
    public static void 인사() {
        System.out.println("안녕하세요, 자바 세계!");
    }

    public static void main(String[] args) {
        인사();
        인사();
    }
}
```

**설명**: `인사()`는 반환값이 없는 `void` 메서드로, 호출할 때마다 정해진 문장을 출력하는 동작만 반복합니다.

**틀리기 쉬운 포인트**: 메서드 정의를 `main` 메서드 **안에** 넣으면 컴파일 에러가 납니다. 메서드는 반드시 클래스 안, `main`과 같은 레벨(형제 관계)에 정의해야 합니다.

### 문제 2. 두 수를 더하는 메서드

```java
public class Practice2 {
    public static int 더하기(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        int 결과 = 더하기(3, 7);
        System.out.println("결과: " + 결과);
    }
}
```

**설명**: `더하기` 메서드는 `int`를 반환하므로, 호출한 곳(`main`)에서 `int 결과 = 더하기(3, 7);`처럼 반환값을 변수에 저장해서 사용할 수 있습니다.

**틀리기 쉬운 포인트**: `더하기(3, 7);`만 쓰고 반환값을 저장하지 않으면 계산은 이루어지지만 결과를 화면에 출력하거나 다른 곳에서 사용할 수 없습니다.

## 응용

### 문제 3. 이름을 매개변수로 받아 인사하기

```java
public class Practice3 {
    public static void 환영인사(String 이름) {
        System.out.println(이름 + "님 환영합니다!");
    }

    public static void main(String[] args) {
        환영인사("홍길동");
    }
}
```

**설명**: `String 이름`이라는 매개변수를 통해 호출할 때 넘긴 `"홍길동"`이라는 값이 메서드 내부의 `이름` 변수에 전달되어 사용됩니다.

**틀리기 쉬운 포인트**: 매개변수 자료형(`String`)과 호출 시 넘기는 값의 자료형이 일치해야 합니다. 예를 들어 `환영인사(123)`처럼 정수를 넘기면 컴파일 에러가 납니다.

### 문제 4. 최댓값을 반환하는 메서드

```java
public class Practice4 {
    public static int 최댓값(int a, int b) {
        return (a > b) ? a : b; // Day2에서 배운 삼항 연산자 활용
    }

    public static void main(String[] args) {
        System.out.println("최댓값: " + 최댓값(7, 3));
    }
}
```

**설명**: 삼항 연산자로 `a`와 `b` 중 더 큰 값을 바로 `return`합니다. `if-else`로 풀어써도 같은 결과지만, 이렇게 간단한 비교는 삼항 연산자로 한 줄에 처리할 수 있습니다.

**틀리기 쉬운 포인트**: `if (a > b) return a; else return b;`처럼 작성해도 되지만, 둘 중 하나라도 `return`을 빠뜨리면 "모든 경로에서 값을 반환하지 않는다"는 컴파일 에러가 발생합니다.

### 문제 5. 짝수 판별 메서드 (boolean 반환)

```java
public class Practice5 {
    public static boolean 짝수인가(int n) {
        return n % 2 == 0;
    }

    public static void main(String[] args) {
        System.out.println("4는 짝수인가? " + 짝수인가(4));
        System.out.println("7는 짝수인가? " + 짝수인가(7));
    }
}
```

**설명**: `n % 2 == 0`이라는 비교식 자체가 `boolean` 값(`true`/`false`)이므로, 이 식을 그대로 `return`하면 됩니다. 굳이 `if-else`로 `true`/`false`를 따로 반환할 필요가 없습니다.

**틀리기 쉬운 포인트**: `if (n % 2 == 0) { return true; } else { return false; }`처럼 길게 쓰는 실수를 하기 쉬운데, 비교식 자체가 이미 boolean이므로 바로 반환하는 것이 더 간결합니다.

## 도전

### 문제 6. 배열의 합계를 반환하는 메서드

```java
public class Practice6 {
    public static int 합계구하기(int[] 배열) {
        int 합계 = 0;
        for (int 값 : 배열) {
            합계 += 값;
        }
        return 합계;
    }

    public static void main(String[] args) {
        int[] 숫자들 = {10, 20, 30};
        System.out.println("합계: " + 합계구하기(숫자들));
    }
}
```

**설명**: 배열도 매개변수로 전달할 수 있습니다(`int[] 배열`). 메서드 내부에서는 Day5~6에서 배운 향상된 for문으로 배열의 모든 요소를 순회하며 합계를 누적한 뒤 반환합니다.

**틀리기 쉬운 포인트**: 배열을 매개변수로 받을 때 `int[] 배열`처럼 대괄호를 자료형 뒤에 붙여야 합니다. `int 배열[]`도 문법적으로는 가능하지만 관례상 `int[] 배열` 형태를 사용합니다.

### 문제 7. 종합 - 성적 처리 메서드 묶음

```java
public class Practice7 {
    public static double 평균구하기(int[] 점수들) {
        int 합계 = 0;
        for (int 점수 : 점수들) {
            합계 += 점수;
        }
        return (double) 합계 / 점수들.length;
    }

    public static String 등급판정(double 평균) {
        if (평균 >= 90) {
            return "A";
        } else if (평균 >= 80) {
            return "B";
        } else {
            return "C";
        }
    }

    public static void main(String[] args) {
        int[] 점수들 = {88, 92, 79, 95};

        double 평균 = 평균구하기(점수들);
        String 등급 = 등급판정(평균);

        System.out.printf("평균: %.2f%n", 평균);
        System.out.println("등급: " + 등급);
    }
}
```

**설명**: 두 메서드가 서로 협력하는 구조입니다. `평균구하기`가 반환한 `double` 값을 그대로 `등급판정`의 매개변수로 전달해서 사용합니다. 이렇게 메서드를 기능별로 나눠두면, 각 메서드를 독립적으로 테스트하거나 재사용하기 쉬워집니다.

**틀리기 쉬운 포인트**: `평균구하기`의 반환 자료형은 `double`인데 캐스팅 없이 `합계 / 점수들.length`로 계산하면 정수 나눗셈이 되어 소수점이 사라집니다. Day1~2에서 배운 형변환을 여기서도 반드시 적용해야 합니다.
