# Day 1. 자바 시작하기 & 변수와 타입 - 실습

> 아래 문제는 교안에서 다룬 변수, 8가지 기본 자료형, 형변환, 출력 메서드(println/print/printf)만으로 풀 수 있습니다.
> 이번 챕터에서는 아직 Scanner(입력)와 연산자를 배우지 않았으므로, 값은 변수에 직접 대입해서 사용합니다.

---

## 기본

### 문제 1. 나의 정보 출력하기
이름(String), 나이(int), 키(double), 재학 여부(boolean)를 변수로 선언하고 초기화한 뒤, 각각 한 줄씩 출력하세요.
- `println`을 사용하세요.

**Output 예시**
```
이름: 홍길동
나이: 20
키: 175.5
재학 여부: true
```

---

### 문제 2. 한 줄로 출력하기
이름과 학번을 변수로 선언하고, `print`와 `println`을 조합해서 아래처럼 **한 줄**로 출력하세요.

**Output 예시**
```
이름: 홍길동, 학번: 20260001
```

---

## 응용

### 문제 3. 형변환 연습
`double` 자료형 변수에 `3.9`를 저장한 뒤, `int`로 강제 형변환해서 두 값을 모두 출력하세요.

**Output 예시**
```
원래 값: 3.9
형변환 후 값: 3
```

---

### 문제 4. 학생 성적 출력 (printf 활용)
학생의 평점(double, 예: `3.856`)을 변수로 선언하고, `printf`를 이용해 소수점 둘째 자리까지 출력하세요.

**Output 예시**
```
평점: 3.86
```

---

### 문제 5. 자료형별 변수 선언
byte, short, int, long, float, double, char, boolean 8가지 자료형의 변수를 각각 하나씩 선언하고 초기화한 뒤, 전부 출력하세요. (long과 float은 접미사 L, f를 반드시 붙이세요.)

**Output 예시**
```
byte: 10
short: 100
int: 1000
long: 10000000000
float: 3.14
double: 3.141592
char: A
boolean: true
```

---

## 도전

### 문제 6. 정수 나눗셈 결과를 실수로 출력
`int` 변수 두 개(`a = 7`, `b = 2`)를 선언하고, 형변환을 이용해 `a / b`의 결과를 소수점까지 정확하게 출력하세요. (연산자는 배우지 않았지만 `/`는 나눗셈 기호로 그대로 사용 가능합니다.)

**Output 예시**
```
7 / 2 = 3.5
```

---

### 문제 7. 학과 정보를 한글 변수로 출력하기
학과번호(String), 학과명(String), 정원(int), 개설여부(boolean)를 한글 변수명으로 선언하고 초기화한 뒤, `printf`를 이용해 아래 형식대로 출력하세요.

**Output 예시**
```
[컴퓨터공학과] 정원 40명, 개설여부 true
```

(힌트: `printf("[%s] 정원 %d명, 개설여부 %b%n", ...)` 형태로 작성해보세요. `%b`는 boolean을 출력하는 형식 지정자입니다.)
