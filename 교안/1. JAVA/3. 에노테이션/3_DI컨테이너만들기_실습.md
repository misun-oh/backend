# 부록 3. 수동 DI 컨테이너 만들기 - 실습

> 아래 문제는 교안에서 다룬 @주입 애노테이션 정의, 컨테이너의 등록()/주입() 메서드, 리플렉션(setAccessible, field.get/set)만으로 풀 수 있습니다.

---

## 기본

### 문제 1. @주입 애노테이션 정의하기
`@Retention(RetentionPolicy.RUNTIME)`, `@Target(ElementType.FIELD)`가 붙은 `주입` 커스텀 애노테이션을 정의하세요.

**확인할 것**: 컴파일 에러 없이 애노테이션이 정의되는지 확인합니다. (실행 결과 없음)

---

### 문제 2. @주입이 붙은 필드 찾기
`교수` 클래스를 만들고, `학과` 타입 필드 `소속학과`에 `@주입`을 붙이세요. 리플렉션으로 `교수` 클래스의 필드 중 `@주입`이 붙은 필드 이름을 출력하세요.

**Output**
```
주입이 필요한 필드: 소속학과
```

---

## 응용

### 문제 3. 컨테이너의 등록() 메서드만 구현하기
교안의 `컨테이너` 클래스에서 `등록()` 메서드만 구현하세요. `학과` 객체 하나를 등록한 뒤, 저장소(`Map`)에 잘 들어갔는지 `저장소.get(학과.class)`로 확인해서 출력하세요.

**Output**
```
등록된 학과명: 컴퓨터공학과
```

---

### 문제 4. 컨테이너의 주입() 메서드까지 완성
문제 3의 컨테이너에 `주입()` 메서드까지 완성하세요. `교수` 객체(`소속학과` 필드가 `@주입`)를 만들고, `학과` 객체를 등록한 뒤 `교수` 객체에 주입해서, 주입된 `소속학과`의 학과명을 출력하세요.

**Output**
```
교수의 소속학과: 컴퓨터공학과
```

---

## 도전

### 문제 5. 여러 필드를 동시에 주입받는 학생 만들기
교안의 예제처럼 `학생` 클래스에 `소속학과`, `지도교수` 두 필드 모두 `@주입`을 붙이세요. 컨테이너에 `학과`, `교수` 객체를 각각 등록한 뒤, `학생` 객체에 한 번의 `주입()` 호출로 두 필드 모두 채워지는지 확인하세요.

**Output**
```
학생의 소속학과: 컴퓨터공학과
학생의 지도교수: 김교수
```

---

### 문제 6. 종합 - 등록되지 않은 타입은 주입되지 않음을 확인
문제 5의 컨테이너에서, 이번에는 `교수` 객체를 등록하지 **않고** `학생` 객체에 `주입()`을 호출해보세요. `소속학과`는 정상적으로 채워지지만 `지도교수`는 `null`로 남아있는지 확인해서 출력하세요. (등록되지 않은 타입은 저장소에서 찾을 수 없으므로 필드가 채워지지 않아야 합니다)

**Output**
```
학생의 소속학과: 컴퓨터공학과
학생의 지도교수: null
```
