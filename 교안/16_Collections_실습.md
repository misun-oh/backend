# Day 16. 컬렉션 프레임워크 (ArrayList, Set, HashMap) - 실습

> 아래 문제는 교안에서 다룬 배열의 불편함, ArrayList, HashSet, HashMap만으로 풀 수 있습니다.

---

## 기본

### 문제 1. 배열의 불편함 재현하기
`Student[] students = new Student[3];`으로 학생 3명을 채운 뒤, 4번째 학생을 추가하려고 시도했을 때 어떤 에러가 나는지 주석으로 남기세요.

**정답 예시(주석 형태)**
```java
// students[3] = new Student("정수아", "S004");
// 실행 에러 발생: ArrayIndexOutOfBoundsException
// 이유: 배열의 크기가 3으로 고정되어 있어 인덱스 3이 존재하지 않음
```

---

### 문제 2. ArrayList로 학생 5명 담기
`List<Student>`을 만들어 학생 5명을 `add()`로 추가한 뒤, `size()`로 전체 인원수를 출력하세요.

**Output**
```
전체 학생 수: 5
```

---

### 문제 3. HashSet으로 중복 신청 방지
`Set<String>`을 만들어 학번 "S001", "S002", "S001"을 순서대로 `add()`하세요. `add()`의 반환값을 확인해서, 세 번째 시도가 중복이었는지 출력하고 최종 인원수를 출력하세요.

**Output**
```
S001 추가됨? true
S002 추가됨? true
S001 추가됨? false
최종 신청 인원: 2
```

---

## 응용

### 문제 4. ArrayList에서 추가/삭제
문제 2의 List에 6번째 학생을 `add()`로 추가한 뒤, 인덱스 2번 학생을 `remove()`로 삭제하고, 최종 학생 수와 남은 학생들의 이름을 반복문으로 출력하세요.

**Output**
```
최종 학생 수: 5
홍길동
김철수
박민수
최지우
정수아
```

---

### 문제 5. HashMap으로 학번 조회
`Map<String, Student>`을 만들어 학생 3명을 `put()`으로 저장하세요("S001"~"S003"). `get("S002")`로 특정 학생을 조회해서 이름을 출력하고, `containsKey("S999")`로 없는 학번을 확인한 결과도 출력하세요.

**Output**
```
S002 학생 이름: 김철수
S999가 존재하는가? false
```

---

### 문제 6. HashMap 전체 순회
문제 5의 Map을 `keySet()`을 이용해 순회하면서 "학번 - 이름" 형식으로 모든 학생 정보를 출력하세요.

**Output**
```
S001 - 홍길동
S002 - 김철수
S003 - 이영희
```

## 도전

### 문제 7. Set으로 학과 목록 중복 제거
문자열 배열 `{"컴퓨터공학과", "경영학과", "컴퓨터공학과", "전자공학과", "경영학과"}`를 순회하며 `Set<String>`에 하나씩 추가하세요. 최종적으로 몇 개의 서로 다른 학과가 있는지, 그리고 그 목록을 출력하세요.

**Output**
```
서로 다른 학과 수: 3
컴퓨터공학과
경영학과
전자공학과
```
(Set은 순서를 보장하지 않으므로 실제 출력 순서는 다를 수 있습니다)

---

### 문제 8. Map의 값 덮어쓰기 확인
`Map<String, Student>`에 "S001" 키로 학생 객체를 저장한 뒤, 같은 "S001" 키로 다른 이름의 학생 객체를 다시 `put()`하세요. `size()`가 몇인지, 그리고 "S001"로 조회했을 때 어떤 학생이 나오는지 확인해서 출력하세요.

**Output**
```
Map 크기: 1
S001 조회 결과: 홍길똥
```

---

### 문제 9. 종합 - List, Set, Map 함께 사용하기
학생 5명을 `List<Student>`에 저장하고, 동시에 학번을 `Set<String>`에 추가해 중복 여부를 체크하며(모두 새 학번이라고 가정), 학번을 키로 하는 `Map<String, Student>`도 함께 만드세요. 마지막으로 List를 순회하며 전체 명단을 출력하고, 특정 학번("S003")을 Map으로 즉시 조회해서 출력하세요.

**Output**
```
[전체 명단]
홍길동
김철수
이영희
박민수
최지우
[학번으로 즉시 조회] S003: 이영희
```
