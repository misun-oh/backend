# Day 8 예제 코드 — Thymeleaf 화면

`src/main/resources/templates/` 기준. 디자인 클래스는 `static/css/basic.css` · `component.css`.

## fragments/layout.html
```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head th:fragment="head(title)">
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title th:text="${title}">사원관리</title>
  <link rel="stylesheet" th:href="@{/css/basic.css}">
  <link rel="stylesheet" th:href="@{/css/component.css}">
  <link rel="stylesheet" th:href="@{/css/app-shell.css}">
  <script th:src="@{/js/component.js}" defer></script>
</head>
<body>
  <header th:fragment="header" class="site-header">
    <div class="site-header__inner container container--wide">
      <a class="site-header__brand" th:href="@{/emps}">👔 사원관리</a>
      <nav class="site-nav hide-mobile">
        <a th:href="@{/emps}">사원 목록</a>
        <a th:href="@{/depts}">부서</a>
      </nav>
    </div>
  </header>

  <footer th:fragment="footer" class="site-footer">
    <div class="container container--wide"><p>© 2026 사원관리 시스템</p></div>
  </footer>
</body>
</html>
```

## emp/list.html
```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head th:replace="~{fragments/layout :: head('사원 목록')}"></head>
<body>
  <div th:replace="~{fragments/layout :: header}"></div>

  <main class="app-main container container--wide">
    <div class="page-head">
      <div><h1>사원 목록</h1><p th:text="|전체 ${#lists.size(emps)}명|">전체</p></div>
      <a class="btn btn--primary" th:href="@{/emps/new}">+ 사원 등록</a>
    </div>

    <p class="form-hint" th:if="${message}" th:text="${message}"></p>

    <div class="table-wrap">
      <table class="table">
        <thead>
          <tr><th>사번</th><th>이름</th><th>부서</th><th>입사일</th><th>상태</th></tr>
        </thead>
        <tbody>
          <tr th:each="e : ${emps}">
            <td th:text="${e.empId}">200</td>
            <td><a th:href="@{/emps/{id}(id=${e.empId})}" th:text="${e.empName}">이름</a></td>
            <td th:text="${e.deptName}">부서</td>
            <td th:text="${#temporals.format(e.hireDate, 'yyyy-MM-dd')}">2015-05-20</td>
            <td>
              <span class="badge badge--dot"
                    th:classappend="${e.active} ? 'badge--success' : 'badge--danger'"
                    th:text="${e.active} ? '재직' : '퇴사'">상태</span>
            </td>
          </tr>
          <tr th:if="${#lists.isEmpty(emps)}"><td colspan="5">등록된 사원이 없습니다</td></tr>
        </tbody>
      </table>
    </div>
  </main>

  <div th:replace="~{fragments/layout :: footer}"></div>
</body>
</html>
```

## emp/form.html
```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head th:replace="~{fragments/layout :: head('사원 등록/수정')}"></head>
<body>
  <div th:replace="~{fragments/layout :: header}"></div>

  <main class="app-main container">
    <h1 th:text="${form.empId != null} ? '사원 수정' : '사원 등록'">사원 등록</h1>

    <form class="card" style="padding: var(--space-6)"
          th:object="${form}" method="post"
          th:action="${form.empId != null} ? @{/emps/{id}(id=${form.empId})} : @{/emps}">
      <input type="hidden" th:field="*{empId}">

      <div class="form-grid">
        <div class="field">
          <label class="label" for="empName">이름</label>
          <input class="input" type="text" th:field="*{empName}">
        </div>
        <div class="field">
          <label class="label" for="email">이메일</label>
          <input class="input" type="email" th:field="*{email}">
        </div>
        <div class="field">
          <label class="label" for="deptId">부서</label>
          <select class="select" th:field="*{deptId}">
            <option value="">선택</option>
            <option th:each="d : ${depts}" th:value="${d.deptId}" th:text="${d.deptName}"></option>
          </select>
        </div>
        <div class="field">
          <label class="label" for="salary">급여</label>
          <input class="input" type="number" th:field="*{salary}">
        </div>
        <div class="field">
          <label class="label" for="hireDate">입사일</label>
          <input class="input" type="date" th:field="*{hireDate}">
        </div>
      </div>

      <div class="row row--between mt-6">
        <a class="btn btn--ghost" th:href="@{/emps}">취소</a>
        <button class="btn btn--primary" type="submit">저장</button>
      </div>
    </form>
  </main>

  <div th:replace="~{fragments/layout :: footer}"></div>
</body>
</html>
```
