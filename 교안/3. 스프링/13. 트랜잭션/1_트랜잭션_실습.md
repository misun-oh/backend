## 문제 2. 롤백되는 등록

`EmpService.registerWithHistory(EmpForm form)` 을 만들어:
1. `empMapper.insert(emp)` (사원 저장)
2. `historyMapper.insert(...)` — 여기서 일부러 `RuntimeException("이력 저장 실패")` 를 던지기
   (또는 존재하지 않는 컬럼에 INSERT해서 SQL 예외 유발)

`@Transactional` 을 붙인 버전과 뗀 버전을 각각 호출해, 예외 후 `EMP` 테이블 상태를 비교하는
테스트를 작성하세요. (`@Transactional` 없는 테스트 클래스 + `@AfterEach` 정리)

**확인할 것**: `@Transactional` 있을 때 사원이 저장되지 않음(롤백), 없을 때 사원만 저장됨(부분 반영).

}
@Transactional
public void registerOne(EmpForm f) { ... }

## 문제 5. (개념) 예외를 삼키면

```java
@Transactional
public void x() {
    aMapper.insert(...);
    try { bMapper.insert(...); }
    catch (Exception e) { log.error("b 실패", e); }   // 잡고 안 던짐
}
```
`bMapper.insert` 에서 예외가 났을 때 `aMapper.insert` 는 커밋되나 롤백되나? 왜?
"a는 살리고 b만 건너뛰고 싶다"면 어떻게 설계해야 하나?
