| F4 | **사원 상세** — 기본정보/급여/조직 탭, 부서명·직급명 조인 표시 | 8, 11 |

## 3. 선택 요구사항 (여유가 되면)

- S1 사원 프로필 사진 업로드/표시, 첨부 문서 다운로드 (Day 16)
- S2 실행 시간 로깅 애스펙트 (Day 6)
- S3 로그를 프로파일별로(dev 콘솔 / prod 파일) (Day 3)
- S4 JWT 로그인까지 추가(세션과 병행, `/api/**` stateless 체인) (Day 19)
- S5 `@Sql` 시드 + `@Transactional` 로 핵심 시나리오 통합 테스트

## 4. 설계 산출물 (먼저 그린다 — Day 1 방식)

`docs/` 또는 `20. 미니 프로젝트/설계/` 에:

1. **유즈케이스 다이어그램** — 액터(인사담당자=USER, 관리자=ADMIN)와 F1~F9.
2. **화면 흐름도** — 로그인 → 목록 → (상세 / 등록폼 / 대시보드 / 부서). 버튼 하나 = 컨트롤러 메서드 하나.
3. **클래스 다이어그램** — `EmpController/EmpApiController → EmpService → EmpMapper`,
   `DeptController → DeptService → DeptMapper`, `AuthController/MemberService`, 도메인·DTO.
4. **시퀀스 다이어그램** — "로그인", "검색+페이징 목록", "사원 등록(검증 실패 포함)" 3개.
5. **패키지 구조** 확정 (아래).

## 5. 패키지 구조

```
com.example.hr
├── HrApplication.java
├── config/        SecurityConfig, WebConfig, (JwtConfig), MyBatisConfig
├── common/        BusinessException, ApiError, PageResult, GlobalExceptionHandler, ApiExceptionHandler, LoggingAspect
├── domain/        Emp, Dept, Member, Attachment
├── dto/           EmpForm, EmpSearchCond, DeptListRow, EmpCreateRequest/Response, SignupForm, LoginRequest ...
├── controller/    EmpViewController, EmpApiController, DeptController, DashboardController, AuthController
├── service/       EmpService(+Impl), DeptService(+Impl), MemberService, FileStorage, DashboardService
└── mapper/        EmpMapper, DeptMapper, MemberMapper, AttachmentMapper   (+ resources/mapper/*.xml)
```
