## 3. 클래스 다이어그램

```mermaid
classDiagram
    class EmpController {
      +list(cond, model) String
      +detail(id, model) String
      +newForm(model) String
      +save(form) String
      +delete(id) String
    }
    class EmpService {
      <<interface>>
      +search(EmpSearchCond) PageResult
      +get(id) Emp
      +register(EmpForm) Long
      +modify(id, form) void
      +remove(id) void
    }
    class EmpServiceImpl {
      -EmpMapper empMapper
    }
    class EmpMapper {
      <<interface>>
      +selectByCond(EmpSearchCond) List
      +countByCond(EmpSearchCond) long
      +selectById(id) Emp
      +insert(Emp) void
      +update(Emp) void
      +deleteById(id) void
    }
    class Emp {
      +Long empId
      +String empName
      +String email
      +Long deptId
      +String jobCode
      +int salary
      +Long managerId
      +LocalDate hireDate
      +boolean active
      +String deptName
      +String jobName
    }
    class EmpSearchCond {
      +String keyword
      +Long deptId
      +boolean activeOnly
      +int page
    }
    class EmpForm {
      +String empName
      +String email
      +Long deptId
      +Integer salary
      +LocalDate hireDate
    }
    class PageResult {
      +List content
      +long totalElements
      +int page
    }

    EmpController --> EmpService
    EmpService <|.. EmpServiceImpl
    EmpServiceImpl --> EmpMapper
    EmpMapper ..> Emp
    EmpController ..> EmpSearchCond
    EmpController ..> EmpForm
```

> `Dept` 클래스는 이 그림에서 뺐습니다. `Emp`는 `Dept` 객체가 아니라 `deptId`(FK 값)만 보유하고,
> `deptName`·`jobName`은 목록 조회 SQL이 `DEPT`·`JOB`을 조인해 채우는 읽기 전용 필드(등록·수정 땐 빈 값).

## 4. 시퀀스 — 사원 등록

```mermaid
sequenceDiagram
    actor U as 인사담당자(브라우저)
    participant C as EmpController
    participant S as EmpService
    participant M as EmpMapper
    participant DB as MySQL

    U->>C: POST /emps (EmpForm)
    C->>C: @Valid 로 입력값 검증
    alt 검증 실패
        C-->>U: 폼 화면 다시 + 에러 메시지
    else 검증 통과
        C->>S: register(form)
        S->>S: EmpForm → Emp 로 변환
        S->>M: insert(emp)
        M->>DB: INSERT INTO EMP ...
        DB-->>M: 생성된 EMP_ID
        M-->>S: empId
        S-->>C: empId
        C-->>U: 302 Redirect /emps/{empId}
    end
```

## 5. 시퀀스 — 사원 목록 조회 (검색·페이징)

```mermaid
sequenceDiagram
    actor U as 사용자(브라우저)
    participant C as EmpController
    participant S as EmpService
    participant M as EmpMapper
    participant DB as MySQL

    U->>C: GET /emps (검색어=김, 부서=5, 2페이지)
    C->>S: search(cond)
    S->>M: selectByCond(cond)
    M->>DB: SELECT ... JOIN DEPT JOIN JOB ... LIMIT 10 OFFSET 10
    DB-->>M: 사원 10건
    M-->>S: Emp 목록 (deptName·jobName 조인 채움)
    S->>M: countByCond(cond)
    M->>DB: SELECT COUNT(*) ...
    DB-->>M: 전체 건수 43
    M-->>S: 43
    S-->>C: PageResult (10건, 총 43, 2페이지)
    C-->>U: 목록 HTML (Thymeleaf 렌더링)
```
