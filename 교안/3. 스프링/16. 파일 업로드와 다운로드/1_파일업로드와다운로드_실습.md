# Day 16. 파일 업로드와 다운로드 — 실습

준비: `ATTACHMENT` 테이블 생성(교안 2절 DDL), `application.yml` 에
`spring.servlet.multipart.max-file-size: 5MB`, `hr.file.base-dir: ${user.home}/hr-uploads`.

## 문제 1. 설정 프로퍼티

`@ConfigurationProperties(prefix = "hr.file")` 로 `FileProps(baseDir)` 를 만들고,
`@ConfigurationPropertiesScan` 또는 `@EnableConfigurationProperties` 로 등록하세요.

## 문제 2. 저장 서비스

`FileStorage.store(MultipartFile)` 를 구현하세요.
- 확장자 추출 → `UUID + ext` 저장 파일명
- `baseDir/yyyy/MM/` 하위에 저장, 없으면 `Files.createDirectories`
- 경로 정규화(`normalize()`) 후 `baseDir` 로 시작하는지 검사(탈출 방어)
- 반환: `StoredFile(originName, storedName, path, size, contentType)`

`ATTACHMENT` INSERT 하는 `AttachmentMapper.insert` 도 만드세요.

## 문제 3. 사원 사진 업로드

- `emp/detail.html` 에 `enctype="multipart/form-data"` 폼 + `<input type="file" name="file">`
- `POST /emps/{id}/photo` → 검증(빈 파일·이미지 확장자·5MB) → `FileStorage.store` → `ATTACHMENT`
  (`REF_TYPE='EMP_PHOTO'`, `REF_ID=empId`) → `redirect:/emps/{id}`
- 상세 화면에 그 사원의 최신 사진을 `<img>` 로 표시(정적 리소스 핸들러 `/uploads/**` 매핑)

## 문제 4. 첨부 다운로드

- `GET /files/{attId}/download` → `ResponseEntity<Resource>` 로 다운로드
- `Content-Disposition: attachment` + 한글 파일명(`filename*=UTF-8''...`)
- 파일이 없으면 404

`한글 이름.png` 를 업로드한 뒤 다운로드해, **저장되는 파일명이 원본 그대로**인지 확인하세요.

## 문제 5. 크기 초과 처리

6MB 파일을 업로드해 `MaxUploadSizeExceededException` 이 나는지 확인하고,
`@ControllerAdvice` 에 핸들러를 추가해 사용자에게 "5MB 이하만 업로드할 수 있습니다" 를 보여주세요.
