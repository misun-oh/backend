# Day 18. 미니 프로젝트 — 요구사항과 설계

지금까지 배운 것을 하나의 애플리케이션으로 완성합니다. 새 개념을 배우는 날이 아니라,
**Day 1의 방식으로 스스로 설계하고 → 구현하고 → 스스로 점검**하는 날입니다.

## 1. 무엇을 만드나

**사원관리 시스템** — 지금까지 챕터마다 조금씩 만들어 온 것을 정리하고, 빠진 부분을 채워
"쓸 수 있는 수준"으로 마무리합니다.

프로토타입: `교안/3. 스프링/prototypes/templates/hr/` (이 화면을 목표로).

## 2. 기능 요구사항 (필수)

| # | 기능 | 관련 챕터 |
|---|---|---|
| F1 | **로그인/로그아웃** — 세션(Day 12) 필수. 미인증 시 접근 차단 | 12 |

| F3 | **사원 목록** — 이름·부서·재직여부 검색 + 페이징(10건) + 정렬(입사일/급여/이름) | 11 |
| F4 | **사원 상세** — 기본정보/급여/조직 탭, 부서명·직급명 조인 표시 | 8, 11 |
| F5 | **사원 등록/수정** — 폼 검증(필수/형식), 에러 메시지 화면 표시, 같은 폼 재사용 | 15 |
| F6 | **사원 삭제** — ADMIN만. 확인 모달. 삭제 후 목록으로 | 8, 12 |

| F9 | **사원 REST API** — `/api/emps` CRUD + 표준 에러 응답. MockMvc 테스트 | 16 |

## 3. 선택 요구사항 (여유가 되면)

- S1 사원 프로필 사진 업로드/표시, 첨부 문서 다운로드 (Day 17)
- S2 실행 시간 로깅 애스펙트 (Day 14)
- S3 로그를 프로파일별로(dev 콘솔 / prod 파일) (Day 3)
- S4 JWT 로그인까지 추가(세션과 병행, `/api/**` stateless 체인) — 부록 2. JWT 학습 후
- S5 `@Sql` 시드 + `@Transactional` 로 핵심 시나리오 통합 테스트
- S6 Spring Security로 F1·F2·F6·F7의 로그인/권한 체크를 통째로 교체 — 부록 3~4 학습 후

## 4. 설계 산출물 (먼저 그린다 — Day 1 방식)

`docs/` 또는 `18. 미니 프로젝트/설계/` 에:

1. **유즈케이스 다이어그램** — 액터(인사담당자=USER, 관리자=ADMIN)와 F1~F9.
2. **화면 흐름도** — 로그인 → 목록 → (상세 / 등록폼 / 대시보드 / 부서). 버튼 하나 = 컨트롤러 메서드 하나.
3. **클래스 다이어그램** — `EmpController/EmpApiController → EmpService → EmpMapper`,
   `DeptController → DeptService → DeptMapper`, `LoginController/MemberService`, 도메인·DTO.
4. **시퀀스 다이어그램** — "로그인", "검색+페이징 목록", "사원 등록(검증 실패 포함)" 3개.
5. **패키지 구조** 확정 (아래).

## 5. 패키지 구조

```
com.example.hr
├── HrApplication.java
├── config/        WebConfig(인터셉터 등록), MyBatisConfig, (SecurityConfig — 부록 3 적용 시)
├── common/        BusinessException, ApiError, PageResult, GlobalExceptionHandler, ApiExceptionHandler, LoggingAspect
├── interceptor/   LoginCheckInterceptor, AdminOnlyInterceptor
├── domain/        Emp, Dept, Member, Attachment
├── dto/           EmpForm, EmpSearchCond, DeptListRow, EmpCreateRequest/Response, SignupForm, LoginRequest ...
├── controller/    EmpViewController, EmpApiController, DeptController, DashboardController, LoginController
├── service/       EmpService(+Impl), DeptService(+Impl), MemberService, FileStorage, DashboardService
└── mapper/        EmpMapper, DeptMapper, MemberMapper, AttachmentMapper   (+ resources/mapper/*.xml)
```
