# Day 18. 미니 프로젝트 — 구현 가이드

챕터마다 만든 조각을 순서대로 정리·연결합니다. "새로 짜기"가 아니라 "이어 붙이고 빈 곳 채우기".

## 0. 프로젝트 정리

- `build.gradle` 의존성 확인 (Boot 4 기준):
  `spring-boot-starter-webmvc` · `-thymeleaf` · `-validation` · `-aop`,
  `spring-security-crypto`(BCrypt만, Day 12), `mybatis-spring-boot-starter:4.0.1`, `com.mysql:mysql-connector-j`,
  (부록까지 학습했다면 선택) `-security`, jjwt(`jjwt-api`/`-impl`/`-gson` 0.13.0), thymeleaf-extras-springsecurity,
  lombok, devtools, (test) `spring-boot-starter-test` + `junit-platform-launcher`.
  → 상세는 [00_SpringBoot4_기준.md](../00_SpringBoot4_기준.md).
- `application.yml`: datasource, mybatis(`map-underscore-to-camel-case`, `mapper-locations`),
  `logging.level.com.example.hr=DEBUG`, `spring.servlet.multipart.*`, `jwt.*`(선택).
- `static/` 에 `basic.css` `component.css` `app-shell.css` `component.js` 복사(`prototypes/static/` 에서).
- `templates/fragments/layout.html` (Day 10), `templates/error/{403,404,500}.html` (Day 12·15).

## 1. 도메인 · DTO (Day 1·5·9·11·16)

`domain/`: `Emp`(+`deptName`·`jobName` 조인 채움 읽기 필드; 상세용 `Dept dept`는 선택), `Dept`, `Member`, `Attachment`(선택).
`dto/`: `EmpForm`(검증), `EmpSearchCond`(+`getOffset`), `EmpSort`(enum),
`PageResult<T>`, `DeptListRow`(인원·평균급여 집계), `EmpCreateRequest`/`EmpUpdateRequest`/`EmpResponse`(record), `SignupForm`, `LoginRequest`.

## 2. Mapper (Day 7·9·11)

`EmpMapper` + `EmpMapper.xml`:
- `findPage(EmpSearchCond)` / `countPage(EmpSearchCond)` — `<where>`+`<if>`, `LIMIT/OFFSET`, `ORDER BY ${sort.column} ${sort.direction}`
- `findByIdWithDept(id)` — `<association>`
- `insert`/`update`/`deleteById`, `countByEmail`
`DeptMapper` — `findAll`, `findAllWithStats`(인원·평균급여 GROUP BY), `insert`, `deleteById`, `countEmpsByDeptId`
`MemberMapper` — `existsById(memberId)`, `insert`(`ROLE` 기본값 `'USER'`), `findById`(`ROLE` 포함)
`AttachmentMapper`(선택) — `insert`, `findLatest(refType, refId)`, `findById`

> 각 Mapper는 `@SpringBootTest @Transactional` 테스트로 한 번씩 확인하고 넘어간다(Day 8).

## 3. Service (Day 5·12·13·15)

`EmpServiceImpl` (`@Transactional(readOnly = true)` 클래스, 쓰기 메서드만 `@Transactional`):
- `search(cond) → PageResult<Emp>` (목록 SQL이 `deptName`·`jobName` 조인해 채움)
- `getWithDept(id) → Emp` (없으면 `NoSuchElementException`)
- `register(form) → Long` (검증은 컨트롤러, 여기선 변환+저장)
- `modify(id, form)` (update 반환 0이면 `NoSuchElementException`)
- `remove(id)`
- `existsByEmail(email)`

`DeptServiceImpl` — `findAllWithStats`, `register`, `remove`(소속 사원 있으면 `BusinessException` — Day 1 실습).
`MemberService.signup` — 중복 검사 + `BCryptPasswordEncoder.encode` + INSERT(`ROLE='USER'` 고정) (Day 12).
`DashboardService.summary()` — 통계 묶음 DTO.
`FileStorage.store` / `AttachmentService`(선택, Day 17).

## 4. 화면 컨트롤러 (Day 6·10·11·15)

`EmpViewController` (`@Controller`, `/emps`):
- `GET /emps` — `@ModelAttribute EmpSearchCond` + `PageResult` + `depts` → `emp/list`
- `GET /emps/{id}` — `getWithDept` → `emp/detail` (+ 선택: 사진)
- `GET /emps/new` / `GET /emps/{id}/edit` — `form` + `depts` → `emp/form`
- `POST /emps` / `POST /emps/{id}` — `@Valid EmpForm form, BindingResult br` → 에러면 `emp/form`, 아니면 redirect
- `POST /emps/{id}/delete` — ADMIN (`AdminOnlyInterceptor` 가 경로로 차단), redirect

`DeptController`(`/depts`, `AdminOnlyInterceptor` 적용), `DashboardController`(`/` 또는 `/dashboard`), `LoginController`(`/login`, `/signup`, `/logout`).

## 5. API 컨트롤러 (Day 16·18)

`EmpApiController`(`/api/emps`): list/detail/create(201+Location)/update/delete(204).
`ApiExceptionHandler`(`@RestControllerAdvice(basePackages="...controller")`): 400/404/409/500 JSON.
(선택, 부록 2까지 학습했다면) `/api/auth/login` + `JwtAuthFilter` + `/api/**` stateless 체인.

## 6. 인증·인가 (Day 12, 선택 심화는 부록 3~4)

`WebConfig`(`WebMvcConfigurer`)에 인터셉터 등록:
- `LoginCheckInterceptor` — 전 구간, `excludePathPatterns("/login", "/signup", "/css/**", "/js/**", "/uploads/**", "/error")`
- `AdminOnlyInterceptor` — `addPathPatterns("/depts/**", "/emps/*/delete")`

`LoginController` — `/login`(GET/POST), `/logout`(POST), `/signup`(GET/POST, `MemberService.signup` 호출).
`BCryptPasswordEncoder` 로 비밀번호 해시·검증. 헤더 fragment 에 `th:if="${loginMember != null}"` /
`th:if="${loginMember.role == 'ADMIN'}"` 로 로그인/로그아웃·ADMIN 메뉴 노출.

> **부록까지 학습했다면(S6)**: 이 절 전체를 `SecurityConfig`(`SecurityFilterChain`, `UserDetailsService`,
> `hasRole("ADMIN")`, `formLogin`/`logout`, `sec:authorize`)로 통째로 교체할 수 있습니다. Controller/
> Service/도메인 계층은 그대로 두고 인증·인가 구현만 바뀝니다.

## 7. 공통 (Day 3·14·15)

- `common/GlobalExceptionHandler`(`@ControllerAdvice`) — `NoSuchElementException`→404화면,
  `BusinessException`→이전 화면+flash, `Exception`→500화면+log.
- `common/LoggingAspect`(선택) — 서비스/컨트롤러 실행 시간.
- `logback-spring.xml`(선택) — dev/prod 프로파일.

## 8. 실행 순서 팁
