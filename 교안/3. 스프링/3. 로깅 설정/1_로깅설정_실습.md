## 문제 1. 레벨별 로그 출력

- `log.trace`, `log.debug`, `log.info`, `log.warn`, `log.error` 를 각각 한 줄씩 (메시지는 자유)
- `name` 값을 `{}` 파라미터 바인딩으로 포함할 것

`application.yml` 에서 `com.example.hr` 레벨을 바꿔 가며 `GET /hello` 를 호출하세요.

**확인할 것**: 레벨을 `INFO` 로 뒀을 때 콘솔에 찍히는 로그는 몇 개인가? `DEBUG` 로 뒀을 때는?

나면 `log.error` 로 **스택트레이스까지** 남기고 `"0으로 나눌 수 없습니다"` 문자열을 반환하세요.

## 문제 5. 프로파일별 로깅

- 프로파일 `prod` : 콘솔 + `logs/hr.log` 파일, `com.example.hr` = INFO, root = WARN

IntelliJ Run Configuration 의 Active profiles 를 `dev` → `prod` 로 바꿔 실행하고,
`GET /hello` 호출 시 콘솔 로그 개수가 어떻게 달라지는지 적으세요.
