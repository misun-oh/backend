# 스프링 시험 - 학사관리 시스템

## 1. 시험 개요

| 항목 | 내용 |
|---|---|
| 시험 유형 | 필기 + Spring Boot 실기 프로젝트 |
| 시험 시간 | 2시간 |
| 기본 총점 | 100점: 필기 50점 + 실기 50점 |
| 주제 | 학사관리 시스템 |

사원관리 시스템을 만들었던 방식과 동일하게 프로젝트를 생성하고 학생 목록, 검색, 페이징을 구현한다.

필기시험 문제는 같은 폴더의 `2_학사관리_필기시험.md`를 참고한다.

---

## 2. 학사관리 시나리오

학교 행정 담당자가 학생 정보를 관리하는 프로그램이다. 학생 목록에서 학생을 확인하고, 이름·학과·재학 상태로 검색하며, 페이지를 이동한다.

참고 프로토타입:

- `prototypes/templates/academic/index.html`

제공 DB 스크립트:

- `3_학사관리_DB.sql`

시험 시작 전에 제공 스크립트를 MySQL에서 실행한다. 스크립트가 `academic` 데이터베이스와 `department`, `student` 테이블 및 검색·페이징용 초기 데이터를 생성한다. 수험생은 테이블을 새로 설계하거나 초기 데이터를 만들 필요가 없다.

---

## 3. 실기시험 - 50점

실기 항목은 4개이며 총 50점이다. 2시간 안에 목록, 검색, 페이징을 완성하는 것을 목표로 한다.

### 3.1 프로젝트 생성 및 준비 - 10점

Spring Initializr 또는 기존 Spring Boot 프로젝트를 사용한다.

시험 기준 환경:

- JDK 17 이상
- Spring Boot 4.0.x
- Gradle 8.14.x 이상
- MySQL 8.x

필수 조건:

- `spring-boot-starter-webmvc`
- `spring-boot-starter-thymeleaf`
- `mybatis-spring-boot-starter:4.0.1`
- MySQL Connector/J
- `application.properties` 또는 `application.yml` DB 설정
- 애플리케이션 정상 실행
- Controller-Service-Mapper 계층 구성

기본 실행 주소는 `http://localhost:8080/students`로 한다.

권장 구조:

```text
com.example.academic
├── AcademicApplication.java
├── controller/
├── service/
├── mapper/
├── dto/
└── domain/
```

| 평가 항목 | 배점 |
|---|---:|
| 프로젝트 실행 | 4점 |
| 의존성 및 DB 설정 | 3점 |
| 계층 구조 구성 | 3점 |

### 3.2 학생 목록 - 15점

학생 번호, 이름, 학과, 학년, 이메일, 재학 상태를 DB에서 조회해 표로 출력한다. 조회 결과가 없으면 안내 메시지를 출력한다.

| 평가 항목 | 배점 |
|---|---:|
| 목록 Controller와 화면 연결 | 3점 |
| 목록 조회 Service/Mapper | 3점 |
| 학생 목록 SQL | 4점 |
| Thymeleaf 출력 | 3점 |
| 빈 결과 처리 | 2점 |

### 3.3 학생 검색 - 15점

다음 URL로 학생을 검색한다.

```text
GET /students?keyword=김&departmentId=10&status=ENROLLED
```

- 이름 또는 이메일 검색
- 학과 검색
- 재학 상태 검색
- 입력된 조건만 SQL에 적용

| 평가 항목 | 배점 |
|---|---:|
| 검색 조건 DTO | 3점 |
| Controller-Service 전달 | 3점 |
| MyBatis 동적 SQL | 6점 |
| 검색 결과 및 조건 유지 | 3점 |

### 3.4 학생 목록 페이징 - 10점

한 페이지에 10명씩 출력한다.

```text
GET /students?page=2&size=10&keyword=김
```

검색 조건을 유지한 상태로 페이지를 이동할 수 있어야 한다.

| 평가 항목 | 배점 |
|---|---:|
| page, size 처리 | 2점 |
| offset 계산 | 2점 |
| LIMIT/OFFSET SQL | 3점 |
| 전체 학생 수 조회 | 1점 |
| 이전·다음·페이지 번호 링크 | 2점 |

## 4. 제공 DB 사용

시험자는 `3_학사관리_DB.sql`을 실행해 DB를 준비한다. 제공 스크립트에는 다음 내용이 포함되어 있다.

- `academic` 데이터베이스 생성
- `department`, `student` 테이블 생성
- 검색과 페이징을 확인할 수 있는 초기 학생 데이터 입력
