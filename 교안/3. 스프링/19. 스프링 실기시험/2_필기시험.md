# 스프링 필기시험 - 학사관리 시스템

## 1. 시험 개요

| 항목 | 내용 |
|---|---|
| 시험 유형 | 지필형 + 4지선다형 |
| 문항 수 | 총 32문항 |

| 시험 범위 | Spring Boot, Spring MVC, Thymeleaf, MyBatis, JUnit |

- 4지선다형 9~32번: 각 1.25점, 총 30점

## 2. 지필형 - 8문항, 20점

각 문항 2.5점이다. 핵심 내용을 서술하시오.

1. Spring IoC와 DI의 의미를 설명하고 DI의 장점을 한 가지 쓰시오.
2. Controller, Service, Mapper 계층의 역할을 각각 설명하시오.
3. `@ModelAttribute`와 `@RequestParam`의 차이를 설명하시오.
4. MyBatis의 `#{}`와 `${}`의 차이와 `${}` 사용 시 주의할 점을 설명하시오.
5. Thymeleaf에서 `th:if`와 `th:each`의 역할을 설명하시오.
6. MyBatis의 `<where>` 태그를 사용하는 이유를 설명하시오.
7. `LIMIT`와 `OFFSET`을 이용한 페이징 원리를 설명하시오.
8. JUnit 단위 테스트의 목적과 단위 테스트의 장점을 설명하시오.

## 3. 4지선다형 - 24문항, 30점

각 문항 1.25점이며 정답은 하나이다.

9. `@SpringBootApplication`의 주요 역할은?
   ① 컴포넌트 스캔과 자동 설정을 활성화한다 ② SQL을 자동 작성한다 ③ DB 데이터를 삭제한다 ④ HTML을 압축한다

10. JUnit에서 기대값과 실제값이 같은지 검증하는 메서드는?
    ① `assertEquals` ② `assertSameText` ③ `assertValue` ④ `assertData`

11. `@Controller` 메서드가 반환하는 문자열의 일반적인 의미는?
    ① 테이블명 ② 뷰 이름 ③ 비밀번호 ④ 포트 번호

12. `@GetMapping("/students")`가 처리하는 요청은?
    ① GET `/students` ② POST `/students` ③ PUT `/students` ④ DELETE `/students`

13. 컨트롤러에서 화면으로 데이터를 전달할 때 사용하는 객체는?
    ① Model ② Mapper ③ DriverManager ④ ResultSet

14. 요청 경로의 값을 받는 어노테이션은?
    ① `@RequestBody` ② `@PathVariable` ③ `@ResponseBody` ④ `@Autowired`

15. 다음 Controller 메서드에서 `/students/20240001`의 `20240001`을 받는 방법은?

    ```java
    @GetMapping("/students/{studentId}")
    public String detail(??? String studentId) { ... }
    ```

    ① `@RequestParam("studentId")` ② `@PathVariable("studentId")` ③ `@ModelAttribute("studentId")` ④ `@RequestBody("studentId")`

16. Thymeleaf에서 객체의 값을 HTML 텍스트로 출력하는 속성은?
    ① `th:each` ② `th:if` ③ `th:text` ④ `th:href`

17. Thymeleaf에서 목록을 반복 출력하는 속성은?
    ① `th:each` ② `th:object` ③ `th:value` ④ `th:action`

18. MyBatis Mapper 메서드와 XML SQL을 연결하는 기준은?
    ① 주석 ② XML의 select id와 메서드명 ③ HTML id ④ DB 비밀번호

19. `@Service` 클래스의 주된 역할은?
    ① 업무 로직 처리 ② 정적 파일 제공 ③ SQL 문법 검사 ④ 브라우저 렌더링

20. `LIMIT 10 OFFSET 20`의 의미는?
    ① 20개를 건너뛰고 10개 조회 ② 10개를 건너뛰고 20개 조회 ③ 20개 삭제 ④ 전체 정렬

21. 여러 조건에 따라 SQL을 다르게 작성할 때 사용하는 MyBatis 기능은?
    ① 동적 SQL ② 정적 리소스 ③ AOP 프록시 ④ Bean Validation

22. 비밀번호 저장 방법으로 가장 적절한 것은?
    ① 평문 저장 ② URL 저장 ③ BCrypt 등 단방향 해시 ④ HTML 주석 저장

23. 인터셉터의 일반적인 실행 시점은?
    ① 컨트롤러 요청 전후 ② DB 설치 전용 ③ 컴파일 전용 ④ 브라우저 종료 후

24. `@Mapper`의 역할은?
    ① MyBatis Mapper 인터페이스를 등록한다 ② HTML을 렌더링한다 ③ 세션을 생성한다 ④ 서버 포트를 변경한다

25. `@RequestParam`의 기본 역할은?
    ① 쿼리 파라미터를 메서드 인자로 받는다 ② 예외를 처리한다 ③ SQL을 커밋한다 ④ Bean을 삭제한다

26. Spring의 `@Autowired`가 수행하는 작업은?
    ① 의존성 주입 ② 테이블 생성 ③ URL 인코딩 ④ HTML 반복
