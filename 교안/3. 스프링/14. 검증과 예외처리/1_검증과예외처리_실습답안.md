## 문제 1 & 2. 검증 규칙 + 컨트롤러

```java
@Getter @Setter
public class EmpForm {
    private Long empId;

    @NotBlank(message = "이름은 필수입니다")
    @Size(max = 20, message = "이름은 20자 이내")
    private String empName;

    @NotBlank(message = "이메일은 필수입니다")
    @Email(message = "이메일 형식이 아닙니다")
    private String email;

    @NotNull(message = "부서를 선택하세요")
    private Long deptId;

    @NotNull @PositiveOrZero(message = "급여는 0 이상")
    private Integer salary;

    @NotNull(message = "입사일은 필수입니다")
    @PastOrPresent(message = "입사일은 미래일 수 없습니다")
    private LocalDate hireDate;
}
```

```java
@GetMapping("/emps/new")
public String newForm(Model model) {
    model.addAttribute("form", new EmpForm());
    model.addAttribute("depts", deptService.findAll());
    return "emp/form";
}

@PostMapping("/emps")
public String create(@Valid @ModelAttribute("form") EmpForm form,
                     BindingResult br, Model model, RedirectAttributes ra) {
    if (empService.existsByEmail(form.getEmail())) {
        br.rejectValue("email", "duplicate", "이미 사용 중인 이메일입니다");
    }
    if (br.hasErrors()) {
        model.addAttribute("depts", deptService.findAll());
        return "emp/form";
    }
    Long id = empService.register(form);
    ra.addFlashAttribute("message", "등록되었습니다");
    return "redirect:/emps/" + id;
}

@PostMapping("/emps/{id}")
public String update(@PathVariable Long id, @Valid @ModelAttribute("form") EmpForm form,
                     BindingResult br, Model model, RedirectAttributes ra) {
    if (br.hasErrors()) {
        model.addAttribute("depts", deptService.findAll());
        return "emp/form";
    }
    empService.modify(id, form);
    ra.addFlashAttribute("message", "수정되었습니다");
    return "redirect:/emps/" + id;
}
```

## 문제 3. Thymeleaf 에러 표시

```html
<form th:object="${form}" method="post"
      th:action="${form.empId != null} ? @{/emps/{id}(id=${form.empId})} : @{/emps}">
  <input type="hidden" th:field="*{empId}">

  <div class="field" th:errorclass="field--error">
    <label class="label" for="empName">이름 *</label>
    <input class="input" type="text" th:field="*{empName}">
    <p class="form-hint" th:if="${#fields.hasErrors('empName')}" th:errors="*{empName}"></p>
  </div>

  <div class="field" th:errorclass="field--error">
    <label class="label" for="email">이메일 *</label>
    <input class="input" type="email" th:field="*{email}">
    <p class="form-hint" th:if="${#fields.hasErrors('email')}" th:errors="*{email}"></p>
  </div>

  <div class="field" th:errorclass="field--error">
    <label class="label" for="deptId">부서 *</label>
    <select class="select" th:field="*{deptId}">
      <option value="">선택</option>
      <option th:each="d : ${depts}" th:value="${d.deptId}" th:text="${d.deptName}"></option>
    </select>
    <p class="form-hint" th:if="${#fields.hasErrors('deptId')}" th:errors="*{deptId}"></p>
  </div>
  <!-- salary, hireDate 동일 -->

  <button class="btn btn--primary" type="submit">저장</button>
</form>
```

- `th:errorclass="field--error"` : 그 필드에 에러가 있으면 요소에 클래스를 추가(축약형).
- 되돌아와도 `th:field` 가 넘어온 `form` 의 값을 다시 채우므로 **입력값 유지**.

## 문제 5. 전역 예외 처리

```java
@Slf4j
@ControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(NoSuchElementException.class)
    @ResponseStatus(HttpStatus.NOT_FOUND)
    public String notFound(NoSuchElementException e, Model model) {
        model.addAttribute("message", e.getMessage());
        return "error/404";
    }

    @ExceptionHandler(Exception.class)
    @ResponseStatus(HttpStatus.INTERNAL_SERVER_ERROR)
    public String error(Exception e, Model model) {
        log.error("처리되지 않은 예외", e);
        model.addAttribute("message", "잠시 후 다시 시도해 주세요");
        return "error/500";
    }
}
```

`templates/error/404.html` (교안 6절과 동일). `/emps/999` → `EmpServiceImpl.get()` 이
`NoSuchElementException` → advice → `error/404` (상태 404).

## 문제 6. 왜 안 될까 / 왜 400일까

1. **`@NotBlank` 가 무시되는 이유**
   - `build.gradle` 에 `spring-boot-starter-validation` 이 없다 (검증 구현체 미포함).
   - 컨트롤러 파라미터에 `@Valid`(또는 `@Validated`)를 안 붙였다. 애노테이션만 있고 트리거가 없음.
   - (추가) 검증 대상이 `@ModelAttribute`(폼)가 아니라 그냥 `String` 파라미터 개별이면 클래스 레벨
     `@Validated` 가 필요.

2. **폼이 아니라 400이 뜨는 이유**
   `BindingResult` 는 반드시 **`@Valid` 대상 파라미터 바로 다음**에 와야 한다.
   `create(@Valid EmpForm form, Model model, BindingResult br)` 처럼 사이에 `Model` 이 끼면,
   스프링은 `BindingResult` 를 검증 결과 홀더로 인식하지 못하고, 검증 실패 시
   `MethodArgumentNotValidException` 을 던져 **400**이 된다.
   → 순서: `@Valid @ModelAttribute EmpForm form, BindingResult br, Model model, ...`
