## 기본

### 문제 1. 오버로딩 - 넓이 구하기

```java
public class Practice1 {
    public static int 넓이(int 한변) {
        return 한변 * 한변;
    }

    public static int 넓이(int 가로, int 세로) {
        return 가로 * 세로;
    }

    public static void main(String[] args) {
        System.out.println("정사각형 넓이: " + 넓이(5));
        System.out.println("직사각형 넓이: " + 넓이(6, 4));
    }
}
```

**설명**: 매개변수가 1개인 `넓이(int)`와 2개인 `넓이(int, int)`는 서로 다른 메서드로 취급됩니다. 컴파일러는 `넓이(5)`처럼 인자를 1개 넘기면 첫 번째 버전을, `넓이(6, 4)`처럼 2개 넘기면 두 번째 버전을 자동으로 선택해 호출합니다.

**틀리기 쉬운 포인트**: 오버로딩된 메서드끼리는 이름은 같아도 완전히 독립된 별개의 메서드입니다. 하나를 수정해도 다른 하나는 영향받지 않습니다.

### 문제 2. 재귀로 1부터 n까지 합 구하기

```java
public class Practice2 {
    public static int 합구하기(int n) {
        if (n <= 1) {
            return n; // 종료 조건: n이 1이면 더 쪼갤 필요 없이 1을 반환
        }
        return n + 합구하기(n - 1);
    }

    public static void main(String[] args) {
        System.out.println("결과: " + 합구하기(5));
    }
}
```

**설명**: `합구하기(5)`는 `5 + 합구하기(4)`, `합구하기(4)`는 `4 + 합구하기(3)`... 이런 식으로 계속 더 작은 문제로 쪼개지다가, `n`이 1이 되면 재귀 호출을 멈추고 값을 반환하기 시작합니다. (`5+4+3+2+1 = 15`)

**틀리기 쉬운 포인트**: 종료 조건을 `n == 0`으로 잘못 잡으면 `합구하기(0)`까지 호출한 뒤 `0`을 더하게 되어 결과는 같지만 불필요한 호출이 한 번 더 발생합니다. 문제의 범위(1부터 n까지)에 맞는 정확한 종료 조건을 잡는 것이 중요합니다.

### 문제 3. 오버로딩 - 다양한 인사 메서드

```java
public class Practice3 {
    public static void 인사() {
        System.out.println("안녕하세요");
    }

    public static void 인사(String 이름) {
        System.out.println(이름 + "님 안녕하세요");
    }

    public static void main(String[] args) {
        인사();
        인사("홍길동");
    }
}
```

**설명**: 매개변수가 없는 `인사()`와 `String` 하나를 받는 `인사(String)`은 매개변수 개수가 다르므로 오버로딩이 성립합니다. 호출 시 괄호 안의 인자 개수에 따라 자동으로 알맞은 버전이 실행됩니다.

**틀리기 쉬운 포인트**: `void` 메서드도 오버로딩이 가능합니다. 오버로딩은 반환형이 아니라 매개변수 목록으로 구분되기 때문입니다.

### 문제 4. 재귀로 거듭제곱 계산

```java
public class Practice4 {
    public static int 거듭제곱(int 밑, int 지수) {
        if (지수 == 0) {
            return 1; // 종료 조건: 어떤 수의 0제곱은 항상 1
        }
        return 밑 * 거듭제곱(밑, 지수 - 1);
    }

    public static void main(String[] args) {
        System.out.println("결과: " + 거듭제곱(2, 5));
    }
}
```

**설명**: `거듭제곱(2, 5)`는 `2 * 거듭제곱(2, 4)`로, 이는 다시 `2 * 거듭제곱(2, 3)`으로 계속 쪼개지다가 `지수`가 0이 되면 `1`을 반환하며 거꾸로 곱해 올라갑니다. (`2*2*2*2*2*1 = 32`)

**틀리기 쉬운 포인트**: 종료 조건을 `지수 == 1`로 설정하고 `return 밑;`으로 처리해도 결과는 맞지만, `지수 == 0`일 때 예외 처리가 안 되는 문제가 생깁니다. 수학적으로 정확한 종료 조건(0제곱은 1)을 사용하는 것이 더 안전합니다.

### 문제 5. 배열을 매개변수로 받아 초기화하는 메서드

```java
public class Practice5 {
    public static void 배열초기화(int[] 배열) {
        for (int i = 0; i < 배열.length; i++) {
            배열[i] = 0;
        }
    }

    public static void main(String[] args) {
        int[] 숫자들 = {1, 2, 3, 4, 5};
        배열초기화(숫자들);

        for (int 값 : 숫자들) {
            System.out.print(값 + " ");
        }
    }
}
```

**설명**: 배열은 참조형이므로, 메서드에 전달된 `배열` 매개변수는 `main`의 `숫자들`과 같은 배열 객체를 가리킵니다. 메서드 안에서 `배열[i] = 0`으로 값을 바꾸면, 원본인 `숫자들` 배열도 그대로 바뀝니다.

**틀리기 쉬운 포인트**: 만약 `int` 같은 기본형을 매개변수로 받아 메서드 안에서 값을 바꿨다면 원본에 영향이 없습니다(Day4~7 복습). 배열(참조형)과 기본형의 이 차이를 명확히 구분해야 합니다.

### 문제 6. 재귀로 배열의 합계 구하기

```java
public class Practice6 {
    public static int 배열합계(int[] 배열, int 인덱스) {
        if (인덱스 == 배열.length) {
            return 0; // 종료 조건: 배열 끝까지 다 왔으면 더 더할 게 없음
        }
        return 배열[인덱스] + 배열합계(배열, 인덱스 + 1);
    }

    public static void main(String[] args) {
        int[] 숫자들 = {1, 2, 3, 4, 5};
        System.out.println("합계: " + 배열합계(숫자들, 0));
    }
}
```

**설명**: 배열 순회를 반복문 대신 재귀로 구현했습니다. `인덱스`를 하나씩 늘려가며 자신을 호출하다가, 배열의 끝(`인덱스 == 배열.length`)에 도달하면 `0`을 반환하고 거꾸로 값을 더해 올라옵니다.

**틀리기 쉬운 포인트**: 종료 조건을 `인덱스 == 배열.length - 1`로 잘못 잡으면 마지막 요소를 더하지 못하고 끝나버립니다. 배열의 유효 인덱스는 `0`부터 `length-1`까지이므로, "더 이상 인덱스가 없다"는 조건은 정확히 `인덱스 == 배열.length`여야 합니다.

### 문제 7. 종합 - 오버로딩 + 배열 매개변수

```java
public class Practice7 {
    public static int 최댓값찾기(int[] 배열) {
        int 최댓값 = 배열[0];
        for (int 값 : 배열) {
            if (값 > 최댓값) {
                최댓값 = 값;
            }
        }
        return 최댓값;
    }

    public static int 최댓값찾기(int[] 배열1, int[] 배열2) {
        int 최댓값1 = 최댓값찾기(배열1); // 이미 만든 단일 배열 버전을 재사용
        int 최댓값2 = 최댓값찾기(배열2);
        return (최댓값1 > 최댓값2) ? 최댓값1 : 최댓값2;
    }

    public static void main(String[] args) {
        int[] a = {3, 7, 2};
        int[] b = {3, 7, 2};
        int[] c = {9, 1, 4};

        System.out.println("배열 하나의 최댓값: " + 최댓값찾기(a));
        System.out.println("두 배열 중 최댓값: " + 최댓값찾기(b, c));
    }
}
```

**설명**: 매개변수가 배열 1개인 버전과 2개인 버전을 오버로딩으로 구현했습니다. 특히 배열 2개 버전은 이미 만들어둔 배열 1개 버전을 내부에서 재사용해서 코드 중복을 줄였습니다(하나의 메서드가 다른 오버로딩 버전을 호출하는 것도 가능합니다).

**틀리기 쉬운 포인트**: 오버로딩된 메서드끼리 서로 호출할 때도, 매개변수의 개수와 자료형을 정확히 맞춰야 컴파일러가 올바른 버전을 찾을 수 있습니다. `최댓값찾기(배열1)`처럼 배열 1개만 넘기면 단일 배열 버전이, `최댓값찾기(배열1, 배열2)`처럼 2개를 넘기면 두 배열 버전이 호출됩니다.
