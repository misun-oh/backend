# Day 8. 메서드 심화 - 실습

> 아래 문제는 교안에서 다룬 오버로딩, 재귀 메서드, 배열 매개변수만으로 풀 수 있습니다.

---

## 기본

### 문제 1. 오버로딩 - 넓이 구하기
정사각형(변 1개)과 직사각형(가로/세로 2개)의 넓이를 구하는 `넓이` 메서드를 오버로딩으로 각각 만들어 호출하세요.

**Output**
```
정사각형 넓이: 25
직사각형 넓이: 24
```

---

### 문제 2. 재귀로 1부터 n까지 합 구하기
정수 n을 받아 1부터 n까지의 합을 재귀로 계산하는 `합구하기` 메서드를 만들고, `합구하기(5)`를 호출해 출력하세요.

**Output**
```
결과: 15
```

---

## 응용

### 문제 3. 오버로딩 - 다양한 인사 메서드
매개변수가 없으면 "안녕하세요", 이름(String)이 있으면 "OO님 안녕하세요"를 출력하는 `인사` 메서드를 오버로딩으로 만들어 둘 다 호출하세요.

**Output**
```
안녕하세요
홍길동님 안녕하세요
```

---

### 문제 4. 재귀로 거듭제곱 계산
정수 `밑`과 `지수`를 받아 거듭제곱(`밑`의 `지수`승)을 재귀로 계산하는 `거듭제곱` 메서드를 만들고, `거듭제곱(2, 5)`를 호출해 출력하세요. (힌트: `2^5 = 2 * 2^4`, 종료 조건은 지수가 0일 때 1)

**Output**
```
결과: 32
```

---

### 문제 5. 배열을 매개변수로 받아 초기화하는 메서드
정수 배열을 매개변수로 받아 모든 요소를 0으로 초기화하는 `배열초기화` 메서드를 만들고, `{1,2,3,4,5}` 배열에 적용한 뒤 결과를 출력하세요.

**Output**
```
0 0 0 0 0
```

---

## 도전

### 문제 6. 재귀로 배열의 합계 구하기
정수 배열과 인덱스를 매개변수로 받아, 재귀적으로 배열의 합계를 구하는 `배열합계` 메서드를 만드세요. (반복문 사용 금지, 재귀만 사용) `{1,2,3,4,5}` 배열로 호출한 결과를 출력하세요.

**Output**
```
합계: 15
```

---

### 문제 7. 종합 - 오버로딩 + 배열 매개변수
정수 배열 하나를 받으면 그 배열의 최댓값을, 정수 배열 두 개를 받으면 두 배열 최댓값 중 더 큰 값을 반환하는 `최댓값찾기` 메서드를 오버로딩으로 구현하세요. `{3,7,2}`와 `{3,7,2}`, `{9,1,4}`로 각각 호출해 결과를 출력하세요.

**Output**
```
배열 하나의 최댓값: 7
두 배열 중 최댓값: 9
```
