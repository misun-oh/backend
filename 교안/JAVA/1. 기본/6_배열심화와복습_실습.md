# Day 6. 배열 심화 & 복습 - 실습

> 기본/응용 문제는 2차원 배열, 값 교환, 버블 정렬을 다루고, 도전 문제는 Day 1~5 전체 개념을 통합합니다.

---

## 기본

### 문제 1. 2차원 배열 합계
`{{1,2,3}, {4,5,6}, {7,8,9}}` 2차원 배열의 모든 요소의 합을 구해 출력하세요. (중첩 반복문 사용)

**Output**
```
합계: 45
```

---

### 문제 2. 값 교환 (swap)
정수 배열 `{100, 200}`의 두 값을 임시 변수를 이용해 교환한 뒤 출력하세요.

**Output**
```
교환 전: 100, 200
교환 후: 200, 100
```

---

## 응용

### 문제 3. 2차원 배열로 학생 점수 출력
`{{90,85},{78,92},{88,76}}` (학생 3명, 국어/영어)을 순회하며 "n번 학생: 국어 X, 영어 Y" 형식으로 출력하세요.

**Output**
```
1번 학생: 국어 90, 영어 85
2번 학생: 국어 78, 영어 92
3번 학생: 국어 88, 영어 76
```

---

### 문제 4. 버블 정렬로 오름차순 정렬
정수 배열 `{8, 3, 6, 1, 9}`를 버블 정렬로 오름차순 정렬한 뒤 출력하세요.

**Output**
```
1 3 6 8 9
```

---

## 도전 (Day 1~5 통합)

### 문제 5. 학생 이메일에서 아이디 목록 추출
문자열 배열 `{"kim@test.com", "lee@test.com", "park@test.com"}`을 순회하며 각각 `@` 앞부분(아이디)만 추출해서 번호와 함께 출력하세요. (String의 indexOf/substring + 배열 순회 복습)

**Output**
```
1. kim
2. lee
3. park
```

---

### 문제 6. 성적 처리 종합 프로그램
학생 5명의 점수를 담은 배열 `{85, 92, 78, 90, 88}`에 대해 다음을 모두 출력하세요.
1. 합계와 평균(소수점 둘째자리)
2. 최댓값
3. 평균이 85 이상이면 "우수 학급", 아니면 "보통 학급" (삼항 연산자)

**Output**
```
합계: 433
평균: 86.60
최댓값: 92
학급 평가: 우수 학급
```
