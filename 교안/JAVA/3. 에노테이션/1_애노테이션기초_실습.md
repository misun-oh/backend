# 부록 1. 애노테이션 기초 - 실습

> 아래 문제는 교안에서 다룬 @Override, @Deprecated, 커스텀 애노테이션 정의(@interface), @Retention, @Target만으로 풀 수 있습니다.

---

## 기본

### 문제 1. @Deprecated 사용해보기
`EmpDto` 클래스에 `info()` 메서드를 만들고 이제 사용하지 않을 메서드, `@Deprecated` 표시를 하고, `main`에서 `info()`를 호출해보세요. (컴파일은 되지만 경고가 뜨는 것을 확인하는 것이 목적입니다)

**Output**
```
이 메서드 대신 toString()을 사용하세요.
```

---

### 문제 2. 커스텀 애노테이션 정의만 하기
`@interface`로 `필수입력`이라는 이름의 빈 애노테이션을 정의하세요. 아직 `@Retention`, `@Target`은 붙이지 않아도 됩니다.

**확인할 것**: 컴파일 에러 없이 애노테이션 타입이 정의되는지만 확인합니다. (실행 결과 없음)

---

## 응용

### 문제 3. 메타 애노테이션 붙이기
문제 2에서 만든 `필수입력` 애노테이션에 `@Retention(RetentionPolicy.RUNTIME)`과 `@Target(ElementType.FIELD)`를 추가하세요.

**확인할 것**: `import java.lang.annotation.*;` 구문이 필요합니다. 컴파일 에러 없이 동작하는지 확인합니다.

---

### 문제 4. 학과 클래스에 애노테이션 부착
`학과` 클래스를 만들고, `학과명`(String) 필드에 문제 3에서 완성한 `@필수입력`을 붙이세요. `정원`(int) 필드에는 붙이지 마세요. 생성자로 두 필드를 초기화하고, `main`에서 객체를 만들어 출력해보세요.

**Output**
```
학과명: 컴퓨터공학과, 정원: 40
```

---

## 도전

### 문제 5. @Target 제약 확인하기
문제 3의 `필수입력` 애노테이션(`@Target(ElementType.FIELD)`)을 메서드에 붙여보려고 시도한 뒤, 어떤 에러가 발생하는지 주석으로 남기세요. (실제로 컴파일 에러가 나는 코드는 주석 처리해서 제출)

**정답 예시(주석 형태)**
```java
// @필수입력
// public void 학과정보출력() { ... }
// 컴파일 에러 발생: '필수입력' not applicable to method
// (Target이 FIELD로 제한되어 있어 메서드에는 사용할 수 없음)
```

---

### 문제 6. 종합 - 여러 애노테이션을 가진 학생 클래스
`학생` 클래스를 만드세요. `이름`(String), `학번`(String) 필드에는 `@필수입력`을 붙이고, `나이`(int) 필드에는 붙이지 않습니다. `@Deprecated`가 붙은 `구정보조회()` 메서드(기존 방식)와, 대체할 `information()` 메서드(새 방식)를 함께 만들어서, `main`에서 `information()`을 호출해 결과를 확인하세요.

**Output**
```
이름: 홍길동, 학번: S001, 나이: 20
```
