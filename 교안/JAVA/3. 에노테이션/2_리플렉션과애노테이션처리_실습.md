# 부록 2. 리플렉션과 애노테이션 처리 - 실습

> 아래 문제는 교안에서 다룬 getClass, getDeclaredFields, setAccessible, field.get/set, isAnnotationPresent만으로 풀 수 있습니다.
> 부록1에서 만든 `@필수입력` 애노테이션(`@Retention(RUNTIME)`, `@Target(FIELD)`)이 있다고 가정합니다.

---

## 기본

### 문제 1. 클래스의 필드 목록 출력하기
`학생` 클래스(필드: `이름`(String), `학번`(String), `나이`(int))를 만들고, 리플렉션으로 이 클래스가 가진 모든 필드의 이름과 타입을 출력하세요.

**Output**
```
필드 이름: 이름, 타입: class java.lang.String
필드 이름: 학번, 타입: class java.lang.String
필드 이름: 나이, 타입: int
```

---

### 문제 2. 리플렉션으로 필드 값 읽기
문제 1의 `학생` 객체(`"홍길동", "S001", 20`)를 만들고, 리플렉션으로 `이름` 필드의 값을 읽어 출력하세요. (setAccessible 사용)

**Output**
```
이름 필드 값: 홍길동
```

---

## 응용

### 문제 3. 리플렉션으로 필드 값 변경하기
문제 2의 `학생` 객체에서, 리플렉션으로 `나이` 필드의 값을 25로 변경한 뒤, 변경된 값을 다시 리플렉션으로 읽어 출력하세요.

**Output**
```
변경 전 나이: 20
변경 후 나이: 25
```

---

### 문제 4. @필수입력이 붙은 필드만 찾기
`학생` 클래스의 `이름`, `학번` 필드에 `@필수입력`을 붙이고, `나이`에는 붙이지 마세요. 리플렉션으로 `@필수입력`이 붙은 필드 이름만 골라서 출력하세요.

**Output**
```
필수 입력 필드: 이름
필수 입력 필드: 학번
```

---

## 도전

### 문제 5. 검증기 만들기 (Null 체크)
교안의 `검증기` 클래스를 참고해서, `@필수입력`이 붙은 필드가 `null`이면 경고 메시지를 출력하는 검증기를 만드세요. `학생` 객체를 `이름 = null`로 생성해서 검증기를 통과시켜보세요.

**Output**
```
이름은(는) 필수 입력값입니다.
```

---

### 문제 6. 종합 - 여러 객체를 한 검증기로 처리하기
`학과`(필드: `학과명`에 `@필수입력`)와 `학생`(필드: `이름`, `학번`에 `@필수입력`) 두 클래스를 모두 만드세요. 문제 5의 검증기가 두 클래스 모두에 대해 동작하는지 확인하기 위해, `학과` 객체(`학과명 = null`)와 `학생` 객체(`이름 = null, 학번 = "S001"`)를 각각 검증기에 넣어 결과를 출력하세요. (검증기 코드는 `학과`, `학생`이라는 이름을 전혀 언급하지 않아야 합니다)

**Output**
```
학과명은(는) 필수 입력값입니다.
이름은(는) 필수 입력값입니다.
```
