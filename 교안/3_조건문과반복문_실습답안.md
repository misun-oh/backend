## 기본

### 문제 1. 성적 등급 판정 (if-else)

```java
import java.util.Scanner;

public class Practice1 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int 점수 = sc.nextInt();

        if (점수 >= 90) {
            System.out.println("A등급");
        } else if (점수 >= 80) {
            System.out.println("B등급");
        } else if (점수 >= 70) {
            System.out.println("C등급");
        } else {
            System.out.println("D등급");
        }
    }
}
```

**설명**: 조건은 위에서부터 순서대로 검사되므로, 큰 값부터 먼저 비교해야 합니다. 85는 첫 조건(90이상)엔 걸리지 않고, 두 번째 조건(80이상)에서 참이 되어 "B등급"이 출력됩니다.

**틀리기 쉬운 포인트**: 만약 조건 순서를 반대로(작은 값부터) 쓰면, 예를 들어 `점수 >= 70`을 맨 위에 두면 90점도 70점 조건에서 걸려버려 항상 C등급으로 판정되는 오류가 생깁니다.

### 문제 2. 1부터 10까지 출력

```java
public class Practice2 {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            System.out.println(i);
        }
    }
}
```

**설명**: `i`가 1부터 시작해서 10 이하인 동안 반복하며, 매 반복 후 1씩 증가합니다.

**틀리기 쉬운 포인트**: `i < 10`으로 쓰면 1부터 9까지만 출력되어 10이 빠집니다. "10까지"라는 표현은 `<=`로 처리해야 합니다.

## 응용

### 문제 3. 요일 출력 (switch문)

```java
import java.util.Scanner;

public class Practice3 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int day = sc.nextInt();

        switch (day) {
            case 1: System.out.println("월요일"); break;
            case 2: System.out.println("화요일"); break;
            case 3: System.out.println("수요일"); break;
            case 4: System.out.println("목요일"); break;
            case 5: System.out.println("금요일"); break;
            case 6: System.out.println("토요일"); break;
            case 7: System.out.println("일요일"); break;
            default: System.out.println("잘못된 입력입니다");
        }
    }
}
```

**설명**: 입력값 `3`은 `case 3`과 일치하므로 "수요일"이 출력되고, `break`를 만나 switch문을 빠져나갑니다.

**틀리기 쉬운 포인트**: 각 case 뒤에 `break`를 빠뜨리면 예를 들어 3을 입력했을 때 "수요일"부터 "일요일"까지 전부 출력되어 버립니다.

### 문제 4. 1부터 100까지 합계 (while문)

```java
public class Practice4 {
    public static void main(String[] args) {
        int i = 1;
        int 합계 = 0;

        while (i <= 100) {
            합계 += i; // 합계 = 합계 + i
            i++;       // 증감식을 반드시 직접 작성
        }

        System.out.println("합계: " + 합계);
    }
}
```

**설명**: `while`문은 `for`문과 달리 증감식이 자동으로 실행되지 않으므로, 반복문 안에서 `i++`을 직접 작성해야 합니다. `합계 += i`는 Day2에서 배운 복합 대입 연산자로, 누적 합을 구할 때 자주 쓰는 패턴입니다.

**틀리기 쉬운 포인트**: `i++`을 빠뜨리면 `i`가 계속 1에 머물러 조건이 영원히 참이 되는 무한루프에 빠집니다.

### 문제 5. 3의 배수만 출력하고 50 넘으면 중단

```java
public class Practice5 {
    public static void main(String[] args) {
        for (int i = 1; i <= 100; i++) {
            if (i % 3 != 0) {
                continue; // 3의 배수가 아니면 아래 코드를 건너뛰고 다음 반복으로
            }
            if (i > 50) {
                break; // 50을 넘으면 반복문 전체 종료
            }
            System.out.println(i);
        }
    }
}
```

**설명**: `continue`는 현재 반복만 건너뛰고 다음 `i`로 넘어가지만, `break`는 반복문 자체를 완전히 끝냅니다. 이 문제에서는 3의 배수가 아닌 값은 `continue`로 넘기고, 3의 배수 중 50을 넘는 첫 값을 만나면 `break`로 종료합니다.

**틀리기 쉬운 포인트**: `break` 조건(`i > 50`)을 `continue` 조건보다 먼저 검사하면, 51처럼 3의 배수가 아닌 값에서도 조기 종료될 수 있어 로직이 꼬입니다. 순서를 "3의 배수 여부 → 범위 확인" 순으로 정확히 지켜야 합니다.

## 도전

### 문제 6. 별 찍기 (중첩 반복문)

```java
import java.util.Scanner;

public class Practice6 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        for (int i = 1; i <= n; i++) {       // 바깥 반복문: 줄 수 담당
            for (int j = 1; j <= i; j++) {   // 안쪽 반복문: 별 개수 담당 (줄마다 i개)
                System.out.print("*");
            }
            System.out.println(); // 한 줄이 끝나면 줄바꿈
        }
    }
}
```

**설명**: 바깥 반복문의 `i`가 현재 몇 번째 줄인지를 나타내고, 안쪽 반복문은 `1`부터 `i`까지 반복하며 별을 출력합니다. 즉 1번째 줄은 별 1개, 2번째 줄은 별 2개... 이런 식으로 늘어납니다.

**틀리기 쉬운 포인트**: 안쪽 반복문에서 `System.out.print`(줄바꿈 없음) 대신 `println`을 쓰면 별이 한 줄에 한 개씩만 찍히고 줄이 계속 바뀌어 삼각형 모양이 무너집니다. 한 줄의 별을 다 찍은 뒤 바깥 반복문에서 딱 한 번만 `println()`으로 줄바꿈해야 합니다.

### 문제 7. 종합 - 원하는 단의 구구단 출력

```java
import java.util.Scanner;

public class Practice7 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int 단 = sc.nextInt();

        if (단 < 2 || 단 > 9) {
            System.out.println("잘못된 입력입니다");
        } else {
            for (int i = 1; i <= 9; i++) {
                System.out.println(단 + " x " + i + " = " + (단 * i));
            }
        }
    }
}
```

**설명**: 먼저 `if`로 입력값이 2~9 범위를 벗어나는지 확인하고, 범위 안이면 `else` 블록에서 `for`문으로 구구단을 출력합니다. `단 < 2 || 단 > 9`는 "2보다 작거나 9보다 크면"이라는 뜻으로, 2~9 범위를 벗어나는 모든 경우를 잡아냅니다.

**틀리기 쉬운 포인트**: 조건을 `단 < 2 && 단 > 9`처럼 `&&`로 쓰면 동시에 만족할 수 없는 조건이 되어(어떤 수도 2보다 작으면서 9보다 클 수 없음) 항상 `false`가 되어버립니다. "범위를 벗어난다"는 조건은 `||`(또는)로 표현해야 합니다.
