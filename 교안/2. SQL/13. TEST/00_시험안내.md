# 데이터베이스 시험 안내

| 항목 | 내용 |
|---|---|
| DBMS | MySQL 8.0 |
| 배점 | 필기 = 선다형 40 + 주관식 10 = **50점** / 실기 50문항 × 1점 = **50점** (합계 100점) |
| 대상 스키마 | 춘 대학교 교육시스템 (테이블 6개) |

## 시험 자료

| 파일 | 용도 |
|---|---|
| `01_스키마및실습데이터.sql` | 실기 1단계에서 실행. DB 생성 → 테이블 6개 생성(제약조건 포함) → 데이터 적재 |
| `02_필기시험_문제.md` / `02_필기시험_답안.md` | 필기 |
| `03_실기시험_문제.md` / `03_실기시험_답안.md` | 실기 |

## 실기 진행 방법

1. MySQL에 접속해 시험용 **데이터베이스를 생성**한다. (`01_스키마및실습데이터.sql` 상단에 `CREATE DATABASE … USE …` 포함, 이름은 자유)
2. `01_스키마및실습데이터.sql` **전체를 실행**해 6개 테이블과 데이터를 만든다. 스크립트 끝의 건수 확인 쿼리로 `20 / 25 / 60 / 32 / 30 / 97` 이 나오는지 본다.
3. `03_실기시험_문제.md` 의 50문항을 SQL로 작성해 하나의 `.sql` 파일로 제출한다.

## 스키마 요약

```
TB_DEPARTMENT (학과)         PK: DEPARTMENT_NO
  DEPARTMENT_NO, DEPARTMENT_NAME, CATEGORY(계열), OPEN_YN, CAPACITY(정원)

TB_PROFESSOR (교수)          PK: PROFESSOR_NO   FK: DEPARTMENT_NO → TB_DEPARTMENT (총장은 NULL)
  PROFESSOR_NO, PROFESSOR_NAME, PROFESSOR_SSN, PROFESSOR_ADDRESS, DEPARTMENT_NO

TB_STUDENT (학생)            PK: STUDENT_NO
  FK: DEPARTMENT_NO → TB_DEPARTMENT,  COACH_PROFESSOR_NO → TB_PROFESSOR (지도교수 없으면 NULL)
  STUDENT_NO, DEPARTMENT_NO, STUDENT_NAME, STUDENT_SSN, STUDENT_ADDRESS,
  ENTRANCE_DATE(입학일), ABSENCE_YN(휴학여부), COACH_PROFESSOR_NO

TB_CLASS (과목)              PK: CLASS_NO
  FK: DEPARTMENT_NO → TB_DEPARTMENT,  PREATTENDING_CLASS_NO → TB_CLASS (선수과목, 자기참조)
  CLASS_NO, DEPARTMENT_NO, PREATTENDING_CLASS_NO, CLASS_NAME, CLASS_TYPE

TB_CLASS_PROFESSOR (과목교수) PK: (CLASS_NO, PROFESSOR_NO)   FK: 각각 TB_CLASS / TB_PROFESSOR

TB_GRADE (성적)              PK: (TERM_NO, CLASS_NO, STUDENT_NO)
  FK: CLASS_NO → TB_CLASS,  STUDENT_NO → TB_STUDENT
  TERM_NO(학기, 예 '200401'=2004년 1학기), CLASS_NO, STUDENT_NO, POINT(0.00~4.50)
```

## 데이터 특징 (실기 문제와 연결)

- 계열(CATEGORY)은 5종: 인문사회 / 자연과학 / 공학 / 예체능 / 의학
- **총장**: `TB_PROFESSOR` 에서 `DEPARTMENT_NO` 가 NULL 인 교수 (P01 임해정)
- **이름이 세 글자가 아닌 교수**: 강혁(P05, 2글자), 선우재덕(P24, 4글자)
- **지도교수 없는 학생**: 8명 (`COACH_PROFESSOR_NO IS NULL`)
- **휴학생**: 11명 (`ABSENCE_YN = 'Y'`)
- **동명이인**: 김민준 3명, 이서연·김태리·남주혁·박서준·김다미·한소희 각 2명
- **선수과목 있는 과목**: 10개 (`PREATTENDING_CLASS_NO IS NOT NULL`)
- **담당교수 없는 과목**: 4개 (`TB_CLASS_PROFESSOR` 에 없는 `CLASS_NO` — C0016·C0019·C0020·C0030)
- **2000년 이전 학번**: 5명 (`STUDENT_NO NOT LIKE 'A%'`)
- **주소 미입력 학생**: 1명 (`STUDENT_ADDRESS IS NULL` — A071030 고민시)
- 주민번호 형식: `YYMMDD-Gxxxxxx`, 성별자리 G가 `1`·`3` 이면 남자, `2`·`4` 이면 여자. 이 데이터는 모두 1900년대 출생(`1`/`2`).

## 채점 기준

- **필기**: 선다형은 단일 정답. 주관식은 키워드가 맞으면 정답(대소문자·조사 무관).
- **실기**: 결과 집합(행·값)이 정답과 일치하면 정답. 문제에 출력 헤더(별칭)가 명시된 경우 별칭까지 일치해야 함. 정렬이 명시된 경우 정렬까지 채점.
