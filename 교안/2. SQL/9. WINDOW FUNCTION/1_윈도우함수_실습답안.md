## 기본

### 문제 1. RANK 기본

```sql
SELECT EMP_NAME, SALARY,
       RANK() OVER (ORDER BY SALARY DESC) AS 순위
FROM EMP
WHERE DEPT_ID = 'D9';
```

**출력 결과**
```
곽상혁 8000000 1
권진우 6000000 2
김민혜 3700000 3
```

**설명**: 총무부 세 사원의 급여가 모두 달라 동점이 없으므로, `RANK()`가 `ROW_NUMBER()`와
똑같이 1, 2, 3을 매깁니다.

### 문제 2. AVG() OVER

```sql
SELECT EMP_NAME, SALARY,
       AVG(SALARY) OVER (PARTITION BY DEPT_ID) AS 부서평균
FROM EMP
WHERE DEPT_ID = 'D5'
ORDER BY EMP_ID;
```

**출력 결과**
```
박지민 3500000 2752000
염성원 2200000 2752000
유제영 2500000 2752000
윤정주 3760000 2752000
최주호 1800000 2752000
```

**설명**: 해외영업1부(D5) 5명의 급여 합계 13,760,000원을 5로 나눈 2,752,000원이
각 사원 행마다 그대로 반복됩니다. `GROUP BY`였다면 이 값 하나만 남고 개별 사원 정보는
사라졌을 것입니다.

## 응용

### 문제 3. PARTITION BY

```sql
SELECT EMP_NAME, DEPT_ID, SALARY,
       RANK() OVER (PARTITION BY DEPT_ID ORDER BY SALARY DESC) AS 부서내순위
FROM EMP
WHERE DEPT_ID IN ('D8', 'D2')
ORDER BY DEPT_ID, 부서내순위;
```

**출력 결과**
```
이금빈 D8 2550000 1
오미자 D8 2436240 2
이광렬 D8 2000000 3
박홍주 D2 2800000 1
엄용민 D2 2490000 2
심재호 D2 1550000 3
```

**설명**: `PARTITION BY DEPT_ID`가 D8과 D2를 각각 별도의 윈도우로 나누므로, 순위가
서로 영향을 주지 않고 부서별로 1위부터 다시 매겨집니다.

---

### 문제 4. LAG / LEAD

```sql
SELECT EMP_NAME, SALARY,
       LAG(SALARY)  OVER (ORDER BY SALARY DESC) AS 윗사람급여,
       LEAD(SALARY) OVER (ORDER BY SALARY DESC) AS 아랫사람급여
FROM EMP
WHERE DEPT_ID = 'D1'
ORDER BY SALARY DESC;
```

**출력 결과**
```
전태성 3660000 (null)    2780000
이다현 2780000 3660000   1380000
한재헌 1380000 2780000   (null)
```

**설명**: 1위(전태성) 위에는 아무도 없어 `LAG`가 `NULL`, 3위(한재헌) 아래에는 아무도
없어 `LEAD`가 `NULL`입니다. 가운데(이다현)는 위(전태성)·아래(한재헌) 값을 모두
가져옵니다.

### 문제 5. 누적 합계

```sql
SELECT EMP_NAME, SALARY,
       SUM(SALARY) OVER (ORDER BY SALARY DESC) AS 누적합계
FROM EMP
WHERE DEPT_ID = 'D9'
ORDER BY SALARY DESC;
```

**출력 결과**
```
곽상혁 8000000 8000000
권진우 6000000 14000000
김민혜 3700000 17700000
```

**설명**: `ORDER BY`가 있는 `SUM() OVER`는 "정렬 순서상 지금 행까지의 합"을 계산하므로,
마지막 행(김민혜)의 누적합계 17,700,000원은 총무부 전체 급여 합계와 정확히 일치합니다.

## 도전

### 문제 6. RANK vs DENSE_RANK

```sql
SELECT EMP_NAME, EXTRACT(YEAR FROM HIRE_DATE) AS 입사연도,
       ROW_NUMBER() OVER (ORDER BY EXTRACT(YEAR FROM HIRE_DATE) ASC) AS 순번,
       RANK()       OVER (ORDER BY EXTRACT(YEAR FROM HIRE_DATE) ASC) AS 순위,
       DENSE_RANK() OVER (ORDER BY EXTRACT(YEAR FROM HIRE_DATE) ASC) AS 밀집순위
FROM EMP
WHERE DEPT_ID = 'D9';
```

**출력 결과**
```
곽상혁 2013 1 1 1
권진우 2013 2 1 1
김민혜 2014 3 3 2
```

**설명**: 곽상혁·권진우는 둘 다 2013년 입사로 동점입니다. `RANK()`는 동점 다음 순위를
동점 인원수(2명)만큼 건너뛰어 3을 매기지만, `DENSE_RANK()`는 건너뛰지 않고 2를
매깁니다. `ROW_NUMBER()`는 동점과 무관하게 항상 1, 2, 3을 매깁니다.

### 문제 7. 종합 - 부서별 Top-2

```sql
SELECT *
FROM (
    SELECT EMP_NAME, DEPT_ID, SALARY,
           RANK() OVER (PARTITION BY DEPT_ID ORDER BY SALARY DESC) AS 부서내순위
    FROM EMP
    WHERE DEPT_ID IS NOT NULL
) T
WHERE T.부서내순위 <= 2
ORDER BY DEPT_ID, 부서내순위;
```

**출력 결과**
```
전태성 D1 3660000 1
이다현 D1 2780000 2
박홍주 D2 2800000 1
엄용민 D2 2490000 2
윤정주 D5 3760000 1
박지민 D5 3500000 2
김태일 D6 3900000 1
김은민 D6 3400000 2
이금빈 D8 2550000 1
오미자 D8 2436240 2
곽상혁 D9 8000000 1
권진우 D9 6000000 2
```

**설명**: 인라인 뷰(`T`)가 부서별 급여 순위를 먼저 매기고, 바깥 쿼리는 그 결과를
`부서내순위 <= 2`로 걸러서 부서마다 상위 2명만 남깁니다. `DEPT_ID IS NOT NULL` 조건이
없으면 부서가 없는 조정원·한규원도 자기들끼리 하나의 파티션(`NULL`)을 이뤄 1, 2위로
잘못 조회되므로 반드시 제외해야 합니다.
