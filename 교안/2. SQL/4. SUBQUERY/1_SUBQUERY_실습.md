### 문제 15. 여러 개의 CTE
부서별 인원수를 구하는 CTE `DEPT_COUNT`를 만들고, 이어서 그중 인원수가 3명 이상인
부서만 골라내는 CTE `BIG_DEPT`를 정의하세요(`BIG_DEPT`는 `DEPT_COUNT`를 참조).
마지막으로 `BIG_DEPT`와 `DEPT`를 조인해서 부서명과 인원수를 인원수 내림차순(동률이면
부서코드 오름차순)으로 조회하세요.

**Output**
```
해외영업1부 5
인사관리부  3
회계관리부  3
기술지원부  3
총무부      3
```
