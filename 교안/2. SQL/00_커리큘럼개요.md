# SQL 교안 커리큘럼 개요 (2주 + 심화 과정)

이 교안은 MySQL 커리큘럼 중 실무에서 가장 많이 쓰이는 4개 챕터
(DQL/함수/JOIN/SUBQUERY)를 뽑아 2주(10일) 과정으로 재구성하고, DB 모델링/정규화
기초를 5번째 챕터로 덧붙인 것입니다. 6~8번째 챕터(DDL/DML/TCL)는 테이블을 직접
만들고 데이터를 조작·확정하는 능력을 위해 추가된 확장 챕터로, Day 11~13(3일) 분량으로
편성합니다. 9~12번째 챕터(WINDOW FUNCTION/INDEX/VIEW & FUNCTION/PROCEDURE &
TRIGGER)는 실무에서 자주 쓰이는 분석·튜닝·DB 객체 설계 역량을 위한 심화 챕터로,
Day 14~17(4일) 분량으로 편성합니다.

## 선수 조건
- `0. 환경구성/00_환경구성.md`로 MySQL Server + Workbench 설치, 계정 생성/권한 부여
  완료
- `0. 환경구성/02_ERD읽는법.md`로 ERD 표기법(PK/FK, 까마귀발 표기) 확인 완료
- `0. 환경구성/01_실습데이터.md`의 스크립트로 실습용 테이블/데이터 생성 완료
- (선택) `0. 환경구성/03_Workbench_ERD추출.md`로 Workbench의 Reverse Engineer 기능을
  미리 익혀두면, `6. DDL` 챕터에서 제약조건을 추가한 뒤 실제 ERD가 어떻게 그려지는지
  직접 확인할 수 있음
- "왜 테이블이 여러 개로 나뉘는지"(정규화)는 `5. DB모델링/2_ERD와정규화.md`에서 다룸
- DDL/DML 기초 문법(SELECT문이 무엇인지 정도)은 몰라도 무방함 — 1일차부터 처음 다룸

## 챕터별 학습 목표 요약

| 챕터 | 이 과정을 마치면 할 수 있는 것 |
|---|---|
| DQL(SELECT) | 조건에 맞는 데이터를 조회하고, 정렬해서 원하는 순서로 확인할 수 있다 |
| 함수(FUNCTION) | 원본 데이터를 가공(문자열 자르기/날짜 계산/형 변환/집계)해서 원하는 형태로 출력할 수 있다 |
| JOIN | 여러 테이블에 나뉘어 있는 데이터를 하나의 결과로 합쳐서 조회할 수 있다 |
| SUBQUERY | "먼저 조회한 결과를 다시 조건으로 쓰는" 2단계 이상의 복잡한 질문을 SQL 한 문장으로 표현할 수 있다 |
| DB모델링 | 엔티티/관계/카디널리티 개념과 ERD 표기법, 정규화(1~3차)를 이해하고 적용할 수 있다 |
| DDL | 제약조건을 갖춘 테이블을 직접 만들고, 구조를 변경·삭제할 수 있다 |
| DML | 테이블에 데이터를 추가·수정·삭제하고, `WHERE` 누락의 위험을 피할 수 있다 |
| TCL | 여러 DML을 하나의 트랜잭션으로 묶어 확정(`COMMIT`)하거나 취소(`ROLLBACK`)할 수 있다 |
| WINDOW FUNCTION | 원본 행을 유지한 채 순위·누적합을 계산하고, 그룹별 Top-N을 구할 수 있다 |
| INDEX & EXPLAIN | 인덱스로 조회를 빠르게 하고, 실행계획을 읽어 인덱스 사용 여부를 진단할 수 있다 |
| VIEW & FUNCTION | 자주 쓰는 쿼리를 뷰/함수로 저장해 재사용하고, 갱신 가능한 뷰를 구분할 수 있다 |
| PROCEDURE & TRIGGER | 여러 SQL을 프로시저로 묶고, 특정 이벤트에 자동 실행되는 트리거를 만들 수 있다 |

## 실습 데이터
DQL/함수/JOIN/SUBQUERY 4개 챕터는 `0. 환경구성/01_실습데이터.md`에 정의된 동일한
스키마(DEPT, EMP, JOB, LOCATION, NATIONAL, SAL_GRADE)를 공유합니다. EMP 테이블은
21명 규모이며, 생년월일 1980~2005년, 입사일 2013년 이후로 구성했습니다. `5. DB모델링/`
챕터는 이 실습 데이터와 별개로 도서관리(회원/도서/대여) 도메인을 자체 예시로 사용합니다.
`6. DDL`/`7. DML`/`8. TCL`/`11. VIEW_FUNCTION`/`12. PROCEDURE_TRIGGER` 챕터는 원본
`EMP`/`DEPT`를 훼손하지 않도록 `CREATE TABLE ... AS SELECT`로 만든
`EMP_COPY`/`DEPT_COPY` 사본에서 실습합니다. `9. WINDOW FUNCTION`/`10. INDEX` 챕터는
데이터를 변경하지 않는 조회 위주 실습이라 원본 `EMP`/`DEPT`를 그대로 사용하며,
`10. INDEX`는 여기에 더해 인덱스 효과를 보여주기 위한 대용량 실습 테이블
`BIG_EMP`(63,000행, `EMP`를 복제해 생성)를 별도로 다룹니다.
